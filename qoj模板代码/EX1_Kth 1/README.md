# EX1. Kth 1

- QOJ: https://qoj.ac/contest/3936/problem/15001
- 状态：高性能候选已由提交 `2832178` 验证，尚未回写正式模板
- 相关模板条目：7.1.001、9.1.002、13.2.004
- 运行要求：GCC/Clang x86-64，目标机需支持 AVX-512F、BMI1、BMI2；代码中的 `k` 为从 0 开始的置位排名。

## 做法

1. `_pdep_u64(1ULL<<k,x)` 只留下 `x` 从低到高第 `k` 个置位；不存在时结果为零。`_tzcnt_u64` 返回该位编号，并约定零的结果为 64。
2. Xorshift 只含移位和异或，是 GF(2) 上的 64 维线性变换。代码保存 64 个基向量的像，并对该变换快速幂，从而一次跳过很多随机状态。
3. 一个询问消耗两次 Xorshift。剩余 `n` 个询问被切成 16 段，每段含 `n/16` 个询问，相邻段首相隔 `n/8` 个随机状态。
4. 两个 512 位向量各保存 8 个段状态，同时推进全部 16 段；主循环每轮展开 8 次，共处理 128 个询问。开头先标量处理 `n%128` 个询问。

矩阵预处理约为 `O(64^2 log n)` 个机器字操作，主循环仍是 `O(n)`，但随机数推进被 16 路分流并由 AVX-512 并行执行。`-DLOCAL` 会运行随机暴力对拍，不读取标准输入。
