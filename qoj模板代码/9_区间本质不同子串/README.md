# 9. 区间本质不同子串

- QOJ: https://qoj.ac/contest/3936/problem/13268
- 状态：性能版 `main.cpp` 已保留用于 QOJ；打印版候选 `template.hpp` 待批准写入正式模板
- 模板条目：4.3.010
- 实现：采用离线 SAM、后缀链接树和区间数据结构处理最多 `2e5` 次区间询问；前缀新增子串的贡献用等差数列直接计算，线段树只维护重复子串产生的负修正，不再执行每个右端点一次的前缀加一。
- 复杂度：当前颜色段枚举最坏为 `O(n log^2 n+q log n)`，接口 `rangeSubs(s, queryList)` 使用 0 下标左闭右开区间；进一步优化方向是用 LCT/HLD 批量维护后缀链接树上的颜色段。
- 实测：同一份代码在 `n=q=2e5`、`-O2` 下随机串中位数约 `0.282s`，全相同串约 `0.162s`，周期串约 `0.219s`；同输入并排测试中，随机数据由约 `0.364s` 降到 `0.294s`，约快 `19%`。这不是编译器或 I/O 卡常，主要减少了 `n` 次线段树区间修改。
- 说明：颜色段访问仍是当前版本的主要耗时；若要把最坏复杂度再降一层，需要重新证明并实现 LCT 的路径访问与区间修正，暂不将未经对拍的实现写入候选模板。
