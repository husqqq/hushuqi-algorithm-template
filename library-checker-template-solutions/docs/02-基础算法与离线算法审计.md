## 审计结论

`other/longest_increasing_subsequence` 的题面要求长度最大的一条严格上升子序列的 0-based 原下标，`N<=500000`、`A_i<=10^9`、时限 5 秒。checker 只检查长度最优、下标严格递增和对应值严格递增，因此不要求与参考实现输出同一条方案。

模板 `2.2.010 lis` 与受控参考都维护“每个长度的最小末值”和该末值的原下标；`lower_bound` 保证严格上升，替换末值不损失最优扩展性，`pre` 链恢复原下标。时间为 `O(N log N)`，额外空间 `O(N)`；值和下标均覆盖题面范围。模板无需修改。新增开发期 `test_ch02_lis.cpp` 覆盖单元素、全相等、递减、递增、重复值及 2000 组固定种子小规模 DP 长度对拍，并检查返回下标和值的严格性。

候选由 `tools/generate_ch02_lc.py --write` 从当前头文件确定性展开后附加 I/O 适配层生成；独立源码 SHA256 为 `a2a0b54c74f6ad10789615250edabe502d0cd58f6bf98924ee0995199ebf215f`，受控参考源码 SHA256 为 `271465709b6482629860f79ff7786acab7b245e7b738bae44432ae327f25ba9b`。本地收据 `.local/scoped-receipts/longest_increasing_subsequence.json` 在固定官方 commit 上通过 sample、`hand_min` 和固定种子 `random`，并由官方 checker 验证。max_random 五轮性能中位数为 0.065811 秒，参考为 0.065171 秒，倍率 1.0098，满足 1.25 倍门槛。

真实线上提交 #395500 为 AC（0.059 秒，22118400 B）；服务端回显 SHA256 与当前独立源码相同，且 `is_latest=true`。第 02 章的冻结范围仅此一题，故该章已完成当前 LC 闭环。
