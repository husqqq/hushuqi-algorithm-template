# 工具目录

本目录只存放可复用的流程工具，不保存任何提交源码、登录信息、日志或一次性产物。

- `check_lc_template_mapping.py`：校验 LC 到模板的唯一映射。
- `generate_ch03_lc.py`、`generate_ch04_lc.py`、`generate_lc_gaps.py`：从当前模板确定性生成候选源码。生成器必须提供无副作用的 `--check` 和显式的 `--write`；不得在帮助、核验或无参数模式改写候选、收据或线上状态。
- `verify_local.py`：使用官方题库与 checker 做本地验证。
- `benchmark_ch03.py`、`ch03_batch_report.py`、`ch03_result_report.py`、`refresh_ch03_audit.py`：第 03 章性能、批次、结果和审计报告工具。
- `submit_yosupo.py`：受控在线提交工具。
- `refresh_untrusted_inventory.py`：刷新“不可完全置信清单”；本地验证或同哈希线上 AC 任一成立即可提供当前正确性证据，零缺口时删除该目录。
- `audit_all_chapters.py`：从 TSV 与当前证据生成全章节审计快照；`--check` 只读核验。
- `refresh_ch10_scope_matrix.py`：从 TSV 维护第 10 章当前官方覆盖矩阵；`--check` 只读核验。
- `tests/`：这些工具的 Python 回归测试；从工作区根目录运行 `python -m unittest discover -s library-checker-template-solutions/tools/tests -p 'test_*.py'`。

从工作区根目录调用工具时统一使用 `python library-checker-template-solutions/tools/<tool>.py ...`。题目候选源码仍固定保存在各 `<category>/<problem>/` 目录，状态与可复用依赖仍固定在 `.local/`。
