## 2026-10-16 字符串模板续审

本轮按正文顺序阅读第 04 章与对应性能头，核对打印头的完整差异，并重点验证以下三个已定位问题。此记录不代表全章公共依赖、全部调用测试或 12 道 LC 的源码级复核已经完成；上表的 11 份过期候选仍须逐题同步，4 份缺当前验证的候选仍公开保留。

- `4.1.002 KMPAutomaton::build`：旧版每个状态、字符分别沿失配链回退；模式为全相同字符且查询另一个字符时，总回退次数为平方级，与正文不符。新版直接复用已建的 `go[pi[state-1]][x]`，并复用同条目的 `prefix`，时间、空间均为 $O(A(n+1))$。默认构造现在建立空模式自环；字符按无符号字节编码，覆盖 0、128、255 与高字节起始字符集。
- `4.5.002 lcsBitset`：块内同名 `borrow` 遮蔽外层借位，随后 `borrow=borrow` 未向下一块传递。固定输入 `a="ab"`、`b="a"+string(63,'c')+"b"` 的原结果为 1，正确结果为 2。新版同时维护移位进位与减法借位；`y+borrow` 的无符号溢出也传递借位，并合并两次扫描、删除两份临时位集。正文补充 DP 行差位集、不变量、低位减法和可复制的跨块固定答案。
- `4.1.010`：原 `search` 示例在文本和模式均为空时，把等于 `end()` 的成功位置误记为 -1；现在显式令空模式的首次位置为 0。

`tests/test_ch04_kmp_automaton.cpp` 穷举长度 0–9 的二元模式，逐状态、逐字符与直接后缀比较核对两种 `next`；另检查重叠、重建、空模式、任意字节和 20 万字符重复模式。新增 `tests/test_ch04_lcs_bitset.cpp` 以独立二维 DP 核对 600 组固定种子的随机字节串及两种参数顺序，并检查 63/64/65、127/128/129 等块边界、连续借位和满块移位。两版的专项测试及关闭整数宏后的 32 位 `-ftrapv -Werror=shadow` 均通过。正文五个 C++ 代码块经 GitHub Markdown API 渲染；KMP、LCS 与搜索示例分别拼接编译、运行通过。
