## 排除项

| 实现 | 未作为该题变体的理由 |
|---|---|
| 5.6.001 普通匈牙利 | `bipartitematching` 最大规模下最坏 `O(VE)` 不满足目标复杂度。 |
| 5.6.002 Bitset 匈牙利 | 官方最大左右部规模下邻接位矩阵内存上界不成立。 |
| 5.3.003 Bitset Kosaraju | `scc` 最大规模下 `O(N^3/64)` 时间和 `O(N^2/64)` 空间不成立。 |
| 5.8.010 HLPP | 返回最大 preflow 值，但公开残量状态可能保留不可达汇点的超额，不能直接输出 `bipartitematching` 所需合法匹配证书；官方大用例 checker 已据此拒绝本地适配器，未在线提交。 |
| 10.1.003 NTT32 | 明确限制最大变换长度 `2^17`，不能覆盖 `convolution_mod` 完整约束。 |
| 10.1.004 三模任意模卷积 | `convNTTMod` 明确限制变换长度 `2^20`，不能覆盖该题完整上界。 |
| 10.1.002 浮点 FFT | 当前接口返回浮点卷积，不能保证该模卷积题的精确剩余类结果。 |
| 3.3.006 非递归线段树 | 文档明确是 3.3.005 `ZkwSeg` 的同一实现别名，不重复提交。 |
| 3.1.002 按大小/按秩合并 | 文档明确复用 3.1.001 `DSU`，不是第二份实现。 |
| 5.7.003 Tutte Matrix | 当前接口只返回匹配大小，不能输出 `general_matching` 要求的匹配边证书。 |
| 3.4.002 BlockRMQ | 正文明确当前实现最坏为 `O(n sqrt(log n))`，而 `staticrmq` 完整约束为 `N,Q<=500000`，不能仅凭小样例纳入完整规模候选。 |
| 3.3.007--3.3.009 predecessor 平衡树实现 | `predecessor_problem` 的官方 `N<=10^7`；逐节点 Treap/FHQ/Splay 构建的时间和内存上界不满足完整约束，因此不作为该题变体提交。 |
| 3.6.006 `FixedHashSet` | 冻结题库没有只要求插入与成员查询的集合题；`predecessor_problem`、`ordered_set` 和 `set_xor_min` 都要求当前接口不支持的删除及顺序/XOR 查询，逐询问用于 `static_range_count_distinct` 又不满足完整规模，因此不生成在线变体。 |

稳定婚姻、稀疏稳定匹配等目录项在冻结 LC 题库中没有对应官方题，因此保留本地测试，不强行映射。更一般的数据结构虽然理论上可以模拟某个简单题，但只有其公开主操作、复杂度和输出语义直接匹配时才纳入；不以任意降维或重新实现另一套核心算法来制造重复提交。
