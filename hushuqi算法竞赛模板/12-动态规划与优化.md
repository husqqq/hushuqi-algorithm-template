# 12. 动态规划与优化

> 本章默认 C++20、0 下标和左闭右开区间。每个独立底层模板条目都内嵌完整实现；同一底层模板覆盖多个接口时只保留一处代表实现，其余条目显式注明依赖与所用接口。

## 本章公共前导

以下前导在本章开头只印一次。后续 C++ 代码块均与此前导拼接使用，不再重复头文件、整数宏、无穷大常量和 `chmin` / `chmax`。

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long

constexpr int inf = 1E9;
constexpr long long INF = 4E18;
constexpr long double eps = 1E-12L;

template<class T>
bool chmin(T &a, const T &b)
{
    // a 是当前值，b 是候选值；若 b 更小则更新 a 并返回 true。
    if (b < a)
    {
        a = b;
        return true;
    }
    return false;
}

template<class T>
bool chmax(T &a, const T &b)
{
    // a 是当前值，b 是候选值；若 b 更大则更新 a 并返回 true。
    if (a < b)
    {
        a = b;
        return true;
    }
    return false;
}

int addMod(int a, int b, int mod)
{
    // a、b 是两个非负余数，mod 是正模数；返回两者之和模 mod。
    return a >= mod - b ? a - (mod - b) : a + b;
}
```

## 12.1 背包

### 12.1.001 01 背包

01 背包让每件物品至多用一次，状态 $f[j]$ 是恰好占用容量 $j$ 时的最大价值，转移 $f[j]\leftarrow\max(f[j],\,f[j-w]+v)$。关键在容量必须**倒序**枚举：倒序时 `f[j-w]` 尚未在本轮被同一件物品更新，仍代表"未放入该物品"的旧状态；一旦改成正序，`f[j-w]` 可能已含这件物品，就退化成可重复取的完全背包。不可达容量用 $-\infty$（这里取 `-INF`）标记并在转移前判掉，避免把无效状态当作价值 $0$ 向后传播。

```cpp
vector<int> zeroOnePack(int m, const vector<pair<int, int>> &a)
{
    // m 是容量，a 的每项是物品体积和价值；返回每个恰好容量的最大价值，不可达为 -INF。
    // 调试检查，可删。
    assert(m >= 0);
    vector<int> f(m + 1, -INF);
    f[0] = 0;
    for (auto [w, v] : a)
    {
        // 调试检查，可删。
        assert(w > 0);
        for (int j = m; j >= w; j--)
        {
            if (f[j - w] != -INF)
            {
                chmax(f[j], f[j - w] + v);
            }
        }
    }
    return f;
}
```

调用 `zeroOnePack(m,a)`，容量非负、物品体积为正，且所有可达价值和须能由 `int` 表示；返回的 `f[j]` 是恰好装满容量 $j$ 的最优值，若求容量不超过 $m$ 的答案取 `max(f)`。时间 $O(nm)$、空间 $O(m)$。容量循环方向是这一族的分水岭：可重复取时改用 [12.1.002 完全背包](#121002) 的正序，件数有限用 [12.1.003 多重背包](#121003)，组内互斥用 [12.1.006 分组背包](#121006)，物品间存在选取依赖时不能拍平成普通物品、须走 [12.1.007 有依赖背包](#121007)。

### 12.1.002 完全背包

完全背包每种物品可取任意次，状态与转移和 01 背包完全相同，只有容量改成**正序**枚举：正序时 `f[j-w]` 可能已在本轮被同种物品更新过，于是"再加一件"自然叠加，等价于该物品用无限次。体积必须严格为正，否则 `j-w>=j`、正序循环没有推进方向甚至自我引用。同样用 `-INF` 标记不可达并在转移前判掉。

```cpp
vector<int> completePack(int m, const vector<pair<int, int>> &a)
{
    // m 是容量，a 的每项是物品体积和价值且每种可取任意次；返回各恰好容量的最大价值。
    // 调试检查，可删。
    assert(m >= 0);
    vector<int> f(m + 1, -INF);
    f[0] = 0;
    for (auto [w, v] : a)
    {
        // 调试检查，可删。
        assert(w > 0);
        for (int j = w; j <= m; j++)
        {
            if (f[j - w] != -INF)
            {
                chmax(f[j], f[j - w] + v);
            }
        }
    }
    return f;
}
```

调用 `completePack(m,a)`，语义与 [12.1.001](#121001) 一致但每种可无限取；容量非负、物品体积为正，且所有可达价值和须能由 `int` 表示。时间 $O(nm)$、空间 $O(m)$。当同一种物品有明确件数上限时它会超额取用，应换 [12.1.003 多重背包](#121003)；混合出现多类物品见 [12.1.004 混合背包](#121004)。

### 12.1.003 多重背包

多重背包给每种物品一个件数上限 $c$。直接把它拆成 $c$ 件 01 物品会带来 $O(c)$ 因子，这里用**二进制拆分**：把 $c$ 分成 $1,2,4,\dots$ 直到剩余，每组当作一件体积价值成倍的 01 物品，用 $O(\log c)$ 组就能凑出 $0\sim c$ 之间任意取用件数。拆出的每组仍按 01 背包倒序更新，因此天然不会超额。件数极大时可换成按容量余数分组的单调队列优化（见 [12.1.009](#121009)），二进制拆分胜在实现短、常数稳。

```cpp
vector<int> boundedPack(int m, const vector<array<int, 3>> &a)
{
    // m 是容量；a[i][0..2] 依次是体积、价值和最多可选件数；返回各恰好容量的最大价值。
    // 调试检查，可删。
    assert(m >= 0);
    vector<int> f(m + 1, -INF);
    f[0] = 0;
    for (auto [w, v, c] : a)
    {
        // 调试检查，可删。
        assert(w > 0 && c >= 0);
        int k = 1;
        while (c > 0)
        {
            int z = min(k, c);
            c -= z;
            if (z <= m / w)
            {
                int ww = w * z;
                int vv = v * z;
                for (int j = m; j >= ww; j--)
                {
                    if (f[j - ww] != -INF)
                    {
                        chmax(f[j], f[j - ww] + vv);
                    }
                }
            }
            if (c > 0)
            {
                k = k <= c / 2 ? k * 2 : c;
            }
        }
    }
    return f;
}
```

调用 `boundedPack(m,a)`，`a[i][0..2]` 依次是体积、价值、件数，要求体积为正、件数非负。时间 $O(m\sum_i\log(c_i+1))$、空间 $O(m)$。一个小样例：容量 $10$、物品 `{3,4,2}` 与 `{2,3,3}`，恰好装满容量 $10$ 的最大价值为 $14$。件数无上限时退回 [12.1.002 完全背包](#121002)，与 01、完全物品混杂时用 [12.1.004 混合背包](#121004) 统一处理。

### 12.1.004 混合背包

混合背包在同一份输入里同时出现 01、完全、多重三类物品，做法是所有物品共享同一个 $f$ 数组，但**逐物品**按其类型选定更新方式：完全物品正序、01 物品倒序（相当于件数为 $1$ 的多重）、多重物品做二进制拆分后倒序。这里用件数字段 $-1$ / $0$ / 正数 作类型标记；每一类的循环方向必须在处理该物品时就地确定，不能全局统一，否则完全与 01 会互相污染。

```cpp
vector<int> mixedPack(int m, const vector<array<int, 3>> &a)
{
    // m 是容量；a[i] 是体积、价值、件数，件数 -1/0/正数分别表示 01/完全/多重物品。
    // 调试检查，可删。
    assert(m >= 0);
    vector<int> f(m + 1, -INF);
    f[0] = 0;
    for (auto [w, v, c] : a)
    {
        // 调试检查，可删。
        assert(w > 0 && c >= -1);
        if (c == 0)
        {
            for (int j = w; j <= m; j++)
            {
                if (f[j - w] != -INF)
                {
                    chmax(f[j], f[j - w] + v);
                }
            }
            continue;
        }
        if (c == -1)
        {
            c = 1;
        }
        int k = 1;
        while (c > 0)
        {
            int z = min(k, c);
            c -= z;
            if (z <= m / w)
            {
                int ww = w * z;
                int vv = v * z;
                for (int j = m; j >= ww; j--)
                {
                    if (f[j - ww] != -INF)
                    {
                        chmax(f[j], f[j - ww] + vv);
                    }
                }
            }
            if (c > 0)
            {
                k = k <= c / 2 ? k * 2 : c;
            }
        }
    }
    return f;
}
```

调用 `mixedPack(m,a)`，第三维为 `-1`、`0`、正数分别表示 01、完全、多重物品。最坏时间 $O(m\sum_i\log(c_i+1))$、空间 $O(m)$，其中完全物品每种只花 $O(m)$。若全部物品同类，直接用对应的 [12.1.001](#121001) / [12.1.002](#121002) / [12.1.003](#121003) 更清晰；组内互斥仍须 [12.1.006 分组背包](#121006)，本函数不处理分组语义。

### 12.1.005 二维费用背包

二维费用背包每件物品同时消耗两种资源、只可选一次，状态升为 $f[x][y]$——恰好用掉第一维费用 $x$、第二维费用 $y$ 时的最大价值，转移 $f[x][y]\leftarrow\max(f[x][y],\,f[x-a][y-b]+v)$。它就是把 01 背包的倒序思想推到两维：两层容量都必须倒序，才能保证同一件物品在本轮至多被计入一次。函数最后遍历整张表取最大值，得到"两维都不超上限"的答案。

```cpp
int knapsack2(int cap1, int cap2, const vector<array<int, 3>> &a)
{
    // cap1、cap2 是两维容量；a[i][0..2] 依次是第一费用、第二费用、价值；返回不超容量的最大总价值。
    // 调试检查，可删。
    assert(cap1 >= 0 && cap2 >= 0);
    vector f(cap1 + 1, vector<int>(cap2 + 1, -INF));
    f[0][0] = 0;
    for (auto [x, y, v] : a)
    {
        // 调试检查，可删。
        assert(x >= 0 && y >= 0 && (x > 0 || y > 0));
        for (int i = cap1; i >= x; i--)
        {
            for (int j = cap2; j >= y; j--)
            {
                if (f[i - x][j - y] != -INF)
                {
                    chmax(f[i][j], f[i - x][j - y] + v);
                }
            }
        }
    }
    int ans = 0;
    for (const auto &row : f)
    {
        for (int x : row)
        {
            chmax(ans, x);
        }
    }
    return ans;
}
```

调用 `knapsack2(cap1,cap2,a)`，每个 `array<int,3>` 的三维依次是第一费用、第二费用、价值，返回允许两维都有剩余时的最大价值。时间 $O(nAB)$、空间 $O(AB)$，其中 $n$ 为物品数、$A,B$ 为两维容量上限。一个样例：两维容量 $(4,5)$、物品 `{(2,3,6),(2,2,5),(3,2,7)}`，答案为 $11$。这是普通 01 背包 [12.1.001](#121001) 的直接推广，费用维数继续增加时按同样的倒序方式再加层即可，但空间随维数指数增长；它与依赖背包 [12.1.007](#121007)、子集和 [12.1.010](#121010) 是不同问题，不要混用。

### 12.1.006 分组背包

分组背包要求每组至多选一件。诀窍是每组开始前先把当前 $f$ 快照成 `h`，组内每件物品都只从**旧数组** `f` 转移、写进新数组 `h`，处理完整组再 `swap`。这样组内任何两件都来自同一份进组前状态，天然互斥；若图省事在同一数组里连续更新，本组前一件的结果会喂给后一件，导致同组多件被同时选中。允许整组不选，因为初始的 `h=f` 已保留"不选本组"的状态。

```cpp
vector<int> groupPack(int m, const vector<vector<pair<int, int>>> &a)
{
    // m 是容量，a[i] 是第 i 组全部“体积、价值”物品；每组至多选一件，返回各恰好容量最大价值。
    // 调试检查，可删。
    assert(m >= 0);
    vector<int> f(m + 1, -INF);
    f[0] = 0;
    for (auto &g : a)
    {
        auto h = f;
        for (auto [w, v] : g)
        {
            // 调试检查，可删。
            assert(w > 0);
            for (int j = w; j <= m; j++)
            {
                if (f[j - w] != -INF)
                {
                    chmax(h[j], f[j - w] + v);
                }
            }
        }
        f.swap(h);
    }
    return f;
}
```

调用 `groupPack(m,a)`，外层每个 `a[i]` 是一组 (体积, 价值) 物品，返回各恰好容量的最大价值，允许整组不选。时间 $O(m\sum_i|G_i|)$、空间 $O(m)$。当每组只有一件时它退化成 01 背包 [12.1.001](#121001)；若组之间还存在"选子必选父"的层级约束，分组模型无法表达，须改用 [12.1.007 有依赖背包](#121007)。

### 12.1.007 有依赖背包

有依赖背包（金明的预算方案型）中物品构成父子依赖森林：选任何非根物品前必须先选它的父物品。树形 DP 用一个虚根 `rt` 把所有依赖树根挂在一起；真实节点只有在自身已选的状态上才能合并非空儿子状态，从而不会出现“没选父亲却选了后代”。完整实现统一放在 [6.5.004 树上依赖背包](06-树论与动态树.md#65004)，本条只复用该接口，不再维护第二份同义代码；同步头 `include/full/12_1_007.hpp` 也只转发 `6_5_004.hpp`。

`treeDepPack` 的接口为 `template<class Acc = long long> vector<optional<Acc>> treeDepPack(const vector<int> &w, const vector<Acc> &val, const vector<int> &par, int cap)`：`w[u]` 是正体积，`val[u]` 是价值，`par[u]` 是父节点编号，依赖树根用 `-1` 表示，`par` 必须构成森林，且 `cap >= 0`。返回长度为 `cap + 1` 的数组，其中第 `c` 项是恰好占用容量 `c` 且满足全部父子依赖的最大价值；不可达容量为 `nullopt`。求容量不超过 `cap` 的答案时只在有值的元素中取最大值。默认累计类型是 `long long`；当价值和可能超出 64 位时，显式传入 `treeDepPack<__int128>` 和 `vector<__int128>`。所有可达状态及其加法中间结果必须能由 `Acc` 表示。

```cpp
vector<__int128> val{3, 5, 8};
auto f = treeDepPack<__int128>(vector<int>{2, 2, 3}, val,
                               vector<int>{-1, 0, 0}, 5);
assert(f[5] && *f[5] == 11);
```

合并儿子的 max-plus 卷积保守时间为 $O(nC^2)$、额外空间为 $O(nC)$，其中 $n$ 是物品数、$C=cap$；依赖链的递归深度为 $O(n)$，实际可承受深度取决于评测环境的线程栈。样例中体积 `{2,2,3}`、价值 `{3,5,8}`、父节点 `{-1,0,0}`、容量 $5$ 时最大值为 `11`（选点 `0` 与 `2`）。没有父子依赖时用 [12.1.001 01 背包](#121001)；只有组内至多选一时用 [12.1.006 分组背包](#121006)；树边只表示合并顺序、并不限制是否选父节点时用 [12.1.009 树上背包及单调队列优化](#121009)。

### 12.1.008 背包方案数与具体方案

这条在求 01 背包最优值的同时统计**最优方案数**并恢复**一组具体方案**。方案数是把最优值 DP 里的 `max` 换成"当价值相等时累加方案数"：`f[j]` 被严格刷新则方案数继承 `cnt[j-w]`，与旧值打平则 `cnt[j]+=cnt[j-w]`，对 `mod` 取模。方案恢复靠一条前驱链——每次严格刷新 `f[j]` 时把 (物品下标, 上一状态在 `path` 中的位置) 压进 `path`、并让 `at[j]` 指向它，最后从最优容量沿 `prev` 回溯即得被选物品序列。注意方案计数按物品编号区分、天然是"组合"意义（每件物品处理一次），若要"排列"数需改变枚举顺序。

```cpp
struct PackResult
{
    // val 是不超过容量时的最优总价值。
    long long val;
    // ways 是模 mod 的最优方案数。
    int ways;
    // pick 是恢复出的一组物品下标，按输入顺序排列。
    vector<int> pick;
};

PackResult packPlan(int cap, const vector<pair<int, long long>> &a, int mod = 1000000007)
{
    // cap 是容量上限，a 是各 01 物品的体积与价值，mod 是计数模数；返回最优价值、方案数及一组方案。
    struct Path
    {
        // item 是本步选择的物品下标，pre 是上一步前驱节点编号。
        int item;
        int pre;
    };
    // 调试检查，可删。
    assert(cap >= 0 && mod > 0);
    int n = a.size();
    vector<long long> f(cap + 1, -INF);
    vector<int> cnt(cap + 1), at(cap + 1, -1);
    vector<Path> path;
    f[0] = 0;
    cnt[0] = 1;
    for (int i = 0; i < n; i++)
    {
        auto [w, v] = a[i];
        // 调试检查，可删。
        assert(w > 0);
        for (int j = cap; j >= w; j--)
        {
            if (f[j - w] == -INF)
            {
                continue;
            }
            long long x = f[j - w] + v;
            if (x > f[j])
            {
                f[j] = x;
                cnt[j] = cnt[j - w];
                path.push_back({i, at[j - w]});
                at[j] = path.size() - 1;
            }
            else if (x == f[j] && x > -INF)
            {
                cnt[j] = addMod(cnt[j], cnt[j - w], mod);
            }
        }
    }
    long long val = *max_element(f.begin(), f.end());
    int ways = 0;
    int last = -1;
    for (int j = 0; j <= cap; j++)
    {
        if (f[j] == val)
        {
            ways = addMod(ways, cnt[j], mod);
            last = at[j];
        }
    }
    vector<int> pick;
    while (last >= 0)
    {
        pick.push_back(path[last].item);
        last = path[last].pre;
    }
    reverse(pick.begin(), pick.end());
    return {val, ways, pick};
}
```

调用 `packPlan(cap,a,mod)`，容量非负、体积为正、模数为正，`a` 每项是 (体积, 价值)；返回 `PackResult{val,ways,pick}`，分别是最优价值、模 `mod` 的最优方案数和一组按输入顺序排列的物品下标。时间 $O(nC)$；状态数组占 $O(C)$，持久前驱节点最坏占 $O(nC)$。只要最优值不需要方案信息时直接用 [12.1.001 01 背包](#121001) 更省内存；要把恢复空间严格压到 $O(C)$，可分治重算转移，而不能继续永久保存每次刷新。

### 12.1.009 树上背包及单调队列优化

这条给出树上背包中一个可被单调队列优化的清晰模型：每个树节点挂一类**有件数上限**的物品，先在本点线性完成这类多重背包，再把子树答案卷积合并上来。多重背包的单调队列优化按体积余数 $r$ 把容量分成若干链 $r,r+w,r+2w,\dots$，在每条链上件数上限就化成滑动窗口长度：维护 `pre[x]-j*v`（旧价值减去到当前格所需件数的线性代价）的窗口最大值，窗口宽度即件数上限 $cnt$，于是本点转移降到 $O(C)$。子树之间仍是普通 max-plus 卷积。注意本函数的树边只决定合并顺序，不表示父子选取依赖，这与 [12.1.007](#121007) 不同。

```cpp
template <class Acc = long long>
vector<optional<Acc>> treePack(const vector<vector<int>> &g,
                                      const vector<array<long long, 3>> &a,
                                      int root,
                                      int cap)
{
    // a[u] 是 {体积,价值,件数}；返回恰用各容量的最大价值，nullopt 表示不可达。
    int n = g.size();
    assert(n > 0 && (int)a.size() == n && 0 <= root && root < n && cap >= 0); // 调试检查，可删
    auto dfs = [&](auto &&self, int u, int p) -> vector<optional<Acc>>
    {
        int w = a[u][0];
        Acc v = (Acc)a[u][1];
        int cnt = a[u][2];
        assert(w > 0 && cnt >= 0); // 调试检查，可删
        vector<optional<Acc>> pre(cap + 1), f(cap + 1);
        pre[0] = (Acc)0;
        for (int r = 0; r < w && r <= cap; r++)
        {
            deque<int> q;
            for (int j = 0, x = r; x <= cap; j++, x += w)
            {
                while (!q.empty() && q.front() < j - cnt)
                {
                    q.pop_front();
                }
                if (pre[x])
                {
                    Acc cur = *pre[x] - (Acc)j * v;
                    while (!q.empty())
                    {
                        int y = r + q.back() * w;
                        Acc old = *pre[y] - (Acc)q.back() * v;
                        if (old > cur)
                        {
                            break;
                        }
                        q.pop_back();
                    }
                    q.push_back(j);
                }
                if (!q.empty())
                {
                    int y = r + q.front() * w;
                    f[x] = *pre[y] + (Acc)(j - q.front()) * v;
                }
            }
        }
        for (int x : g[u])
        {
            if (x == p)
            {
                continue;
            }
            auto h = self(self, x, u);
            auto nf = f;
            for (int i = 0; i <= cap; i++)
            {
                for (int j = 1; i + j <= cap; j++)
                {
                    if (f[i] && h[j])
                    {
                        Acc cur = *f[i] + *h[j];
                        if (!nf[i + j] || *nf[i + j] < cur)
                        {
                            nf[i + j] = cur;
                        }
                    }
                }
            }
            f.swap(nf);
        }
        return f;
    };
    return dfs(dfs, root, -1);
}
```

调用 `treePack(g,a,root,cap)`，`g` 必须是覆盖全部点的非空无向树，`a[u][0..2]` 是点 $u$ 的物品体积、价值、件数上限；返回的 `f[c]` 是恰用容量 $c$ 的最大价值，`nullopt` 表示不可达。默认状态、队列评分与卷积和都用 `long long`，必须保证这些中间值可表示；需要宽范围时调用 `treePack<__int128>`。单点树、物品 `{2,3,3}`、容量 $7$ 时，容量 $0,2,4,6$ 的答案为 $0,3,6,9$。保守时间 $O(nC^2)$、额外空间 $O(nC)$；链形树的递归深度为 $O(n)$，实际可承受深度取决于评测环境的线程栈。单节点的有界物品步骤是 $O(C)$。非树上的单个多重背包用 [12.1.003 多重背包](#121003)，单调队列原理见 [12.3.001 单调队列优化](#123001)。

### 12.1.010 布尔母函数 / 有界子集和可达性

有界子集和判定问题：每种权值 $w_i$ 最多用 $cnt_i$ 次，问某个目标和是否可达。二进制拆分能做，但这里用一个更巧的 $O(kS)$ 布尔母函数：`rem[s]` 记录"和 $s$ 可达时，当前这种权值还剩几次可用"。处理权值 $w_i$ 时正序扫 $s$——若 $s$ 在上一轮已可达就把额度重置为 $cnt_i$（本轮一次没用）；否则若 $s-w_i$ 可达且那里还有剩余次数，就从它继承并消耗一次（`rem[s]=rem[s-w_i]-1`），两者都不满足则 $s$ 不可达置 $-1$。这样无需拆分就限制了每种的使用次数。

```cpp
bool boundSubset(const vector<int> &cnt, const vector<int> &w, int sum)
{
    // cnt、w 分别是每类物品数量和正权值，sum 是目标和；返回目标是否可达。
    // 调试检查，可删。
    assert(cnt.size() == w.size() && sum >= 0);
    for (int i = 0; i < (int)w.size(); i++)
    {
        // 调试检查，可删。
        assert(cnt[i] >= 0 && w[i] > 0);
    }
    vector<int> rem(sum + 1, -1);
    rem[0] = 0;
    for (int i = 0; i < (int)w.size(); i++)
    {
        for (int s = 0; s <= sum; s++)
        {
            if (rem[s] >= 0)
            {
                rem[s] = cnt[i];
            }
            else if (s < w[i] || rem[s - w[i]] <= 0)
            {
                rem[s] = -1;
            }
            else
            {
                rem[s] = rem[s - w[i]] - 1;
            }
        }
    }
    return rem[sum] >= 0;
}
```

调用 `boundSubset(cnt,w,sum)`，`cnt[i]`、`w[i]` 分别是第 $i$ 种物品的非负数量与正权值、下标一一对应，`sum` 是目标和，返回布尔是否可达（原调用说明误写成 `array<int,2>` 输入与"可达表"返回，与函数签名不符，已按实际签名更正）。时间 $O(kS)$、空间 $O(S)$，$k$ 为种类数、$S$ 为目标和。只判可达性而不限件数时，用 [12.2.008 子集和 Bitset 优化](#122008) 的按字并行更快；需要方案数或最优价值则退回普通 [12.1.003 多重背包](#121003)。

## 12.2 常见 DP

### 12.2.001 数位 DP

数位 DP 从高位到低位扫描整数、统计 $[0,n]$ 中满足数位约束的个数。这份实现把"约束"抽象成一个自动机：调用者提供状态转移 `next(q,d,ns)` 和终态判定 `accept(q,st)`，本体只负责管理两个通用维度——`lim`（是否仍贴着上界 $n$，贴界时最高位只能枚举到 $n$ 的对应位）和 `st`（是否已经填过非零位，即是否走出前导零）。每读一位，就对 $(\text{lim},\text{st},q)$ 的计数向 $(\text{nl},\text{ns},\text{nq})$ 分摊。前导零必须靠 `st` 单独标记而不能当普通的数字 $0$，否则形如"数位递增""无前导零段"这类约束会算错；`lim` 维度保证不会数超过 $n$。

```cpp
template<class Next, class Accept>
unsigned long long digitDP(long long n, int m, int s, Next next, Accept accept)
{
    // n 是区间右端点，m 是状态数，s 是初态；next 转移状态，accept 判定终态；返回被接受的整数个数。
    if (n < 0)
    {
        return 0;
    }
    // 调试检查，可删。
    assert(m > 0 && 0 <= s && s < m);
    string a = to_string(n);
    vector dp(2, vector(2, vector<unsigned long long>(m)));
    dp[1][0][s] = 1;
    for (char c : a)
    {
        vector ndp(2, vector(2, vector<unsigned long long>(m)));
        for (int lim = 0; lim < 2; lim++)
        {
            for (int st = 0; st < 2; st++)
            {
                for (int q = 0; q < m; q++)
                {
                    for (int d = 0; d <= (lim ? c - '0' : 9); d++)
                    {
                        int nl = lim && d == c - '0';
                        int ns = st || d;
                        int nq = next(q, d, ns);
                        // 调试检查，可删。
                        assert(0 <= nq && nq < m);
                        ndp[nl][ns][nq] += dp[lim][st][q];
                    }
                }
            }
        }
        dp.swap(ndp);
    }
    unsigned long long ans = 0;
    for (int lim = 0; lim < 2; lim++)
    {
        for (int st = 0; st < 2; st++)
        {
            for (int q = 0; q < m; q++)
            {
                if (accept(q, st))
                {
                    ans += dp[lim][st][q];
                }
            }
        }
    }
    return ans;
}
```

调用 `digitDP(n,m,s,next,accept)`：`n` 是区间右端点（$n<0$ 返回 $0$），`m` 是正状态数，`s` 是初态；`next(q,d,ns)` 返回合法新状态，`accept(q,st)` 判断终态，其中 `ns`、`st` 表示是否已经读入非零位。返回类型能表示 $[0,2^{63}-1]$ 的全部 $2^{63}$ 个整数；求 $[l,r]$ 用两次调用之差。时间 $O(10m\log n)$、空间 $O(m)$。集合状态压缩用 [12.2.002 状压 DP](#122002)，棋盘轮廓局部转移用 [12.2.011 插头 DP](#122011)。

下面固定检查“不含数字 $4$”和数字 $0$ 的 `st` 语义：

```cpp
signed main()
{
    auto nextf = [](int q, int d, int ns)
    {
        // q 是当前状态，d 是本位数字，ns 表示读入后是否已开始；返回新状态。
        (void)ns;
        return q == 1 || d == 4;
    };
    auto no4 = [](int q, int st)
    {
        // q 是终态，st 表示是否已开始；返回该整数是否不含数字 4。
        (void)st;
        return q == 0;
    };
    assert(digitDP(49, 2, 0, nextf, no4) == 36);
    auto same = [](int q, int d, int ns)
    {
        // 这个单状态自动机不改变状态。
        (void)d;
        (void)ns;
        return q;
    };
    auto started = [](int q, int st)
    {
        // 只接受已经读入非零位的整数，因此排除数字 0。
        (void)q;
        return st;
    };
    assert(digitDP(0, 1, 0, same, started) == 0);
    auto all = [](int q, int st)
    {
        // 接受所有终态，包括始终未开始的数字 0。
        (void)q;
        (void)st;
        return true;
    };
    assert(digitDP(numeric_limits<long long>::max(), 1, 0, same, all)
           == (1ULL << 63));
    cout << "OK\n";
}
```

### 12.2.002 状压 DP

状压 DP 把"规模较小的集合中哪些元素已用"编码成位掩码，适合旅行商、集合划分、匹配这类未来只依赖已选集合而非顺序的问题。下例是最经典的旅行商：$dp[s][u]$ 表示已访问集合恰为 $s$、当前停在 $u$ 的最小费用，转移枚举下一个未访问点 $v$：$dp[s\,|\,2^v][v]\leftarrow dp[s][u]+w[u][v]$，最后在全集上加回到起点 $0$ 的边取最小。$n\le22$ 时状态数 $2^n n$ 尚可承受；复杂度必须按实际枚举的状态数与转移数算，不能笼统写成 $2^n$。

```cpp
// 知识点 12.2.002：旅行商状态压缩 DP。
namespace bitmask_dp
{
int tsp(const vector<vector<int>> &w)
{
    // w 是完整有向图权值方阵；返回从 0 出发访问所有点并回到 0 的最小费用。
    int n = w.size();
    // 调试检查，可删。
    assert(1 <= n && n <= 22);
    for (auto &row : w)
    {
        // 调试检查，可删。
        assert((int)row.size() == n);
    }
    if (n == 1)
    {
        return 0;
    }
    vector<vector<int>> dp(1LL << n, vector<int>(n));
    vector<vector<char>> ok(1LL << n, vector<char>(n));
    dp[1][0] = 0;
    ok[1][0] = true;
    for (int s = 1; s < (1LL << n); s++)
    {
        for (int u = 0; u < n; u++)
        {
            if (!(s >> u & 1) || !ok[s][u])
            {
                continue;
            }
            for (int v = 0; v < n; v++)
            {
                if (s >> v & 1)
                {
                    continue;
                }
                int ns = s | 1LL << v;
                int nd = dp[s][u] + w[u][v];
                if (!ok[ns][v] || nd < dp[ns][v])
                {
                    dp[ns][v] = nd;
                    ok[ns][v] = true;
                }
            }
        }
    }
    int ans = 0;
    bool found = false;
    for (int u = 0; u < n; u++)
    {
        if (ok.back()[u])
        {
            int cur = dp.back()[u] + w[u][0];
            if (!found || cur < ans)
            {
                ans = cur;
                found = true;
            }
        }
    }
    return ans;
}
}
```

调用 `bitmask_dp::tsp(w)`，`w` 是 $1\le n\le22$ 的完整有向图权值方阵，所有路径费用须能由 `int` 表示；返回从 $0$ 出发遍历所有点再回到 $0$ 的最小费用，单点图返回 $0$，不读取自环权值。时间 $O(2^n n^2)$、空间 $O(2^n n)$。集合划分可在此框架上改成枚举子集；整数各位约束用 [12.2.001 数位 DP](#122001)，只判子集和可达性时用 [12.2.008 子集和 Bitset 优化](#122008)。

### 12.2.003 棋盘分割

棋盘分割把矩形棋盘沿格线递归切成 $k$ 个子矩形，最小化各块元素和的平方和。状态是当前子矩形四条边界与块数，转移枚举最后一刀及两侧块数分配；$k=1$ 时代价是整块和的平方。记忆值用 `optional` 区分不可达状态，不拿某个可能被合法答案达到的整数充当无穷大。

```cpp
// 知识点 12.2.003：矩形棋盘切成 k 块的最小平方和。
namespace board_part
{
template <class Acc = long long>
Acc splitBoard(const vector<vector<int>> &a, int parts)
{
    // a 是非空棋盘，parts 是块数；返回最小平方和。
    static_assert(numeric_limits<Acc>::is_integer && numeric_limits<Acc>::is_signed &&
                  sizeof(Acc) >= sizeof(long long));
    // 调试检查，可删。
    assert(!a.empty() && !a[0].empty());
    int n = a.size();
    int m = a[0].size();
    // 调试检查，可删。
    assert(1 <= parts && parts <= n * m);
    vector<vector<Acc>> s(n + 1, vector<Acc>(m + 1));
    for (int i = 0; i < n; i++)
    {
        // 调试检查，可删。
        assert((int)a[i].size() == m);
        for (int j = 0; j < m; j++)
        {
            s[i + 1][j + 1] = s[i][j + 1] + s[i + 1][j] - s[i][j] + a[i][j];
        }
    }
    auto sum = [&](int x1, int y1, int x2, int y2)
    {
        // 四个参数定义半开子矩形；返回元素和。
        return s[x2][y2] - s[x1][y2] - s[x2][y1] + s[x1][y1];
    };
    // Key[0..4] 依次是上、左、下、右边界与块数。
    using Key = array<int, 5>;
    map<Key, optional<Acc>> memo;
    auto dfs = [&](auto &&self, int x1, int y1, int x2, int y2, int k) -> optional<Acc>
    {
        // self 是递归自身，四坐标定义矩形，k 是块数；返回最小平方和。
        Key key{x1, y1, x2, y2, k};
        if (auto it = memo.find(key); it != memo.end())
        {
            return it->second;
        }
        if (k == 1)
        {
            Acc x = sum(x1, y1, x2, y2);
            return memo[key] = x * x;
        }
        if (k > (x2 - x1) * (y2 - y1))
        {
            return memo[key] = nullopt;
        }
        optional<Acc> ans;
        for (int x = x1 + 1; x < x2; x++)
        {
            for (int p = 1; p < k; p++)
            {
                auto l = self(self, x1, y1, x, y2, p);
                auto r = self(self, x, y1, x2, y2, k - p);
                if (l && r && (!ans || *l + *r < *ans))
                {
                    ans = *l + *r;
                }
            }
        }
        for (int y = y1 + 1; y < y2; y++)
        {
            for (int p = 1; p < k; p++)
            {
                auto l = self(self, x1, y1, x2, y, p);
                auto r = self(self, x1, y, x2, y2, k - p);
                if (l && r && (!ans || *l + *r < *ans))
                {
                    ans = *l + *r;
                }
            }
        }
        return memo[key] = ans;
    };
    return *dfs(dfs, 0, 0, n, m, parts);
}
}
```

`splitBoard(a,parts)` 返回合法切分的最小平方和；需要宽累计时调用 `splitBoard<__int128>`。调用者须保证二维前缀和、任意区域和的平方及候选代价之和都能由 `Acc` 表示。内部 `optional` 只区分某个子矩形无法切出指定块数的状态，不暴露到公开接口。状态数 $O(n^2m^2k)$，最坏时间 $O(n^3m^2k^2+n^2m^3k^2)$，空间 $O(n^2m^2k+nm)$。

### 12.2.004 两台机器工作调度

两台相同机器并行做一批独立任务、最小化完工时间（makespan），本质是把总工时尽量对半分：设一台机器的负载为 $s$，另一台就是 $\text{sum}-s$，完工时间是二者较大者 $\max(s,\text{sum}-s)$，$s$ 越接近 $\text{sum}/2$ 越优。于是问题化成"哪些负载 $s$ 可由任务子集凑出"的 01 子集和可达性 DP，`dp[s]` 用布尔标记，最后在所有可达 $s$ 上取 $\max(s,\text{sum}-s)$ 的最小值。

```cpp
// 知识点 12.2.004：独立任务分配给两台机器的最短完工时间。
namespace twoMachSched
{
int twoMachines(const vector<int> &a)
{
    // a 是各任务的非负耗时；返回两台相同机器并行完成全部任务的最小 makespan。
    __int128 total = 0;
    for (int x : a)
    {
        // 调试检查，可删。
        assert(x >= 0);
        total += x;
    }
    // 本算法按总耗时分配数组，故总耗时还必须能作为容器下标。
    // 调试检查，可删。
    assert(total <= numeric_limits<int>::max()
           && total < (__int128)numeric_limits<size_t>::max());
    int sum = (int)total;
    vector<char> dp(sum + 1);
    dp[0] = 1;
    for (int x : a)
    {
        for (int s = sum; s >= x; s--)
        {
            dp[s] |= dp[s - x];
        }
    }
    int ans = sum;
    for (int s = 0; s <= sum; s++)
    {
        if (dp[s])
        {
            ans = min(ans, max(s, sum - s));
        }
    }
    return ans;
}
}
```

调用 `twoMachSched::twoMachines(a)`，`a` 是各任务的非负耗时，返回两台相同机器并行的最小 makespan。时间 $O(nS)$、空间 $O(S)$，$S$ 为总耗时。子集和可达性判定本身可用 [12.2.008 子集和 Bitset 优化](#122008) 把常数压到 $1/64$；机器数超过两台时对半分不再成立，得转多维背包或状压。

### 12.2.005 找硬币问题

找硬币问题的关键是先分清模型：硬币是否可重复、顺序是否计入、要最少枚数还是方案数或只判可达，三者的初值与合并运算各不相同。下例是最常见的一种——面值无限、顺序无关，同时求最少枚数与无序方案数：外层枚举面值、内层容量**正序**（完全背包语义，一种面值可反复用），`best[s]=\min(best[s],best[s-x]+1)` 取最少枚数、`ways[s]+=ways[s-x]` 累加方案数。外层枚举面值而非金额，保证每种组合只按面值升序统计一次，得到的是无序方案数（若把两层循环对调则统计有序序列数）。

```cpp
// 知识点 12.2.005：完全背包找硬币的最少枚数与方案数。
namespace coin_problem
{
array<int, 2> coinChange(const vector<int> &coin, int target, int mod)
{
    // coin 是不同正面值，target 是目标金额，mod 是方案数模数；返回最少枚数和无序方案数，无解时第一维为 -1。
    // 调试检查，可删。
    assert(target >= 0 && mod > 0);
    set<int> seen;
    for (int x : coin)
    {
        // 调试检查，可删。
        assert(x > 0 && seen.insert(x).second);
    }
    const int inf = numeric_limits<int>::max() / 4;
    vector<int> best(target + 1, inf);
    vector<int> ways(target + 1);
    best[0] = 0;
    ways[0] = 1;
    for (int x : coin)
    {
        for (int s = x; s <= target; s++)
        {
            if (best[s - x] != inf)
            {
                best[s] = min(best[s], best[s - x] + 1);
            }
            ways[s] = addMod(ways[s], ways[s - x], mod);
        }
    }
    return {best[target] == inf ? -1 : best[target], ways[target]};
}
}
```

调用 `coin_problem::coinChange(coin,target,mod)`，`coin` 是不同正面值、`target` 是目标金额、`mod` 是方案数模数，返回 `{最少枚数, 无序方案数}`，无解时第一维为 $-1$。时间 $O(kS)$、空间 $O(S)$，$k$ 为面值数、$S$ 为金额。硬币有件数上限时正序不再成立，改用 [12.1.003 多重背包](#121003) 的二进制拆分或 [12.1.010](#121010) 的剩余次数 DP；只关心某金额能否凑出用 [12.2.008 子集和 Bitset 优化](#122008)。

### 12.2.006 汉诺塔

经典三柱汉诺塔的解是递归的："移 $n$ 个盘 = 先把上 $n-1$ 个移到辅助柱，再移最大盘，再把 $n-1$ 个移回"，总步数 $2^n-1$。本条不做递归模拟，而是 $O(1)$ 回答"第 $k$ 步移哪个盘、从哪到哪"：观察到第 $k$ 步移动的盘号等于 $k$ 二进制末尾零的个数加一（`countr_zero(k)+1`），因为盘 $i$ 每 $2^i$ 步动一次；而某个盘每次移动的方向固定（由 $n-\text{disk}$ 的奇偶决定顺时针或逆时针），出现次数 `before` 决定它当前在哪根柱上。多柱（Frame–Stewart）版本步数不再是 $2^n-1$，该公式不适用。

```cpp
// 知识点 12.2.006：汉诺塔第 k 步移动。
namespace hanoi
{
array<int, 3> kthMove(int n, unsigned long long k)
{
    // n 是盘数，k 从 1 开始且不超过 2^n-1；返回盘号、起始柱和目标柱，柱编号为 0..2。
    // 调试检查，可删。
    assert(1 <= n && n < 64 && 1 <= k && k < (1ULL << n));
    int disk = countr_zero(k) + 1;
    unsigned long long before = (k >> disk) + 1;
    int dir = ((n - disk) & 1) ? 1 : -1;
    int from = (dir * (int)(before - 1) % 3 + 3) % 3;
    int to = (from + dir + 3) % 3;
    return {disk, from, to};
}
}
```

调用 `hanoi::kthMove(n,k)`，$n$ 是盘数（$1\le n<64$）、$k$ 从 $1$ 开始且不超过 $2^n-1$，返回 `{盘号, 起始柱, 目标柱}`，柱编号 $0\dots2$。时间与空间 $O(1)$。要输出整段移动序列时逐 $k$ 调用即得，总输出量 $2^n-1$ 是指数级、复杂度须按输出规模计而非递归层数；多柱最优步数问题不在此列。

### 12.2.007 最长上升/公共子序列

最长上升子序列（LIS）与最长公共子序列（LCS）状态和复杂度不同。LIS 维护“长度为 $k+1$ 的上升子序列的最小末值” `tail[k]`，对每个元素用 `lower_bound` 找到应替换的位置；`at[k]` 记录该末值来自哪个下标，`pre[i]` 记录方案前驱，从最后一个末值即可恢复一条严格 LIS。LCS 是两序列前缀 DP，其完整实现统一放在 [4.5.001 最长公共子序列](#45001)，本条不再复制。

```cpp
template<class T>
vector<T> lis(const vector<T> &a)
{
    // a 是输入序列；返回一条严格最长上升子序列。
    int n = a.size();
    vector<T> tail;
    vector<int> at;
    vector<int> pre(n, -1);
    for (int i = 0; i < n; i++)
    {
        int k = lower_bound(tail.begin(), tail.end(), a[i]) - tail.begin();
        if (k > 0)
        {
            pre[i] = at[k - 1];
        }
        if (k == (int)tail.size())
        {
            tail.push_back(a[i]);
            at.push_back(i);
        }
        else
        {
            tail[k] = a[i];
            at[k] = i;
        }
    }
    if (at.empty())
    {
        return {};
    }
    vector<T> ans;
    for (int x = at.back(); x != -1; x = pre[x])
    {
        ans.push_back(a[x]);
    }
    reverse(ans.begin(), ans.end());
    return ans;
}
```

`lis(a)` 返回一条严格最长上升子序列，空输入返回空序列；把 `lower_bound` 改成 `upper_bound` 可求最长不下降子序列。时间 $O(n\log n)$、额外空间 $O(n)$。普通 LCS、Bitset LCS 和 SCS 使用 [4.5.001 最长公共子序列](#45001) 的 `lcs`、`lcsBitset` 与 `scs`，不要在本章复制实现。

### 12.2.008 子集和 Bitset 优化

子集和可达性判定用一个位集表示"哪些和可达"，加入体积 $w$ 时执行 `bits |= bits << w`——第 $s$ 位为 $1$ 表示和 $s$ 可达，左移 $w$ 位再或回去，就等价于"每个原可达和再加一件 $w$"。这样把布尔 DP 的每字 $64$ 个状态并行处理，常数降到 $1/64$。`SubsetSum` 手写了跨 `unsigned long long` 字的移位（`q=w>>6` 是整字偏移、`r=w&63` 是字内偏移，跨字时补上前一字被移出的高位），并在每次 `add` 后把超过上限 $n$ 的高位掩掉。注意这条 `bits |= bits<<w` 是 **01 物品**语义（每次调用只加一件）；完全背包那种"同一件反复取"不能靠单次移位表达，需在字内做前缀 or。

```cpp
struct SubsetSum
{
    // n 是维护的最大子集和。
    int n;
    // a 的第 i 位表示子集和 i 当前是否可达。
    vector<unsigned long long> a;

    static size_t words(int n)
    {
        // n 是最大子集和；返回位集所需的机器字数。
        // 调试检查，可删。
        assert(n >= 0);
        return (size_t)(n / 64 + 1);
    }

    SubsetSum(int n) : n(n), a(words(n))
    {
        // n 是维护的最大子集和；初始时只有和 0 可达。
        a[0] = 1;
    }

    void add(int x)
    {
        // x 是新加入的一件 01 物品的非负重量；更新可达和。
        // 调试检查，可删。
        assert(x >= 0);
        int q = x >> 6, r = x & 63;
        for (int i = (int)a.size() - 1; i >= q; i--)
        {
            unsigned long long z = a[i - q] << r;
            if (r && i > q)
            {
                z |= a[i - q - 1] >> (64 - r);
            }
            a[i] |= z;
        }
        if ((n & 63) != 63)
        {
            a.back() &= (1ULL << ((n & 63) + 1)) - 1;
        }
    }

    bool has(int x) const
    {
        // 参数 x 表示 要查询是否可达的子集和；返回目标子集和 x 当前是否可达。
        return 0 <= x && x <= n && (a[x >> 6] >> (x & 63) & 1);
    }
};
```

用 `SubsetSum ss(n)` 建对象（`n` 是需维护的最大和），`ss.add(x)` 加入一件体积 $x$，`ss.has(x)` 查询和 $x$ 是否可达。加入 $k$ 件的总时间 $O\!\left(\frac{kS}{64}\right)$、空间 $O\!\left(\frac{S}{64}\right)$，$S$ 为上限。它是 [12.2.004 两台机器工作调度](#122004) 等可达性问题的加速器；需要方案数或最优价值时它不适用，回到普通 01 背包 [12.1.001](#121001)；有件数上限的可达性判定用 [12.1.010](#121010)。

下面检查跨越 $64$ 位块的移位与末字掩码：

```cpp
signed main()
{
    SubsetSum s(65);
    for (int x : {1, 63, 64})
    {
        s.add(x);
    }
    assert(s.has(0) && s.has(64) && s.has(65) && !s.has(62));
}
```

### 12.2.009 树形 DP 与动态 DP

树上最大权独立集的静态递推是 $f_{u,0}=\sum_v\max(f_{v,0},f_{v,1})$、$f_{u,1}=w_u+\sum_v f_{v,0}$，其中 $0/1$ 表示不选或选择 $u$。代码用递归 lambda 在回溯时合并子树状态；链形树的递归深度为 $O(n)$，实际可承受深度取决于评测环境的线程栈。支持单点修改的动态版本要把重链转移写成 max-plus 矩阵并维护矩阵积，完整实现见 [6.4.005 动态 DP](#64005)，本章不重复打印其 `GlobalTree` 底层。

```cpp
template <class Acc = long long>
Acc treeMWIS(const vector<vector<int>> &g, const vector<Acc> &w, int root = 0)
{
    // g 是无向树，w 是点权，root 是根；返回允许空集的最大权独立集权值。
    int n = g.size();
    // 调试检查，可删。
    assert((int)w.size() == n);
    if (n == 0)
    {
        return 0;
    }
    // 调试检查，可删。
    assert(0 <= root && root < n);
    int deg = 0;
    for (int u = 0; u < n; u++)
    {
        deg += g[u].size();
        for (int v : g[u])
        {
            // 调试检查，可删。
            assert(0 <= v && v < n);
        }
    }
    // 调试检查，可删。
    assert(deg == 2 * (n - 1));
    vector<int> par(n, -2);
    int seen = 0;
    auto dfs = [&](auto &&self, int u, int p) -> array<Acc, 2>
    {
        par[u] = p;
        seen++;
        array<Acc, 2> f{0, w[u]};
        for (int v : g[u])
        {
            if (v == p)
            {
                continue;
            }
            // 调试检查，可删。
            assert(par[v] == -2);
            auto h = self(self, v, u);
            f[0] += max(h[0], h[1]);
            f[1] += h[0];
        }
        return f;
    };
    auto f = dfs(dfs, root, -1);
    // 调试检查，可删。
    assert(seen == n);
    return max(f[0], f[1]);

}
```

调用 `treeMWIS(g,w,root)` 求静态树的最大权独立集，空树返回 $0$，非空输入必须是覆盖全部点的无向树；默认点权、DP 状态与返回值均为 `long long`，必须保证所有子树状态能装入 `Acc`。需要宽答案时调用 `treeMWIS<__int128>` 并传入 `vector<__int128>` 点权。时间和额外空间均为 $O(n)$。需要修改点权时使用 [6.4.005 动态 DP](#64005) 的 `DynamicMWIS`：预处理 $O(n\log n)$、单点修改 $O(\log n)$、查询 $O(1)$。其他树形状态不能只替换矩阵元素，必须重新证明链上转移满足结合律。

### 12.2.010 不同子序列计数

统计一个序列的不同子序列数量（含空串则加一）。设 $\text{sum}$ 为"当前所有不同子序列数"（初值 $1$，代表空串），逐元素处理：加入元素 $x$ 时，理论上每个已有子序列后面接一个 $x$ 都产生新串，于是 $\text{sum}$ 翻倍；但若 $x$ 之前出现过，上次处理 $x$ 那一刻已经统计过"以 $x$ 结尾"的那批串，它们会被重复计入，须减去 $x$ 上次出现前的 $\text{sum}$。故递推 $\text{sum}\leftarrow 2\,\text{sum}-\text{last}[x]$，其中 `last[x]` 记 $x$ 上次处理前的 $\text{sum}$。全程对 `mod` 取模，减法先加 `mod` 防负。

```cpp
// 返回不同非空子序列个数，值相同的元素视为相同字符。
int distinctSub(const vector<long long> &a, int mod = 998244353)
{
    // a 是输入序列，mod 是正模数；返回不同非空子序列数量模 mod。
    // 调试检查，可删。
    assert(mod > 0);
    unordered_map<long long, int> last;
    int sum = 1 % mod;
    for (long long x : a)
    {
        int old = last[x];
        int twice = sum >= mod - sum ? sum - (mod - sum) : sum + sum;
        int next = twice - old;
        if (next < 0)
        {
            next += mod;
        }
        last[x] = sum;
        sum = next;
    }
    return sum == 0 ? mod - 1 : sum - 1;
}
```

调用 `distinctSub(a,mod)`，`a` 是输入序列（值相同即视为同字符），返回不同**非空**子序列个数模 `mod`（末尾 $-1$ 去掉空串）。期望 $O(n)$ 时间、$O(k)$ 空间，$k$ 为不同值数；用 `unordered_map` 存 `last`，哈希退化时最坏 $O(n^2)$，值域小时可换定长数组稳定到 $O(n)$。它统计的是"去重后的子序列数"，与不去重的子序列计数（直接 $2^n$）是不同问题，别混用。

### 12.2.011 插头 DP

沿棋盘扫描线（轮廓线）逐格转移，状态只保存轮廓上每个位置的**插头**——即回路/路径穿过该格线的连通信息。相邻状压 DP 只记「有无」，插头 DP 还要记**连通性**，用于铺砖、哈密顿回路、连通块构造这类要求整体连通的问题。连通性用**括号表示法**编码：轮廓上有 $m+1$ 个插头，每个取值 $\{0\text{ 无},\ 1\text{ 左括号 }(,\ 2\text{ 右括号 })\}$，同一条链的两端记成一对匹配括号，$2$ bit 一个插头压进一个整数。

下例是最经典的 URAL1519 型问题：**用一条闭合回路恰好覆盖棋盘全部空格，求方案数**。处理格 $(i,j)$ 时看它的左插头 $L=\text{plug}[j]$ 与上插头 $U=\text{plug}[j+1]$，按二者取值分情形转移（下插头写回 $\text{plug}[j]$、右插头写回 $\text{plug}[j+1]$）：

- $L=U=0$：本格是回路拐角 $\ulcorner$，新建一对插头，下 $=($、右 $=)$；
- 恰一个非空：回路直行或拐弯，把该插头改道向右或向下（两种转移）；
- $L=U=1$（两左括号）：两段合并，需把 $U$ 匹配的 $)$ 改成 $($；
- $L=U=2$（两右括号）：把 $L$ 匹配的 $($ 改成 $)$；
- $L=2,U=1$（$)\,($）：两条不同链首尾相连，直接消去两插头；
- $L=1,U=2$（$(\,)$）：相邻括号互为配对，**闭合成回路**——只有在最后一个空格、且闭合后轮廓再无其它插头时才计入答案（否则会漏成多条回路）。

障碍格要求左、上插头都为空。每行处理完要求最右插头为空，再整体左移一位对齐下一行。

```cpp
// 插头 DP（括号表示法）：统计用一条闭合回路覆盖棋盘全部空格的方案数（URAL1519 型）。
// 轮廓线上有 m+1 个插头，每个取值 {0 无, 1 左括号'(', 2 右括号')'}，2 bit 编码。
template <class Acc = long long>
struct PlugDP
{
    int n;
    int m;
    vector<vector<int>> a;

    PlugDP(vector<vector<int>> g) : n(g.size()), m(0), a(move(g))
    {
        // g 是矩形棋盘，1 表示障碍，0 表示必须覆盖的空格；初始化棋盘。
        // 调试检查，可删。
        assert(n > 0 && !a[0].empty());
        m = a[0].size();
        // 调试检查，可删。
        assert(2 * (m + 1) <= 64);
        for (int i = 0; i < n; i++)
        {
            // 调试检查，可删。
            assert((int)a[i].size() == m);
        }
    }

    int get(unsigned long long s, int p) const
    {
        // s 是插头状态，p 是插头位置；返回该位置的 0/1/2 编码。
        return (s >> (2 * p)) & 3;
    }

    unsigned long long set(unsigned long long s, int p, int v) const
    {
        // s 是插头状态，p 是插头位置，v 是新的 0/1/2 编码；返回修改后的状态。
        return (s & ~(3ULL << (2 * p))) | ((unsigned long long)v << (2 * p));
    }

    Acc solve()
    {
        // 无参数；返回覆盖全部空格且只有一条闭合回路的方案数。
        int ex = -1;
        int ey = -1;
        for (int i = 0; i < n; i++)
        {
            for (int j = 0; j < m; j++)
            {
                if (!a[i][j])
                {
                    ex = i;
                    ey = j;
                }
            }
        }
        if (ex < 0)
        {
            return 0;
        }

        map<unsigned long long, Acc> cur;
        cur[0] = 1;
        Acc ans = 0;
        for (int i = 0; i < n; i++)
        {
            map<unsigned long long, Acc> nxt;
            for (auto [s, c] : cur)
            {
                nxt[s << 2] += c;
            }
            cur = nxt;
            for (int j = 0; j < m; j++)
            {
                map<unsigned long long, Acc> nx;
                for (auto [s, c] : cur)
                {
                    int L = get(s, j), U = get(s, j + 1);
                    if (a[i][j])                         // 障碍：左、上插头必须都空
                    {
                        if (!L && !U)
                        {
                            nx[s] += c;
                        }
                        continue;
                    }
                    if (!L && !U)                        // ┌：新建一对插头
                    {
                        if (i + 1 < n && j + 1 < m)
                        {
                            nx[set(set(s, j, 1), j + 1, 2)] += c;
                        }
                    }
                    else if (!L || !U)                   // 直行/拐弯：单插头可向右或向下
                    {
                        int t = L ? L : U;
                        if (j + 1 < m)
                        {
                            nx[set(set(s, j, 0), j + 1, t)] += c;
                        }
                        if (i + 1 < n)
                        {
                            nx[set(set(s, j, t), j + 1, 0)] += c;
                        }
                    }
                    else if (L == 1 && U == 1)           // ( ( ：找 U 的配对 ) 改成 (
                    {
                        unsigned long long t = set(set(s, j, 0), j + 1, 0);
                        int cnt = 1;
                        for (int k = j + 2; k <= m; k++)
                        {
                            int v = get(t, k);
                            if (v == 1)
                            {
                                cnt++;
                            }
                            else if (v == 2)
                            {
                                cnt--;
                                if (cnt == 0)
                                {
                                    t = set(t, k, 1);
                                    break;
                                }
                            }
                        }
                        nx[t] += c;
                    }
                    else if (L == 2 && U == 2)           // ) ) ：找 L 的配对 ( 改成 )
                    {
                        unsigned long long t = set(set(s, j, 0), j + 1, 0);
                        int cnt = 1;
                        for (int k = j - 1; k >= 0; k--)
                        {
                            int v = get(t, k);
                            if (v == 2)
                            {
                                cnt++;
                            }
                            else if (v == 1)
                            {
                                cnt--;
                                if (cnt == 0)
                                {
                                    t = set(t, k, 2);
                                    break;
                                }
                            }
                        }
                        nx[t] += c;
                    }
                    else if (L == 2 && U == 1)           // ) ( ：两条链合并，两插头消去
                    {
                        nx[set(set(s, j, 0), j + 1, 0)] += c;
                    }
                    else                                 // ( ) ：相邻配对，闭合回路
                    {
                        // 仅当此为末空格、且闭合后轮廓再无其它插头（整条回路收尾）才计入
                        if (i == ex && j == ey && set(set(s, j, 0), j + 1, 0) == 0)
                        {
                            ans += c;
                        }
                    }
                }
                cur = nx;
            }
            map<unsigned long long, Acc> f;
            for (auto [s, c] : cur)
            {
                if (!get(s, m))
                {
                    f[s] += c;
                }
            }
            cur = f;
        }
        return ans;
    }
};
```

用 `PlugDP q(g)` 构造非空矩形棋盘，$1$ 表示障碍、$0$ 表示必须覆盖的空格，宽度须满足 $m\le31$；默认 `q.solve()` 返回 `long long` 方案数，必须保证方案数累加能装入 `Acc`，可能超过 64 位时使用 `PlugDP<__int128>`。全为障碍时返回 $0$。状态数随轮廓宽度指数增长，应把较小的一维放在宽度方向。铺砖、指定端点路径和最优权值需要重新定义插头转移，不能只改计数合并运算。

## 12.3 DP 优化

### 12.3.001 单调队列优化

当转移是 $f[i]=c_i+\min_{i-k\le j<i}f[j]$ 时，只需维护最近 $k$ 个 $f[j]$ 的最小值。双端队列按 $f$ 值单调递增：队首过期就弹出，新状态入队前弹掉所有不优于它的队尾；每个下标至多进出各一次，便把朴素 $O(nk)$ 降到 $O(n)$。通用的窗口最值、单调栈和最大矩形实现见 [2.2.008 单调栈 / 单调队列](#22008)，本条只保留 DP 转移。

```cpp
vector<int> windowDP(const vector<int> &c, int k)
{
    // c[i] 是进入状态 i 的代价，k 是前驱窗口长度；返回 f[0]=c[0] 的最小代价 DP。
    if (c.empty())
    {
        return {};
    }
    // 调试检查，可删。
    assert(k > 0);
    int n = c.size();
    vector<int> f(n);
    deque<int> q;
    f[0] = c[0];
    q.push_back(0);
    for (int i = 1; i < n; i++)
    {
        while (!q.empty() && q.front() < i - k)
        {
            q.pop_front();
        }
        f[i] = f[q.front()] + c[i];
        while (!q.empty() && f[q.back()] >= f[i])
        {
            q.pop_back();
        }
        q.push_back(i);
    }
    return f;
}
```

`windowDP(c,k)` 返回上述递推的全部状态，空代价序列返回空；非空时 $k>0$，所有状态值须能由 `int` 表示。时间 $O(n)$、额外空间 $O(n)$。代价满足四边形不等式的区间合并用 [12.3.002 四边形不等式优化](#123002)，最优决策随位置单调用 [12.3.003 分治优化](#123003)，转移写成直线求最值用 [12.3.004 斜率优化 / 李超树优化](#123004)。

### 12.3.002 四边形不等式优化

半开区间合并递推为 $dp[l][r]=\min_{l<k<r}\big(dp[l][k]+dp[k][r]\big)+w(l,r)$，单元素基例 $dp[i][i+1]=0$。若代价 $w$ 满足四边形不等式（$w(a,c)+w(b,d)\le w(a,d)+w(b,c)$，$a\le b\le c\le d$）且区间单调，则最优决策点满足 $\text{opt}[l][r-1]\le\text{opt}[l][r]\le\text{opt}[l+1][r]$。Knuth 优化把断点限制在这两个旧决策之间，总枚举量降到 $O(n^2)$；使用前必须证明条件。

```cpp
// 知识点 12.3.002：满足 Knuth 条件的区间 DP。
namespace quad_opt
{
template <class Acc = long long, class Cost>
Acc knuth(int n, Cost w)
{
    // n 是序列长度，w(l,r) 返回半开区间代价；返回 dp[0][n]，调用者必须证明 Knuth 单调性条件。
    // 调试检查，可删。
    assert(n >= 0);
    vector<vector<Acc>> dp(n + 1, vector<Acc>(n + 1));
    vector<vector<int>> opt(n + 1, vector<int>(n + 1));
    for (int i = 0; i < n; i++)
    {
        opt[i][i] = i;
        opt[i][i + 1] = i + 1;
    }
    opt[n][n] = n;
    for (int len = 2; len <= n; len++)
    {
        for (int l = 0; l + len <= n; l++)
        {
            int r = l + len;
            optional<Acc> val;
            int lo = max(l + 1, opt[l][r - 1]);
            int hi = min(r - 1, opt[l + 1][r]);
            for (int k = lo; k <= hi; k++)
            {
                Acc cur = dp[l][k] + dp[k][r] + (Acc)w(l, r);
                if (!val || cur < *val)
                {
                    val = cur;
                    opt[l][r] = k;
                }
            }
            assert(val); // Knuth 条件下该区间至少有一个候选。
            dp[l][r] = *val;
        }
    }
    return dp[0][n];
}
}
```

`knuth(n,w)` 默认返回 `long long` 的 $dp[0][n]$；$n=0$ 或 $1$ 返回 $0$。调用者须证明 Knuth 条件，并保证区间代价和候选加法能由 `Acc` 表示；需要宽状态时调用 `knuth<__int128>`。局部 `optional` 只表示本区间尚未枚举候选，因此最优值恰等于类型上界也不会和哨兵混淆。时间、空间均为 $O(n^2)$。

下面检查空序列、单元素与三堆石子的已知最优值：

```cpp

    auto cost = [](const vector<int> &a)
    {
        int n = a.size();
        vector<int> pre(n + 1);
        for (int i = 0; i < n; i++)
        {
            pre[i + 1] = pre[i] + a[i];
        }
        auto w = [&](int l, int r)
        {
            return pre[r] - pre[l];
        };
        return quad_opt::knuth(n, w);

    assert(cost({7}) == 0);
    assert(cost({1, 2, 3}) == 9);

```

### 12.3.003 分治优化

分治优化针对分层转移 $dp[i]=\min_{j<i}\big(\text{pre}[j]+w(j,i)\big)$，当本层最优决策点 $\text{opt}(i)$ 随 $i$ 单调不减时适用。做法是分治处理下标区间 $[l,r]$：先算中点 $mid$，在给定候选决策区间 $[ql,qr]$ 里暴力找出它的最优决策 $best$；由单调性，$[l,mid-1]$ 的最优决策都 $\le best$、$[mid+1,r]$ 的都 $\ge best$，于是递归时把候选区间分别收窄到 $[ql,best]$ 和 $[best,qr]$。每层递归的决策枚举量之和是 $O(n)$、递归 $O(\log n)$ 层，故代价函数被调用 $O(n\log n)$ 次。它与 Knuth 的区别：这里是"一层依赖上一层"的转移，Knuth 是"区间拆两段"的转移。

```cpp
// 知识点 12.3.003：决策单调的分治优化。
namespace dc_dp
{
template <class Acc = long long, class Cost>
vector<Acc> divideLayer(const vector<Acc> &pre, int n, Cost w)
{
    // pre[j] 是上一层状态，n 是本层最大下标，w(j,i) 是转移代价；返回本层 dp，调用者必须保证最优决策单调。
    // 调试检查，可删。
    assert(n >= 0 && (int)pre.size() == n + 1);
    vector<Acc> dp(n + 1);
    auto solve = [&](auto &&self, int l, int r, int ql, int qr) -> void
    {
        // self 是递归自身，[l,r] 是待算区间，[ql,qr] 是候选决策范围；填充 dp，无返回值。
        if (l > r)
        {
            return;
        }
        int mid = l + (r - l) / 2;
        int best = ql;
        optional<Acc> val;
        for (int j = ql; j <= min(qr, mid - 1); j++)
        {
            Acc cur = pre[j] + (Acc)w(j, mid);
            if (!val || cur < *val)
            {
                val = cur;
                best = j;
            }
        }
        assert(val); // 候选区间非空，且 pre 中没有不可达状态。
        dp[mid] = *val;
        self(self, l, mid - 1, ql, best);
        self(self, mid + 1, r, best, qr);
    };
    solve(solve, 1, n, 0, n - 1);
    return dp;
}
}
```

`divideLayer(pre,n,w)` 要求 `pre[0..n-1]` 全部是可达状态，且最优决策单调；默认返回 `long long` 的本层结果。若上一层含不可达状态，应先过滤候选或另用 `optional` 状态，不能拿类型上界传入本函数。所有转移和须能由 `Acc` 表示；需要宽状态时调用 `divideLayer<__int128>`。单层调用代价函数 $O(n\log n)$ 次，额外空间 $O(n+\log n)$。

下面检查空层、单点、并列决策与平方代价的已知结果：

### 12.3.004 斜率优化 / 李超树优化

把转移 $dp[i]=\min_j(a_jx_i+b_j)$ 中的每个决策看成直线即可做斜率优化。若斜率按不增顺序加入、查询横坐标也不减，维护下凸壳的双端队列就能均摊 $O(1)$：新线使队尾交点次序逆转时弹尾，查询时第二条线不劣于第一条便弹头。斜率或查询无序时改用 [3.7.001 李超线段树](#37001)，本章不复制数据结构实现。

```cpp
template <class Acc = long long>
struct MonoHull
{
    using U128 = unsigned __int128;

    struct Line
    {
        // k、b 是直线 y=kx+b 的斜率和截距。
        int k;
        int b;

        Acc get(int x) const
        {
            // x 是查询横坐标；返回直线在 x 处的函数值。
            return (Acc)k * x + b;
        }
    };
    // q 是按交点顺序排列的下凸壳，last 是上一次查询横坐标。
    deque<Line> q;
    optional<int> last;

    static pair<bool, U128> product(int a, int b, int c, int d)
    {
        // 返回 (a-b)(c-d) 的符号与绝对值，true 表示负数。
        auto diff = [](int x, int y)
        {
            if (x >= y)
            {
                return pair{false, (unsigned long long)x - (unsigned long long)y};
            }
            return pair{true, (unsigned long long)y - (unsigned long long)x};
        };
        auto x = diff(a, b), y = diff(c, d);
        return {x.first != y.first, (U128)x.second * y.second};
    }

    static bool less(pair<bool, U128> a, pair<bool, U128> b)
    {
        // 比较两个符号-绝对值表示的整数。
        if (a.first != b.first)
        {
            return a.first;
        }
        return a.first ? a.second > b.second : a.second < b.second;
    }

    void add(int k, int b)
    {
        // k、b 是新直线的斜率和截距；要求斜率按不增顺序加入。
        // 调试检查，可删。
        assert(q.empty() || k <= q.back().k);
        if (!q.empty() && k == q.back().k)
        {
            if (q.back().b <= b)
            {
                return;
            }
            q.pop_back();
        }
        Line c{k, b};
        while (q.size() >= 2)
        {
            Line a = q[q.size() - 2];
            Line d = q.back();
            auto l = product(d.b, a.b, d.k, c.k);
            auto r = product(c.b, d.b, a.k, d.k);
            if (less(l, r))
            {
                break;
            }
            q.pop_back();
        }
        q.push_back(c);
    }

    optional<Acc> query(int x)
    {
        // x 是不小于上次查询的横坐标；无直线时返回空，否则返回最小函数值。
        // 调试检查，可删。
        assert(!last || *last <= x);
        last = x;
        while (q.size() >= 2 && q[1].get(x) <= q[0].get(x))
        {
            q.pop_front();
        }
        if (q.empty())
        {
            return nullopt;
        }
        return q.front().get(x);
    }
};
```

用 `MonoHull h` 建空凸壳，斜率不增插入、横坐标不减查询。函数值默认用 `long long`，需要宽答案时使用 `MonoHull<__int128>`；交点比较把完整 64 位差的绝对值乘积放进 `unsigned __int128`，不会溢出有符号 128 位。无直线时返回空；插入和查询均摊 $O(1)$，空间 $O(q)$。顺序不单调时改用 [3.7.001 李超线段树](#37001)。

### 12.3.005 WQS 二分

WQS 二分（又称带权二分 / Aliens trick）处理「恰好取 $K$ 个」且最优值关于 $K$ 下凸的问题。设 $g(K)$ 为恰取 $K$ 个的最优代价，$g$ 下凸。去掉个数限制、给每次「取」附加一个罚 $\lambda$，做无约束最优化

$$h(\lambda)=\min_{c}\big(g(c)+\lambda c\big).$$

$\lambda$ 越大越抑制取用，最优个数 $c^*(\lambda)$ 单调不增；二分 $\lambda$ 使 $c^*=K$，再由凸共轭关系

$$g(K)=\max_{\lambda}\big(h(\lambda)-\lambda K\big)$$

反推真实代价。由于斜率 $g(c)-g(c{+}1)$ 为整数，整数 $\lambda$ 足以命中每个凸包顶点。两个实现要点：

- check 的 DP 在**同代价**时按「段数最多」打破平局，使 $c^*(\lambda)$ 单调、且能覆盖凸包边上的每个整点；
- 恢复答案时取「最多段数仍 $\ge K$ 的**最大** $\lambda$」。若误取「段数 $\le K$ 的最小 $\lambda$」，会选到相邻凸包边、令 $h(\lambda)-\lambda K$ 偏小（实测偏小 $1$）。

下例把正数数组恰好分成 $K$ 个连续非空段，最小化 $\sum(\text{段和})^2$。罚值上界不再写死：设总和为 $S$，当 $\lambda=S^2+1$ 时，任何至少两段的含罚代价都严格大于单段方案，因此它一定跨过所有 $K>1$ 的目标边界。

```cpp
template <class Acc = long long>
Acc wqsPartition(const vector<int> &pre, int K)
{
    // pre 是正数数组的前缀和，K 是目标段数；返回恰分 K 段的最小平方和。
    static_assert(numeric_limits<Acc>::is_integer && numeric_limits<Acc>::is_signed &&
                  sizeof(Acc) >= sizeof(long long));
    int n = (int)pre.size() - 1;
    // 调试检查，可删。
    assert(n >= 1 && 1 <= K && K <= n && pre[0] == 0);
    for (int i = 1; i <= n; i++)
    {
        // 调试检查，可删。
        assert(pre[i] > pre[i - 1]);
    }
    Acc total = pre[n];
    if (K == 1)
    {
        return total * total;
    }
    auto check = [&](Acc lambda)
    {
        // lambda 是每段罚值；返回含罚最优代价及同代价下的最多段数。
        vector<Acc> dp(n + 1);
        vector<int> cnt(n + 1);
        for (int i = 1; i <= n; i++)
        {
            bool found = false;
            for (int j = 0; j < i; j++)
            {
                Acc seg = (Acc)pre[i] - pre[j];
                Acc cur = dp[j] + seg * seg + lambda;
                int c = cnt[j] + 1;
                if (!found || cur < dp[i] || (cur == dp[i] && c > cnt[i]))
                {
                    dp[i] = cur;
                    cnt[i] = c;
                    found = true;
                }
            }
        }
        return pair<Acc, int>{dp[n], cnt[n]};
    };
    Acc lo = 0;
    Acc hi = total * total + 1;
    Acc best = 0;
    while (lo <= hi)
    {
        Acc mid = lo + (hi - lo) / 2;
        if (check(mid).second >= K)
        {
            best = mid;
            lo = mid + 1;
        }
        else
        {
            hi = mid - 1;
        }
    }
    return check(best).first - best * K;
}
```

`wqsPartition(pre,K)` 默认用 `long long` 返回恰好 $K$ 段的最小平方和，需要宽代价时调用 `wqsPartition<__int128>`。调用者须保证 $S^2+1$、每个 `dp[j]+seg^2+lambda`、二分边界及最终的 `best*K` 都能由 `Acc` 表示。当前 `check` 为 $O(n^2)$，总时间 $O(n^2\log S)$、额外空间 $O(n)$；接入斜率优化后可进一步降低检查复杂度。

```cpp

    assert(wqsPartition(vector<int>{0, 1, 2, 3, 4}, 4) == 4);
    assert(wqsPartition(vector<int>{0, 3, 4, 8, 9, 14}, 3) == 66);
}
```

### 12.3.006 SMAWK 全单调矩阵优化

当转移代价形成全单调矩阵（特别是 Monge 矩阵）时，SMAWK 在线性时间 $O(H+W)$ 内求出 $H$ 行、$W$ 列矩阵每行的最优列。回调 `better(r,x,y)` 表示第 `r` 行的 `y` 是否优于 `x`；相等时应返回 `false` 以保留最左最优列。它比本章分治优化的 $O(H\log W)$ 更快，但要求更强：所有行的最优列必须单调，且候选列的比较满足全单调性。`include/full/12_3_006.hpp` 只保存算法本体，不依赖具体数值类型。

```cpp
template <class F>
vector<int> smawk(int rows, int cols, F better)
{
    // rows、cols 是矩阵行列数；better(row, oldCol, newCol) 表示新列严格更优；返回每行最左最优列。
    assert(rows >= 0 && cols > 0);
    if (rows == 0)
    {
        return {};
    }
    auto solve = [&](auto &&self, const vector<int> &rs, const vector<int> &cs) -> vector<int>
    {
        vector<int> reduced;
        reduced.reserve(cs.size());
        for (int col : cs)
        {
            while (!reduced.empty())
            {
                int row = rs[(int)reduced.size() - 1];
                if (!better(row, reduced.back(), col))
                {
                    break;
                }
                reduced.pop_back();
            }
            if ((int)reduced.size() < (int)rs.size())
            {
                reduced.push_back(col);
            }
        }
        vector<int> oddRows;
        for (int i = 1; i < (int)rs.size(); i += 2)
        {
            oddRows.push_back(rs[i]);
        }
        vector<int> answer(rs.size());
        if (!oddRows.empty())
        {
            vector<int> oddAnswer = self(self, oddRows, reduced);
            for (int i = 0; i < (int)oddAnswer.size(); i++)
            {
                answer[2 * i + 1] = oddAnswer[i];
            }
        }
        int p = 0;
        for (int i = 0; i < (int)rs.size(); i += 2)
        {
            int limit = (i + 1 == (int)rs.size() ? reduced.back() : answer[i + 1]);
            int best = reduced[p];
            while (reduced[p] < limit)
            {
                ++p;
                if (better(rs[i], best, reduced[p]))
                {
                    best = reduced[p];
                }
            }
            answer[i] = best;
        }
        return answer;
    };
    vector<int> rs(rows), cs(cols);
    iota(rs.begin(), rs.end(), 0);
    iota(cs.begin(), cs.end(), 0);
    return solve(solve, rs, cs);
}
```

空间复杂度为 $O(H+W)$（递归栈计入 $O(\log H)$）。若仅能证明最优列单调而不能证明全单调，应使用 `monoMin` 或 `divideLayer`；误用 SMAWK 会产生错误答案。

```cpp
signed main()
{
    vector<vector<int>> a{{0, 4, 9}, {1, 1, 5}, {4, 2, 2}, {8, 3, 1}};
    auto p = smawk(4, 3, [&](int r, int x, int y) { return a[r][y] < a[r][x]; });
    assert((p == vector<int>{0, 0, 1, 2}));
}
```
