# 算法竞赛模板库全面优化计划

## 优化原则

1. **代码简洁性**
   - 变量名要短且有意义（不要过长的描述性名称）
   - 保留多种实现：简单O(n²) vs 优化O(n log n)，如果简单版本代码很短
   - 复杂度相近时只保留最优的
   - assert可以省略（选手自己不抄）

2. **覆盖完整性**
   - 参考图片中的OI-Wiki目录
   - 补充缺失的算法
   - 数学竞赛相关几何定理
   - 所有竞赛可能出现的算法都要有

3. **适配性**
   - 代码在各种场景下都能用
   - 接口设计灵活
   - 模板参数通用

## 优化策略

### Phase 1: 代码质量优化（当前章节）
- 缩短变量名
- 移除冗余assert
- 保留多种实现（简单+优化）
- 统一代码风格

### Phase 2: 补充缺失算法
- 从图片目录中找缺失项
- 优先级：常见竞赛算法 > 数学竞赛几何 > 高级理论

### Phase 3: Library Checker测试
- 在LC覆盖范围内的算法都要测试
- 确保正确性

### Phase 4: 文档同步更新
- 每个新增算法补充理论说明
- 更新目录索引

## 执行方式

使用多个子agent并行处理各章节：
- Agent 1: 基础算法与离线算法
- Agent 2: 数据结构
- Agent 3: 字符串
- Agent 4: 图论
- Agent 5: 树论与动态树
- Agent 6: 数论
- Agent 7: 组合数学
- Agent 8: 线性代数
- Agent 9: 多项式与变换
- Agent 10: 计算几何
- Agent 11: 动态规划
- Agent 12: 补充新算法
