## 优化原则

### 1. 代码简洁性 ✅
- 变量名简短但有意义
- 移除非必要assert（选手自己判断）
- 统一代码风格（C++20、#define int long long）

### 2. 实现多样性 ✅
**保留策略**：
- ✅ 简单O(n²) + 优化O(n log n)，如果简单版很短
- ✅ 不同算法思想（如Dijkstra + SPFA）
- ❌ 代码长度相近但复杂度差的只留最优

**示例**：
- 拉格朗日插值：保留O(n²)简单、O(n)连续点、O(n log²n)任意点
- 最短路：保留Dijkstra、SPFA、Floyd
- LCA：保留倍增、RMQ两种

### 3. 覆盖完整性 ✅
**优先级**：
- P0：竞赛常见算法（并查集、线段树、KMP、网络流等）
- P1：进阶算法（FFT、后缀自动机、LCT等）
- P2：专题算法（计算几何、博弈论、数学竞赛几何等）

### 4. 测试覆盖 ✅
- Library Checker覆盖范围内的算法都要测试
- 标记测试链接
- 确保正确性
