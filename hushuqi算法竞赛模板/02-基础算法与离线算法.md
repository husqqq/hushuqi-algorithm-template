## 2.1 搜索与枚举

### 2.1.001 整数二分、实数二分

在单调谓词上定位分界点。整数版维护「答案仍在闭区间 $[l,r]$ 中」的不变量，每轮用 `midpoint` 安全折半，`firstTrue` 返回第一个为真的位置、`lastTrue` 返回最后一个为真的位置；`lastTrue` 里 `m == l` 时上取到 `r`，是为了偶数长度不陷入死循环。两者都不设 $l-1$ / $r+1$ 哨兵，调用者须保证答案确在给定闭区间内。实数版不比较浮点端点是否相等，改用固定迭代轮数把误差压到初始长度的 $2^{-it}$。二分只对单调判定成立，不能对任意函数盲套。

```cpp
template <class F> int firstTrue(int l, int r, F f)
{
    // l、r 是答案所在闭区间，f 是由假变真的谓词；返回第一个为真的位置。
    while (l < r)
    {
        auto m = midpoint(l, r);
        if (f(m))
        {
            r = m;
        }
        else
        {
            l = m + 1;
        }
    }
    return l;
}
```

```cpp
template <class F> int lastTrue(int l, int r, F f)
{
    // l、r 是答案所在闭区间，f 是由真变假的谓词；返回最后一个为真的位置。
    while (l < r)
    {
        auto m = midpoint(l, r);
        if (m == l)
        {
            m = r;
        }
        if (f(m))
        {
            l = m;
        }
        else
        {
            r = m - 1;
        }
    }
    return l;
}
```

```cpp
template <class F> long double firstReal(long double l, long double r, F f, int it = 100)
{
    // l、r 是初始实数区间，f 是单调谓词，it 是迭代轮数；返回分界点近似值。
    for (int t = 0; t < it; t++)
    {
        auto m = midpoint(l, r);
        if (f(m))
        {
            r = m;
        }
        else
        {
            l = m;
        }
    }
    return midpoint(l, r);
}
```

若要在已有随机访问有序区间上反复做下界/上界查询，分支结果通常难以预测，可以使用无分支步长收缩版：

```cpp
template <class It, class T, class F = less<>> It fastLower(It first, It last, const T &x, F f = {})
{
    // [first,last) 必须支持随机访问；返回第一个不小于 x 的位置。
    assert(first <= last);
    int n = last - first;
    for (n++; n > 1;)
    {
        int h = n / 2;
        n -= h;
        first += f(first[h - 1], x) * h;
    }
    return first;
}

template <class It, class T, class F = less<>> It fastUpper(It first, It last, const T &x, F f = {})
{
    // [first,last) 必须支持随机访问；返回第一个大于 x 的位置。
    assert(first <= last);
    int n = last - first;
    for (n++; n > 1;)
    {
        int h = n / 2;
        n -= h;
        first += !f(x, first[h - 1]) * h;
    }
    return first;
}
```

谓词方向决定用哪支：`firstTrue` 的谓词须由假变真，`lastTrue` 的谓词须由真变假；无解时先在调用前验证边界谓词，或把返回区间外扩一格作显式哨兵。三个谓词接口的最小调用如下：

```cpp
int x = firstTrue(0, 10, [](int p)
{
    return p * p >= 20;
});
int y = lastTrue(0, 10, [](int p)
{
    return p * p <= 20;
});
long double z = firstReal(0, 2, [](long double p)
{
    return p * p >= 2;
});
assert(x == 5 && y == 4 && fabsl(z * z - 2) < 1E-12L);
```

整数版调用谓词 $\lceil\log_2(r-l+1)\rceil$ 次、额外空间 $O(1)$；实数版固定调用 $it$ 次。`fastLower/fastUpper` 与标准库语义相同，允许空区间，但只适合随机访问迭代器；它们仍是 $O(\log n)$，优势只在不可预测比较下减少分支。本机一百万次随机下界查询的 7 轮中位数约为 `66ms`，标准 `lower_bound` 约为 `112ms`；小数组或比较器很贵时差距可能消失，默认仍可用标准库版本。

### 2.1.002 整数三分、实数三分、黄金分割三分

求单峰函数的极值，模板求最大值；求最小值时应反转比较，只有确认值域取负不溢出时才传 `-f(x)`。比较两个三等分点后能证明峰值不在较差点外侧那一段，于是每轮丢掉约三分之一。整数版收窄到常数宽度后逐点枚举剩余的至多 5 个位置，专门兜住平台峰与整除取整；`ternaryReal` 每轮独立取两点，`goldenMax` 用黄金比 $\varphi-1\approx0.618$ 布点，使收缩后有一个内点可复用、每轮只新增一次求值，因此函数求值昂贵时更省。三分要求真单峰，函数有多个相隔局部峰时没有正确性保证。

```cpp
template <class F> int ternaryInt(int l, int r, F f)
{
    // l、r 是整数闭区间，f 是单峰函数；返回一个最大值位置。
    // 求最小值要把收缩循环和末尾扫描中的 f 比较同时反向；只改一处会得到错误区间。
    while (r - l > 4)
    {
        auto d = r - l;
        auto x = l + d / 3;
        auto y = r - d / 3;
        if (f(x) < f(y))
        {
            l = x + 1;
        }
        else
        {
            r = y - 1;
        }
    }
    auto p = l;
    auto x = l;
    while (x < r)
    {
        x++;
        if (f(p) < f(x))
        {
            p = x;
        }
    }
    return p;
}
```

```cpp
template <class F> long double ternaryReal(long double l, long double r, F f, int it = 120)
{
    // l、r 是实数区间，f 是单峰函数，it 是迭代轮数；返回最大值位置近似值。
    // 求最小值时反向循环内的 f(x)、f(y) 比较；若改传 -f，先确认取负不会溢出。
    for (int t = 0; t < it; t++)
    {
        auto x = lerp(l, r, 1.0L / 3);
        auto y = lerp(l, r, 2.0L / 3);
        if (f(x) < f(y))
        {
            l = x;
        }
        else
        {
            r = y;
        }
    }
    return midpoint(l, r);
}
```

```cpp
template <class F> long double goldenMax(long double l, long double r, F f, int it = 120)
{
    // l、r 是实数区间，f 是单峰函数，it 是迭代轮数；返回黄金分割搜索结果。
    // 求最小值时反向 fx、fy 的比较；其余复用点和区间更新方向不变。
    constexpr long double ratio = 0.6180339887498948482L;
    auto x = lerp(l, r, 1 - ratio);
    auto y = lerp(l, r, ratio);
    auto fx = f(x);
    auto fy = f(y);
    for (int t = 0; t < it; t++)
    {
        if (fx < fy)
        {
            l = x;
            x = y;
            fx = fy;
            y = lerp(l, r, ratio);
            fy = f(y);
        }
        else
        {
            r = y;
            y = x;
            fy = fx;
            x = lerp(l, r, 1 - ratio);
            fx = f(x);
        }
    }
    return midpoint(l, r);
}
```
只在能证明单峰时使用。三个函数都可直接接收 Lambda：

```cpp
auto fi = [](int x)
{
    return -(x - 3) * (x - 3);
};
auto fr = [](long double x)
{
    return -(x - 1.5L) * (x - 1.5L);
};
assert(ternaryInt(-10, 10, fi) == 3);
assert(fabsl(ternaryReal(0, 3, fr) - 1.5L) < 1E-12L);
assert(fabsl(goldenMax(0, 3, fr) - 1.5L) < 1E-12L);
```

整数版要求调用前保证 `r-l` 能由 64 位有符号整数表示，循环中的差值和三分点因此不会溢出；实数版要求两个端点有限，`midpoint` 与 `lerp` 避免先把同号大端点相加或先计算跨极值的 `r-l`。整数版进行 $O(\log(r-l+1))$ 轮、每轮两次求值，末尾至多检查 5 点；`ternaryReal` 固定 $2\cdot it$ 次求值，`goldenMax` 初始化 2 次、之后每轮新增 1 次共 $it+2$ 次；额外空间均为 $O(1)$。

### 2.1.003 全排列与不重复排列

按字典序枚举多重集合的全部不同排列。先排序得到最小字典序，再反复 `next_permutation`：标准库按「下一个严格更大的序列」推进，遇到相同元素时自动跳过，因此不会产生重复排列。

```cpp
vector<int> a{1, 1, 2}; // a 是待枚举的多重集合。
sort(a.begin(), a.end());
do
{
    use(a); // use 处理当前排列。
} while (next_permutation(a.begin(), a.end()));
```

必须先排序再进入 `do while`，故 `{1,1,2}` 恰好产生 3 个排列；`use(a)` 在循环体内直接处理当前排列，需要留存时自行复制一份 `vector`。不同排列数为 $P$ 时，排序 $O(n\log n)$、枚举 $O(Pn)$；`next_permutation` 本身为 $O(1)$ 额外空间，常用 libstdc++/libc++ 的 `sort` 栈空间为 $O(\log n)$，若换用带缓冲的排序实现则以该实现为准，回调自行复制才额外需要 $O(n)$。

### 2.1.004 子集枚举、固定大小子集枚举

用位掩码枚举子集：普通枚举把第 $i$ 位是否为 1 解释为是否选第 $i$ 个元素，直接从 $0$ 递增到 $2^n-1$。Gosper's hack 由当前掩码直接构造下一个 popcount 相同的掩码——`low = s & -s` 取最低置位，`s + low` 进位后再把低位补齐——因此只走恰有 $k$ 位的状态，不扫描其余掩码。两段都限定 $n<63$，避免 `1ULL << n` 越过无符号 64 位边界。

```cpp
// n 是元素数，s 是当前子集掩码，use 处理当前子集。
assert(0 <= n && n < 63); // 调试检查，可删
for (auto s = 0ULL; s < (1ULL << n); s++)
{
    use(s);
}
```

```cpp
// n 是元素数，k 是子集大小，s 是当前掩码，use 处理当前子集。
assert(0 <= k && k <= n && n < 63); // 调试检查，可删
if (k == 0)
{
    use(0ULL);
}
else
{
    for (auto s = (1ULL << k) - 1; s < (1ULL << n);)
    {
        use(s);
        auto low = s & -s;
        auto nxt = s + low;
        s = nxt | (s ^ nxt) / low >> 2;
    }
}
```

两段都要求 $0\le n<63$，固定大小版本还要求 $0\le k\le n$；$k=0$ 时直接处理唯一的空集。若只要枚举某个掩码 `s` 的非空子集，用 `for (t = s; t; t = (t - 1) & s)`，不要遍历整个状态空间。全部子集共 $2^n$ 个、固定大小子集恰 $\binom{n}{k}$ 个，每次推进 $O(1)$、额外空间 $O(1)$。

### 2.1.005 Gray Code

Gray Code 把 $0,1,\ldots,2^n-1$ 重编码为 $n$ 位序列，使相邻编码的汉明距离恒为 1，适合枚举子集时每步只增删一个元素（增量维护子集和、行列式符号、状态代价等），它只改变访问顺序、不减少 $2^n$ 个状态。二进制反射编码为 $g=x\oplus(x\gg1)$：相邻整数加一会翻转从最低位起的一段连续位，与右移一位的自身异或后这段翻转两两抵消，只剩一位变化；当 $n>0$ 时，反射构造还保证完整序列首尾只差一位，形成哈密顿环。逆变换满足 $x_i=g_i\oplus x_{i+1}$，即从最高位向低位做前缀异或，代码靠不断右移并累积异或一次完成。

```cpp
// x 是普通二进制编号，g 是对应的 Gray Code。
auto g = x ^ (x >> 1);
```

```cpp
// g 是 Gray Code，x 是还原后的普通二进制编号。
auto x = g;
for (auto y = g >> 1; y; y >>= 1)
{
    x ^= y;
}
```

对普通编号 `x` 执行第一段得 `g`，对 `g` 执行第二段还原 `x`；想知道第 $x$ 个状态相对前一个翻转了哪一位，算 `g ^ preG` 取其唯一置位即可。当 $n>0$ 时，连续枚举完整的 $2^n$ 个 $n$ 位 Gray Code，其相邻项与首尾都恰差一位；截取任意前缀后不再保证首尾相邻。逆变换仅适用于此处的二进制反射编码。编码在 64 位机器字上 $O(1)$，解码执行 $g$ 的二进制位数减一次那么多轮，即 $O(\log(g+1))$ 时间、$O(1)$ 空间。

### 2.1.006 DFS / BFS 基础搜索

BFS 求无权图最短边数：队列按距离层弹出，节点首次被访问时的距离即最短。DFS 沿一条分支深入到底再回溯，访问顺序由邻接表决定；本模板按约定直接写递归 lambda，深链场景需确认系统栈足够。两者都靠 `d` / `vis` 保证每个点只正式处理一次。

```cpp
vector<int> bfs(const vector<vector<int>> &g, int s)
{
    // g 是邻接表，s 是起点；返回各顶点到 s 的最少边数，-1 表示不可达。
    vector<int> d(g.size(), -1);
    queue<int> q;
    d[s] = 0;
    q.push(s);
    while (!q.empty())
    {
        auto x = q.front();
        q.pop();
        for (auto y : g[x])
        {
            if (d[y] != -1)
            {
                continue;
            }
            d[y] = d[x] + 1;
            q.push(y);
        }
    }
    return d;
}
```

```cpp
vector<int> dfsOrder(const vector<vector<int>> &g, int s)
{
    // g 是邻接表，s 是起点；返回从 s 出发的递归 DFS 首次访问顺序。
    vector<int> ans, vis(g.size());
    auto dfs = [&](auto &&self, int x) -> void
    {
        vis[x] = 1;
        ans.push_back(x);
        for (auto y : g[x])
        {
            if (!vis[y])
            {
                self(self, y);
            }
        }
    };
    dfs(dfs, s);
    return ans;
}
```

图用 `vector<vector<int>>` 邻接表、顶点编号 $[0,n)$，`bfs(g, s)` 返回各点到 `s` 的最少边数（`-1` 表示不可达），`dfsOrder(g, s)` 返回首次访问序（具体顺序由邻接表顺序决定）。邻接表图上均为 $O(n+m)$ 时间、$O(n)$ 额外空间；递归 DFS 另占最坏 $O(n)$ 调用栈。

### 2.1.007 启发式搜索与 A*（第 K 短路）

求第 $k$ 短游走（允许重复经过顶点和边，不是第 $k$ 条简单路径）。先在反图上跑 Dijkstra，得到每点到终点的真实最短距离 $h(x)$，它既不高估又满足一致性，是理想的 A* 启发函数；随后正图 A* 每次弹出全局最小的 $g+h$ 状态，同一顶点第 $c$ 次有效弹出对应到它的第 $c$ 条候选游走，终点达到所需弹出次数时即得答案。每点只扩展至多 `need` 次；通常 `need == k`，仅在起终点相同且不计空路时为 `k + 1`。负边会同时破坏反图 Dijkstra 与这一弹出顺序，故要求边权非负；可达状态用 `optional` 与距离分开，调用者必须保证实际距离、估价与二者之和可由 64 位有符号整数表示。BFS、Dijkstra 与 A* 的适用边界见 [`知识点关系.md`](知识点关系.md)。

```cpp
// WEdge[0] 表示终点，WEdge[1] 表示边权。
using WEdge = array<int, 2>;

optional<int> kthShortest(const vector<vector<WEdge>> &g, int s, int t, int k, bool allowEmpty = false)
{
    // g 是非负权图，s、t 是起终点，k 是排名，allowEmpty 表示是否计入空路；不存在第 k 条游走时返回空。
    auto n = (int)g.size();
    assert(0 <= s && s < n && 0 <= t && t < n); // 调试检查，可删
    assert(k >= 1);                              // 调试检查，可删
    vector<vector<WEdge>> rg(n);
    for (int x = 0; x < n; x++)
    {
        for (auto [y, w] : g[x])
        {
            assert(0 <= y && y < n && w >= 0); // 调试检查，可删
            rg[y].push_back({x, w});
        }
    }
    vector<optional<int>> h(n);
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> dq;
    h[t] = 0;
    dq.push({0, t});
    while (!dq.empty())
    {
        auto [dx, x] = dq.top();
        dq.pop();
        if (!h[x] || dx != *h[x])
        {
            continue;
        }
        for (auto [y, w] : rg[x])
        {
            auto d = dx + w;
            if (!h[y] || d < *h[y])
            {
                h[y] = d;
                dq.push({d, y});
            }
        }
    }
    if (!h[s])
    {
        return nullopt;
    }
    auto need = (unsigned long long)k + (s == t && !allowEmpty);
    // State 依次保存估价距离、已走距离和当前顶点。
    using State = tuple<int, int, int>;
    priority_queue<State, vector<State>, greater<>> q;
    vector<unsigned long long> cnt(n);
    q.push({*h[s], 0, s});
    while (!q.empty())
    {
        auto cur = q.top();
        q.pop();
        auto d = get<1>(cur);
        auto x = get<2>(cur);
        cnt[x]++;
        if (cnt[x] > need)
        {
            continue;
        }
        if (x == t && cnt[x] == need)
        {
            return d;
        }
        for (auto [y, w] : g[x])
        {
            if (!h[y])
            {
                continue;
            }
            auto nd = d + w;
            q.push({nd + *h[y], nd, y});
        }
    }
    return nullopt;
}
```

边表 `WEdge = {to, weight}`（`[0]` 终点、`[1]` 非负边权），建图后调用 `kthShortest(g,s,t,k)`，`nullopt` 只表示没有第 $k$ 条游走；调用者须保证距离与估价和能由 `int` 表示。默认 `s == t` 时不把空路径计入，传 `allowEmpty = true` 才计入长度 0。以边集 $0\to1(1),0\to2(2),0\to3(10),1\to2(1),1\to3(4),2\to3(1)$ 为例，$0\to3$ 的前三短游走长度为 `3,3,5`。反图 Dijkstra 为 $O((n+m)\log n)$；A* 中每点至多有效弹出 $k+1$ 次、扩边至多 $O(km)$ 次，堆复杂度 $O(km\log(kn+km))$、最坏空间 $O(kn+km)$。改成简单路径则问题性质不同，不能套此模板。

### 2.1.008 模拟退火

无可靠精确算法、但状态可局部扰动且评分连续时求近似最优解，它没有正确性保证，不能替代可证明的凸优化、DP 或搜索。更优状态必然接受，更差状态以 $\exp(-\Delta/t)$ 的概率接受：高温放行较差跳转以逃出局部最优，降温后逐渐收敛稳定。结果质量高度依赖邻域设计、初温、降温率 `rate`、每层尝试次数 `each` 和多起点策略，因此接口把这些旋钮全部显式交给调用者。

```cpp
template <class S, class Score, class Next, class Rng>
pair<S, long double> anneal(S cur,
                            Score score,
                            Next next,
                            Rng &rng,
                            long double t = 1,
                            long double stop = 1E-8L,
                            long double rate = .995L,
                            int each = 1)
{
    // cur 是初态，score/next 是评分与邻域函数，rng 是随机源；其余参数控制降温，返回最佳状态及分数。
    assert(t > stop && stop > 0 && 0 < rate && rate < 1 && each > 0); // 调试检查，可删
    long double val = (long double)score(cur);
    auto best = cur;
    long double ans = val;
    uniform_real_distribution<long double> dis(0, 1);
    while (t > stop)
    {
        for (int z = 0; z < each; z++)
        {
            auto p = next(cur, rng, t);
            long double v = (long double)score(p);
            long double d = v - val;
            if (d <= 0 || dis(rng) < expl(-d / t))
            {
                cur = move(p);
                val = v;
            }
            if (val < ans)
            {
                best = cur;
                ans = val;
            }
        }
        t *= rate;
    }
    return {best, ans};
}
```

`score` 越小越好且结果须可转为 `long double`，`next(cur,rng,t)` 生成邻居。下面从已知最优点出发，固定种子并核对最优状态不会丢失：

```cpp
mt19937_64 rng(1);
auto score = [](int x)
{
    return (long double)(x - 3) * (x - 3);
};
auto next = [](int x, auto &rng, long double t)
{
    (void)t;
    return x + uniform_int_distribution<int>(-1, 1)(rng);
};
auto [state, value] = anneal(3LL, score, next, rng, 1.L, 1E-4L, .9L, 4);
assert(state == 3 && value == 0);
```

参数要求 $t_0>stop>0$、$0<rate<1$、`each > 0`，固定随机种子便于复现，正式提交宜多起点运行取最好值。温度层数为 $\left\lceil\frac{\log(stop/t_0)}{\log(rate)}\right\rceil$，候选总数为该值乘 `each`，总时间再乘单次 `score` 与 `next` 的代价，空间只两个状态；正确率无渐进保证。

### 2.1.009 DLX 精确覆盖

精确覆盖要求从 $0/1$ 矩阵中选若干行，使每一列恰被一个所选行覆盖；数独和棋盘精确铺放都能把候选决策写成行、把必须唯一满足的约束写成列。DLX 用循环双向十字链表实现 Algorithm X：递归时选择当前节点最少的列 $c$，尝试该列中的每一行；选行后删除它覆盖的全部列以及与这些列冲突的其他行，回溯时严格按相反顺序恢复，链表就回到进入递归前的状态。这里所有列都是必须覆盖一次的主列，列编号为 $1\ldots m$；同一行的列不得重复，只有“至多一次”的次要列需要另行扩展表头规则。

```cpp
struct DLX
{
    // m 是必须恰好覆盖的列数。
    int m;
    // l、r、u、d 是十字链表节点向左、右、上、下的指针。
    vector<int> l, r, u, d;
    // row、col 分别是数据节点对应的行编号和列编号。
    vector<int> row, col;
    // sz[c] 是当前列 c 中仍未删除的数据节点数。
    vector<int> sz;
    // cur 是当前递归路径选中的行编号，ans 是找到的完整答案。
    vector<int> cur, ans;

    explicit DLX(int cols, int reserveNodes = 0)
        : m(cols), l(m + 1), r(m + 1), u(m + 1), d(m + 1), row(m + 1), col(m + 1), sz(m + 1)
    {
        // cols 是列数，reserveNodes 是预估的数据节点数；建立带根节点的列链表。
        assert(m >= 0 && reserveNodes >= 0); // 调试检查，可删。
        for (int i = 0; i <= m; i++)
        {
            l[i] = i - 1;
            r[i] = i + 1;
            u[i] = d[i] = col[i] = i;
        }
        l[0] = m;
        r[m] = 0;
        if (reserveNodes > 0)
        {
            auto cap = m + 1 + reserveNodes;
            l.reserve(cap);
            r.reserve(cap);
            u.reserve(cap);
            d.reserve(cap);
            row.reserve(cap);
            col.reserve(cap);
        }
    }

    void addRow(int id, const vector<int> &columns)
    {
        // id 是返回答案时使用的行编号，columns 是该行覆盖的列编号；把一行加入十字链表。
        int head = -1;
        for (int k = 0; k < (int)columns.size(); k++)
        {
            int c = columns[k];
            // 调试检查，可删。
            assert(1 <= c && c <= m);
            // 调试检查，可删。
            assert(find(columns.begin(), columns.begin() + k, c) == columns.begin() + k);
            int x = (int)l.size();
            l.push_back(x);
            r.push_back(x);
            u.push_back(u[c]);
            d.push_back(c);
            row.push_back(id);
            col.push_back(c);
            d[u[c]] = x;
            u[c] = x;
            sz[c]++;
            if (head == -1)
            {
                head = x;
            }
            else
            {
                l[x] = l[head];
                r[x] = head;
                r[l[head]] = x;
                l[head] = x;
            }
        }
    }

    optional<vector<int>> solve()
    {
        // 无参数；返回一组覆盖全部列的行编号，无解时返回空。
        cur.clear();
        ans.clear();
        if (!dfs())
        {
            return nullopt;
        }
        return ans;
    }

  private:
    void cover(int c)
    {
        // c 是当前仍在列链表中的列编号；从结构中删除该列及与其冲突的行。
        r[l[c]] = r[c];
        l[r[c]] = l[c];
        for (int i = d[c]; i != c; i = d[i])
        {
            for (int j = r[i]; j != i; j = r[j])
            {
                d[u[j]] = d[j];
                u[d[j]] = u[j];
                sz[col[j]]--;
            }
        }
    }

    void uncover(int c)
    {
        // c 是最近一次删除的列编号；按相反顺序恢复列和冲突行。
        for (int i = u[c]; i != c; i = u[i])
        {
            for (int j = l[i]; j != i; j = l[j])
            {
                sz[col[j]]++;
                d[u[j]] = j;
                u[d[j]] = j;
            }
        }
        r[l[c]] = c;
        l[r[c]] = c;
    }

    bool dfs()
    {
        // 无参数；返回当前子问题是否有解，并在成功时把行编号写入 ans。
        if (r[0] == 0)
        {
            ans = cur;
            return true;
        }
        int c = r[0];
        for (int j = r[c]; j != 0; j = r[j])
        {
            if (sz[j] < sz[c])
            {
                c = j;
            }
        }
        if (sz[c] == 0)
        {
            return false;
        }
        cover(c);
        for (int i = d[c]; i != c; i = d[i])
        {
            cur.push_back(row[i]);
            for (int j = r[i]; j != i; j = r[j])
            {
                cover(col[j]);
            }
            bool found = dfs();
            for (int j = l[i]; j != i; j = l[j])
            {
                uncover(col[j]);
            }
            cur.pop_back();
            if (found)
            {
                uncover(c);
                return true;
            }
        }
        uncover(c);
        return false;
    }
};
```

先构造 `DLX dlx(m,z)`，其中 `z` 只是用于预留数据节点容量的可选估计，再以 `addRow(id,columns)` 加入候选行并调用 `solve()`；返回值中的行编号按搜索选择顺序排列，空值表示无解，$m=0$ 时空行集就是合法答案。设矩阵中 $1$ 的总数为 $z$，建表时间与空间均为 $O(m+z)$；搜索最坏为指数级，单次删除或恢复的代价等于实际遍历的链表节点数，最小列启发式只改善搜索树而不改变最坏上界。若只需一般集合覆盖的最少行数，问题不再是精确覆盖，应使用状态压缩 DP、搜索剪枝或近似算法。

下面用七列标准实例核对唯一解由第 $2,4,6$ 行组成，再检查无列实例和无解实例：

```cpp
signed main()
{
    DLX dlx(7, 18);
    dlx.addRow(1, {1, 4, 7});
    dlx.addRow(2, {1, 4});
    dlx.addRow(3, {4, 5, 7});
    dlx.addRow(4, {3, 5, 6});
    dlx.addRow(5, {2, 3, 6, 7});
    dlx.addRow(6, {2, 7});
    auto ans = dlx.solve();
    assert(ans);
    sort(ans->begin(), ans->end());
    assert(*ans == vector<int>({2, 4, 6}));
    auto empty = DLX(0).solve();
    assert(empty && empty->empty());
    DLX bad(2);
    bad.addRow(1, {1});
    assert(!bad.solve());
    cout << (*ans)[0] << ' ' << (*ans)[1] << ' ' << (*ans)[2] << '\n'; // 2 4 6
    return 0;
}
```

## 2.2 排序、分治与序列处理

### 2.2.001 快速排序、归并排序、基数排序

三种排序不是同一功能的快慢版本，接口和内存约束各异。通用比较排序 `sort` 只依赖严格弱序，能处理任意对象和自定义比较器，是默认首选；`mergeSort` 在合并两个有序段时保持相等元素原顺序，需要稳定性或想在归并过程中顺带统计（如逆序对）时用它；`radixSort` 把有符号 64 位整数翻转符号位（`^ (1ULL << 63)`）后按 16 位一段稳定分桶、四趟完成，数据是大量纯整数且内存充裕时最快。

```cpp
sort(a.begin(), a.end());
```

```cpp
template <class T, class Cmp = less<T>> void mergeSort(vector<T> &a, Cmp cmp = {})
{
    // a 是待排序数组，cmp 是严格弱序比较器；排序结果直接写回 a。
    vector<T> b;
    b.reserve(a.size());
    auto dfs = [&](auto &&self, int l, int r) -> void
    {
        if (r - l <= 1)
        {
            return;
        }
        auto m = midpoint(l, r);
        self(self, l, m);
        self(self, m, r);
        auto i = l;
        auto j = m;
        b.clear();
        while (i < m || j < r)
        {
            if (j == r || (i < m && !cmp(a[j], a[i])))
            {
                b.push_back(move(a[i++]));
            }
            else
            {
                b.push_back(move(a[j++]));
            }
        }
        move(b.begin(), b.end(), a.begin() + l);
    };
    dfs(dfs, 0, a.size());
}
```

```cpp
void radixSort(vector<int> &a)
{
    // a 是待排序的有符号 64 位整数数组；排序结果直接写回 a。
    static_assert(numeric_limits<int>::digits == 63);
    vector<unsigned long long> x(a.size()), b(a.size());
    for (int i = 0; i < (int)a.size(); i++)
    {
        x[i] = (unsigned long long)a[i] ^ (1ULL << 63);
    }
    constexpr int B = 1 << 16;
    vector<int> cnt(B);
    for (int sh = 0; sh < 64; sh += 16)
    {
        fill(cnt.begin(), cnt.end(), 0);
        for (auto v : x)
        {
            cnt[v >> sh & (B - 1)]++;
        }
        partial_sum(cnt.begin(), cnt.end(), cnt.begin());
        for (auto it = x.rbegin(); it != x.rend(); it++)
        {
            auto p = *it >> sh & (B - 1);
            b[--cnt[p]] = *it;
        }
        x.swap(b);
    }
    for (int i = 0; i < (int)a.size(); i++)
    {
        a[i] = bit_cast<int>(x[i] ^ (1ULL << 63));
    }
}
```
`sort(a.begin(), a.end())` 通用首选，`mergeSort(a)` 稳定备用，`radixSort(a)` 专供纯整数大数据。归并缓冲通过 `reserve` 后逐个构造，不要求 `T` 可默认构造；基数版要求 64 位二补码有符号整数，末步用 `bit_cast<int>` 恢复位模式，不依赖超范围无符号数到有符号数的实现定义转换。本机基准（MinGW g++ 14.2、`-O2`、一百万随机 64 位整数、7 轮中位数）为 `radixSort=16ms`、`sort=41ms`、`mergeSort=67ms`，基数排序最快，但比较器、自定义对象和低内存场景仍用 `sort`。`sort` 与 `mergeSort` 均 $O(n\log n)$、归并额外空间 $O(n)$；基数排序固定 4 趟、每趟 $O(n+2^{16})$，总空间 $O(n+2^{16})$。

传自定义比较器时，例如按降序稳定归并：

```cpp
vector<int> a{2, 1, 3};
auto cmp = [](int x, int y)
{
    return x > y;
};
mergeSort(a, cmp);
assert((a == vector<int>{3, 2, 1}));
```

### 2.2.002 离散化与坐标压缩

把任意可比较值映射到 $[0,V)$，保留大小关系和相等关系，是本章多处（整体二分、区间不同数等）共用的底层结构，故在此首次完整给出。做法是复制全部候选值，排序去重后用 `lower_bound` 求排名：`id(x)` 要求 `x` 已存在并返回其编号，`lower(x)` 返回第一个不小于 `x` 的位置，`value(p)` 反查原值。注意编号只能用于比较顺序、频率和树状数组下标；原值差、几何距离等运算必须回到 `value(id)`，否则会把不等距坐标误当成等距。

```cpp
template <class T> struct Discrete
{
    vector<T> a; // a 保存升序且去重后的原值。

    Discrete() = default;

    explicit Discrete(vector<T> v) : a(move(v))
    {
        // v 收集所有可能出现的值。
        sort(a.begin(), a.end());
        a.erase(unique(a.begin(), a.end()), a.end());
    }

    int id(const T &x) const
    {
        // x 必须已存在；返回 x 从 0 开始的离散编号。
        auto it = lower_bound(a.begin(), a.end(), x);
        assert(it != a.end() && *it == x); // 调试检查，可删
        return it - a.begin();
    }

    int lower(const T &x) const
    {
        // x 是查询值；返回第一个不小于 x 的离散位置。
        return lower_bound(a.begin(), a.end(), x) - a.begin();
    }

    const T &value(int p) const
    {
        // p 是合法离散编号；返回对应原值的常量引用。
        return a[p];
    }
};
```

以 `Discrete<int> dis(a)` 构造后，`dis.id(x)`、`dis.lower(x)`、`dis.value(p)` 分别取编号、下界位置和原值。这是静态离散化：在线出现新值时会失效，须提前收集所有可能的更新值，或改用平衡树；也不要把离散编号当原值做距离运算。构造 $O(n\log n)$ 时间、$O(n)$ 空间，单次映射 $O(\log V)$。

### 2.2.003 逆序对及其扩展

统计 $i<j$ 且 $a_i>a_j$ 的二元组。两种同为 $O(n\log n)$ 但扩展方向不同的做法都完整保留，不合并成黑盒：归并版在合并时，每当右半元素先被取出，就一次性加上左半尚未取出的元素数 `m - i`，无需离散化且便于顺带累计其他归并贡献；BIT 版先离散化，再从右向左扫描、查询严格小于当前值的已加入数量，便于改成按值排名、动态频率或别的前缀统计。相等元素在两版中都不计入逆序对。逆序对、三维偏序、整体二分与区间第 $k$ 小的关系见 [`知识点关系.md`](知识点关系.md)。

```cpp
template <class T> int invMerge(vector<T> a)
{
    // a 是按值复制的序列；返回严格逆序对数量。
    vector<T> b;
    b.reserve(a.size());
    int ans = 0;
    auto dfs = [&](auto &&self, int l, int r) -> void
    {
        if (r - l <= 1)
        {
            return;
        }
        auto m = midpoint(l, r);
        self(self, l, m);
        self(self, m, r);
        auto i = l;
        auto j = m;
        b.clear();
        while (i < m || j < r)
        {
            if (j == r || (i < m && !(a[j] < a[i])))
            {
                b.push_back(move(a[i++]));
            }
            else
            {
                ans += m - i;
                b.push_back(move(a[j++]));
            }
        }
        move(b.begin(), b.end(), a.begin() + l);
    };
    dfs(dfs, 0, a.size());
    return ans;
}
```

```cpp
template <class T> int invBit(const vector<T> &a)
{
    // a 是原序列；返回用离散化和 Fenwick 统计的严格逆序对数量。
    Discrete<T> dis(a);
    vector<int> bit(dis.a.size() + 1);
    auto add = [&](int p)
    {
        for (p++; p < (int)bit.size(); p += p & -p)
        {
            bit[p]++;
        }
    };
    auto sum = [&](int p)
    {
        int ans = 0;
        for (; p > 0; p -= p & -p)
        {
            ans += bit[p];
        }
        return ans;
    };
    int ans = 0;
    for (auto it = a.rbegin(); it != a.rend(); it++)
    {
        auto p = dis.id(*it);
        ans += sum(p);
        add(p);
    }
    return ans;
}
```
`invMerge(a)` 与 `invBit(a)` 结果相同；返回值为 `int`，在本模板即 64 位。只做一次静态统计选归并版更直接，还要按值维护频率或排名选 BIT 版；扩展到其他偏序时必须重新确认严格/非严格比较和重复值处理。本机基准（同一组一百万随机 64 位整数、7 轮中位数）归并版 `69ms`、BIT 版 `177ms`，故静态统计默认归并版，BIT 版作值域统计扩展保留。两版均 $O(n\log n)$ 时间、$O(n)$ 额外空间。

### 2.2.004 整体二分

当一批询问都在同一有序答案域上二分、且一次判定能用可撤销的数据结构批量完成时，把「每个询问各自二分」改成递归地一起划分询问与元素：在值域中点 `vm` 处把离散排名 $<vm$ 的元素加入 Fenwick，每个询问看自己区间内已加入的元素数 `c` 决定落入左半还是右半答案域（落右半时把 `k` 扣掉 `c`），本层递归前务必回滚 Fenwick 修改。它要求判定关于答案单调，不支持在线强制查询。本条实例 `rangeKth` 求静态数组区间第 $k$ 小；其中的离散化依赖 [2.2.002 离散化与坐标压缩](#22002) 的 `Discrete`，此处不再重复，而 `Fenwick` 树状数组在本章首次完整给出，后续 [2.2.005 CDQ 分治与三维偏序](#22005)、[2.3.005 区间不同数统计](#23005) 均按编号引用本条。与二分、离散化、BIT 和主席树的选型关系见 [`知识点关系.md`](知识点关系.md)。

```cpp
struct Fenwick
{
    int n = 0;     // n 是下标范围长度。
    vector<int> a; // a 保存从 1 开始的树状数组节点和。

    Fenwick(int m = 0)
    {
        // m 是初始下标范围长度。
        init(m);
    }

    void init(int m)
    {
        // m 是新的下标范围长度；调用后全部频率清零。
        assert(m >= 0); // 调试检查，可删
        n = m;
        a.assign(n + 1, 0);
    }

    void add(int p, int v)
    {
        // p 是从 0 开始的位置，v 是增量。
        assert(0 <= p && p < n); // 调试检查，可删
        for (p++; p <= n; p += p & -p)
        {
            a[p] += v;
        }
    }

    int sum(int r) const
    {
        // r 是右端点；返回半开前缀 [0,r) 的和。
        assert(0 <= r && r <= n); // 调试检查，可删
        int ans = 0;
        for (; r > 0; r -= r & -r)
        {
            ans += a[r];
        }
        return ans;
    }

    int sum(int l, int r) const
    {
        // l、r 是半开区间端点；返回 [l,r) 的和。
        assert(0 <= l && l <= r && r <= n); // 调试检查，可删
        return sum(r) - sum(l);
    }
};

// KthQuery[0..2] 依次表示左端点、右端点、从 1 开始的排名。
using KthQuery = array<int, 3>;

vector<int> rangeKth(const vector<int> &a, vector<KthQuery> qs)
{
    // a 是静态数组，qs 中每项是 {l,r,k}；返回各半开区间第 k 小值。
    if (qs.empty())
    {
        return {};
    }
    assert(!a.empty()); // 调试检查，可删
    for (auto q : qs)
    {
        assert(0 <= q[0] && q[0] < q[1] && q[1] <= (int)a.size()); // 调试检查，可删
        assert(1 <= q[2] && q[2] <= q[1] - q[0]);                  // 调试检查，可删
    }
    Discrete<int> dis(a);
    vector<int> rk(a.size());
    for (int i = 0; i < (int)a.size(); i++)
    {
        rk[i] = dis.id(a[i]);
    }
    vector<int> es(a.size()), ids(qs.size()), ans(qs.size());
    iota(es.begin(), es.end(), 0);
    iota(ids.begin(), ids.end(), 0);
    Fenwick bit(a.size());
    auto solve = [&](auto &&self, int vl, int vr, vector<int> ps, vector<int> qi) -> void
    {
        if (qi.empty())
        {
            return;
        }
        if (vr - vl == 1)
        {
            for (auto id : qi)
            {
                ans[id] = dis.value(vl);
            }
            return;
        }
        auto vm = midpoint(vl, vr);
        vector<int> pl, pr, ql, qr;
        for (auto p : ps)
        {
            if (rk[p] < vm)
            {
                bit.add(p, 1);
                pl.push_back(p);
            }
            else
            {
                pr.push_back(p);
            }
        }
        for (auto id : qi)
        {
            auto &q = qs[id];
            auto c = bit.sum(q[0], q[1]);
            if (q[2] <= c)
            {
                ql.push_back(id);
            }
            else
            {
                q[2] -= c;
                qr.push_back(id);
            }
        }
        for (auto p : pl)
        {
            bit.add(p, -1);
        }
        self(self, vl, vm, move(pl), move(ql));
        self(self, vm, vr, move(pr), move(qr));
    };
    solve(solve, 0, dis.a.size(), move(es), move(ids));
    return ans;
}
```

`KthQuery = {l, r, k}`（半开区间加从 1 开始的排名，须 $1\le k\le r-l$），`rangeKth(a, qs)` 返回各区间第 $k$ 小值；空询问集直接返回空数组，非空询问要求原数组非空。函数内部只改询问副本里的 `k`、不动调用者数据；上面的代码需与本章前导及 [2.2.002](#22002) 的 `Discrete` 拼接编译。整体二分须满足答案单调、修改可按答案域分组、判定状态可回滚，若只是一次静态 `nth_element` 就别套它。答案域离散后大小为 $V$ 时，每层处理全部元素与询问并做 Fenwick 操作，时间 $O((n+q)\log V\log n)$、空间 $O(n+q+V)$。

### 2.2.005 CDQ 分治与三维偏序

统计每个三维点被多少点在三维上同时不大于。先按 `x, y, z` 排序，第一维借排序天然处理，再对完全相同的点合组（否则递归顺序会让相同点得到不同答案）；CDQ 分治把第二维当作「时间维」，只统计左半对右半的贡献，合并时按 `y` 归并、用 Fenwick 查询 `z` 前缀。所用 `Fenwick` 与 [2.2.004 整体二分](#22004) 完全相同，此处依赖该条的 `Fenwick`，不再重复粘贴。

```cpp
// Point3[0..3] 依次是 x、y、z 坐标与原输入编号。
using Point3 = array<int, 4>;

// answer[i] 是三维坐标均不大于第 i 个点的点数。
inline vector<int> dom3(vector<Point3> points)
{
    // points 的每项为 {x,y,z,id}；返回每个原编号的三维非严格支配计数。
    int n = points.size();
    vector<int> coord;
    for (auto point : points)
    {
        coord.push_back(point[2]);
    }
    ranges::sort(coord);
    coord.erase(unique(coord.begin(), coord.end()), coord.end());
    ranges::sort(points,
                 [](const Point3 &a, const Point3 &b)
                 {
                     return tie(a[0], a[1], a[2]) < tie(b[0], b[1], b[2]);
                 });
    struct Node
    {
        // x、y 是原坐标，z 是离散编号，weight 是该坐标的重复点数。
        int x, y, z, weight;
        // ids 保存该组重复点的原编号。
        vector<int> ids;
        // answer 保存当前累计的非严格支配计数。
        long long answer;
    };
    vector<Node> nodes;
    for (auto point : points)
    {
        int z = lower_bound(coord.begin(), coord.end(), point[2]) - coord.begin();
        if (!nodes.empty() && tie(nodes.back().x, nodes.back().y, nodes.back().z) == tie(point[0], point[1], z))
        {
            ++nodes.back().weight;
            ++nodes.back().answer;
            nodes.back().ids.push_back(point[3]);
        }
        else
        {
            nodes.push_back({point[0], point[1], z, 1, {point[3]}, 1});
        }
    }
    vector<int> bit(coord.size() + 1), order(nodes.size()), buffer(nodes.size()), answer(n);
    iota(order.begin(), order.end(), 0);
    auto add = [&](int x, int value)
    {
        for (++x; x < bit.size(); x += x & -x)
        {
            bit[x] += value;
        }
    };
    auto sum = [&](int x)
    {
        int result = 0;
        for (++x; x > 0; x -= x & -x)
        {
            result += bit[x];
        }
        return result;
    };
    function<void(int, int)> cdq = [&](int left, int right)
    {
        if (right - left == 1)
        {
            return;
        }
        int middle = midpoint(left, right);
        cdq(left, middle);
        cdq(middle, right);
        int i = left, j = middle, output = left;
        while (j < right)
        {
            while (i < middle && nodes[order[i]].y <= nodes[order[j]].y)
            {
                add(nodes[order[i]].z, nodes[order[i]].weight);
                buffer[output++] = order[i++];
            }
            nodes[order[j]].answer += sum(nodes[order[j]].z);
            buffer[output++] = order[j++];
        }
        while (i < middle)
        {
            buffer[output++] = order[i++];
        }
        for (int k = left; k < middle; ++k)
        {
            add(nodes[order[k]].z, -nodes[order[k]].weight);
        }
        copy(buffer.begin() + left, buffer.begin() + right, order.begin() + left);
    };
    cdq(0, nodes.size());
    for (auto &node : nodes)
    {
        for (int id : node.ids)
        {
            answer[id] = node.answer;
        }
    }
    return answer;
}

struct Point4
{
    // x、y、z、w 是四维坐标。
    int x, y, z, w;
};

struct Dom4Event
{
    // y、z、w 是后三维坐标；src 表示该点来自较小 x 的左半部。
    int y, z, w;
    bool src;
};

inline long long dom4Cross(vector<Dom4Event> a, int m)
{
    // a 是一次跨段统计的事件，m 是离散后第四维大小；返回后三维均严格递增的跨段点对数。
    sort(a.begin(), a.end(), [](const auto &u, const auto &v)
    {
        return tie(u.y, u.src) < tie(v.y, v.src);
    });
    vector<Dom4Event> buf(a.size());
    vector<int> bit(m + 1);
    auto add = [&](int p, int v)
    {
        for (++p; p <= m; p += p & -p) bit[p] += v;
    };
    auto sum = [&](int p)
    {
        int ans = 0;
        for (; p; p -= p & -p) ans += bit[p];
        return ans;
    };
    long long ans = 0;
    auto cdq = [&](auto &&self, int l, int r) -> void
    {
        if (r - l <= 1) return;
        int mid = (l + r) / 2;
        self(self, l, mid);
        self(self, mid, r);
        int i = l;
        for (int j = mid; j < r; j++)
        {
            while (i < mid && a[i].z < a[j].z)
            {
                if (a[i].src) add(a[i].w, 1);
                i++;
            }
            if (!a[j].src) ans += sum(a[j].w);
        }
        for (int k = l; k < i; k++) if (a[k].src) add(a[k].w, -1);
        merge(a.begin() + l, a.begin() + mid, a.begin() + mid, a.begin() + r,
              buf.begin() + l, [](const auto &u, const auto &v)
        {
            return u.z < v.z;
        });
        copy(buf.begin() + l, buf.begin() + r, a.begin() + l);
    };
    cdq(cdq, 0, a.size());
    return ans;
}

inline long long countFourDimensional(vector<Point4> a)
{
    // a 是四维点集；返回两点四维坐标均严格递增的有序点对数量。
    vector<int> ws;
    for (auto p : a) ws.push_back(p.w);
    sort(ws.begin(), ws.end());
    ws.erase(unique(ws.begin(), ws.end()), ws.end());
    for (auto &p : a) p.w = lower_bound(ws.begin(), ws.end(), p.w) - ws.begin();
    sort(a.begin(), a.end(), [](const auto &u, const auto &v)
    {
        return tie(u.x, u.y, u.z, u.w) < tie(v.x, v.y, v.z, v.w);
    });
    long long ans = 0;
    auto solve = [&](auto &&self, int l, int r) -> void
    {
        if (r - l <= 1) return;
        int mid = (l + r) / 2;
        while (mid < r && a[mid - 1].x == a[mid].x) mid++;
        if (mid == r)
        {
            mid = (l + r) / 2;
            while (mid > l && a[mid - 1].x == a[mid].x) mid--;
            if (mid == l) return;
        }
        self(self, l, mid);
        self(self, mid, r);
        vector<Dom4Event> e;
        e.reserve(r - l);
        for (int i = l; i < mid; i++) e.push_back({a[i].y, a[i].z, a[i].w, true});
        for (int i = mid; i < r; i++) e.push_back({a[i].y, a[i].z, a[i].w, false});
        ans += dom4Cross(move(e), ws.size());
    };
    solve(solve, 0, a.size());
    return ans;
}
```

`Point3 = {x, y, z, id}`，`id` 须覆盖 $[0,n)$ 且唯一，`dom3(p)` 返回每个原下标的支配计数；例如 `{{1,1,1,0},{1,1,1,1},{2,0,2,2},{2,2,2,3}}` 得 `{2,2,1,4}`。计数含点自身和完全相同的其他点，严格偏序需调整排序、分组和查询边界。排序与 CDQ 共 $O(n\log^2 n)$ 时间，Fenwick、归并缓冲和节点数组共 $O(n)$ 空间。同一条目的 `countFourDimensional` 统计四维坐标均严格递增的有序点对；外层按第一维分治，内层 CDQ 处理后三维，复杂度 $O(n\log^3 n)$，坐标任一维相等均不计入。

固定例覆盖重复点、不可比点、被全部点支配的点和全同点（`Fenwick` 取自 [2.2.004](#22004)）：

### 2.2.006 分数级联（Fractional Cascading）

给定 $k$ 个静态有序表，需要很多次把同一个值 $x$ 分别送进每张表求 `lower_bound`。逐表二分单次是 $O(\sum_i\log n_i)$；分数级联预处理后只对第一张增强表二分，随后逐层沿「桥」转移，把单次查询降到 $O(\log N+k)$，其中 $N=\sum_i n_i$。构造从最后一层向前：增强表 $B_i$ 把原表 $A_i$ 与下一层 $B_{i+1}$ 的约一半元素（隔一个采样一个）合并，每个增强元素记录它在 $A_i$ 中的下界 `own` 与在 $B_{i+1}$ 中的下界 `down`。因为下层每隔一个就被采样，沿 `down` 落到的位置与真实下界至多差一步（查询里的 `p--` 修正这一步），所以后续每层只需常数次比较；采样保证所有增强表总长仍为 $O(N)$。典型用于线段树或树链分解后同时查多份有序目录，以及计算几何中沿相邻层级定位同一坐标。

```cpp
template <class T> struct FracCascade
{
    struct Item
    {
        T x;           // x 是增强表中的键值。
        int own, down; // own 指向本层原表下界，down 指向下一层增强表下界。
    };

    vector<vector<T>> a;    // a 保存各层原始有序表。
    vector<vector<Item>> b; // b 保存采样合并后的增强表和桥指针。

    explicit FracCascade(vector<vector<T>> src) : a(move(src)), b(a.size())
    {
        // src 是若干个按同一规则升序排列的静态表。
        for (auto &x : a)
        {
            assert(is_sorted(x.begin(), x.end())); // 调试检查，可删
        }
        for (int i = (int)a.size() - 1; i >= 0; i--)
        {
            auto v = a[i];
            if (i + 1 < (int)b.size())
            {
                for (int j = 1; j < (int)b[i + 1].size(); j += 2)
                {
                    v.push_back(b[i + 1][j].x);
                }
            }
            sort(v.begin(), v.end());
            v.erase(unique(v.begin(), v.end()), v.end());
            for (auto x : v)
            {
                auto p = lower_bound(a[i].begin(), a[i].end(), x) - a[i].begin();
                int q = 0;
                if (i + 1 < (int)b.size())
                {
                    q = lower_bound(b[i + 1].begin(),
                                    b[i + 1].end(),
                                    x,
                                    [](const Item &u, const T &rhs)
                                    {
                                        return u.x < rhs;
                                    }) -
                        b[i + 1].begin();
                }
                b[i].push_back({x, p, q});
            }
        }
    }

    vector<int> lowerBound(const T &x) const
    {
        // x 是所有表共用的查询值；返回每个原表中的 lower_bound 位置。
        vector<int> ans(a.size());
        int p = 0;
        if (!b.empty())
        {
            p = lower_bound(b[0].begin(),
                            b[0].end(),
                            x,
                            [](const Item &u, const T &rhs)
                            {
                                return u.x < rhs;
                            }) -
                b[0].begin();
        }
        for (int i = 0; i < (int)a.size(); i++)
        {
            ans[i] = p == (int)b[i].size() ? (int)a[i].size() : b[i][p].own;
            if (i + 1 == (int)a.size())
            {
                break;
            }
            p = p == (int)b[i].size() ? (int)b[i + 1].size() : b[i][p].down;
            if (p && b[i + 1][p - 1].x >= x)
            {
                p--;
            }
        }
        return ans;
    }
};
```

每个输入表须按同一规则升序排列，构造后不支持插入、删除或改值。`fc.lowerBound(x)` 返回长度 $k$ 的位置数组，第 $i$ 项是 $A_i$ 中第一个不小于 $x$ 的下标、无则等于 $A_i$ 长度；例如三张表 `{{-3,1,5,9},{0,2,8},{-5,4,4,10}}` 查 `4` 得 `{2,2,1}`。只有一次查询或表数很少时预处理不划算，有动态修改时改用平衡树、线段树套有序结构或重建分块。当前实现逐层排序建桥，构造 $O(N\log N)$ 时间、$O(N)$ 空间，单次查询 $O(\log N+k)$；改用线性归并建每层可把预处理降到 $O(N)$。

固定查询覆盖小于全部元素、重复值、空表、命中元素和大于全部元素：

```cpp
signed main()
{
    vector<vector<int>> a{{-3, 1, 5, 9}, {}, {0, 2, 8}, {-5, 4, 4, 10}};
    FracCascade<int> fc(a);
    assert((fc.lowerBound(-10) == vector<int>{0, 0, 0, 0}));
    assert((fc.lowerBound(4) == vector<int>{2, 0, 2, 1}));
    assert((fc.lowerBound(5) == vector<int>{2, 0, 2, 3}));
    assert((fc.lowerBound(11) == vector<int>{4, 0, 3, 4}));
    auto ans = fc.lowerBound(4);
    cout << ans[0] << ' ' << ans[1] << ' ' << ans[2] << ' ' << ans[3] << '\n'; // 2 0 2 1
    return 0;
}
```

### 2.2.007 扫描线

矩形面积并是扫描线最常用、也最便于完整测试的实例：把每个矩形拆成左右两条竖边，按 `x` 排序成进入（`+1`）/离开（`-1`）事件，线段树维护当前 `y` 轴被覆盖的总长度。相邻两事件横坐标之间活跃矩形集合不变，故面积增量为「当前 `y` 覆盖长度 × 横向宽度」。线段树每个节点记覆盖次数 `cov` 和实际覆盖长度 `len`：`cov` 非零时整段有效，为零时才向下合并子节点的 `len`——正因如此这棵覆盖线段树不需要 lazy 下传。相同 `x` 的事件必须成组处理，避免出现零宽度的中间状态。

```cpp
// Rect[0..3] 依次表示左横坐标、下纵坐标、右横坐标、上纵坐标。
using Rect = array<int, 4>;

int rectArea(const vector<Rect> &rs)
{
    // rs 中每项是 {左、下、右、上}；返回所有半开矩形的面积并。
    // Event[0..3] 依次表示横坐标、下纵坐标、上纵坐标、覆盖次数变化量。
    using Event = array<int, 4>;
    vector<Event> es;
    vector<int> ys;
    for (auto [xl, yl, xr, yr] : rs)
    {
        if (xl >= xr || yl >= yr)
        {
            continue;
        }
        es.push_back({xl, yl, yr, 1});
        es.push_back({xr, yl, yr, -1});
        ys.push_back(yl);
        ys.push_back(yr);
    }
    if (es.empty())
    {
        return 0;
    }
    sort(ys.begin(), ys.end());
    ys.erase(unique(ys.begin(), ys.end()), ys.end());
    sort(es.begin(),
         es.end(),
         [](const auto &a, const auto &b)
         {
             return a[0] < b[0];
         });
    vector<int> cov(ys.size() * 4);
    vector<int> len(ys.size() * 4);
    auto add = [&](auto &&self, int p, int l, int r, int ql, int qr, int d) -> void
    {
        if (ql <= l && r <= qr)
        {
            cov[p] += d;
        }
        else
        {
            auto m = midpoint(l, r);
            if (ql < m)
            {
                self(self, p * 2, l, m, ql, qr, d);
            }
            if (m < qr)
            {
                self(self, p * 2 + 1, m, r, ql, qr, d);
            }
        }
        if (cov[p])
        {
            len[p] = ys[r] - ys[l];
        }
        else if (r - l == 1)
        {
            len[p] = 0;
        }
        else
        {
            len[p] = len[p * 2] + len[p * 2 + 1];
        }
    };
    int ans = 0;
    auto pre = es[0][0];
    for (int i = 0; i < (int)es.size();)
    {
        auto width = es[i][0] - pre;
        ans += len[1] * width;
        auto j = i;
        while (j < (int)es.size() && es[j][0] == es[i][0])
        {
            auto [x, yl, yr, d] = es[j];
            auto l = lower_bound(ys.begin(), ys.end(), yl) - ys.begin();
            auto r = lower_bound(ys.begin(), ys.end(), yr) - ys.begin();
            add(add, 1, 0, ys.size() - 1, l, r, d);
            j++;
        }
        pre = es[i][0];
        i = j;
    }
    return ans;
}
```

`Rect = {xl, yl, xr, yr}`，区域为 $[x_l,x_r)\times[y_l,y_r)$，退化矩形自动忽略；`rectArea(rs)` 返回面积并，例如 `{{0,0,2,2},{1,1,3,2}}` 得 `5`。调用者须保证坐标差、扫描线覆盖长度及最终面积都能由 `int` 表示；确实需要更宽面积时把这份短代码中的坐标和面积类型一起改宽。$2n$ 个事件、$2n$ 个纵坐标，排序与更新共 $O(n\log n)$ 时间、$O(n)$ 空间。

### 2.2.008 单调栈、单调队列

共同直觉是：新元素到来时，所有既不优于它、又比它更早的候选都可永久删除，因为新元素值更优且失效更晚。`prevLess` 用栈求每个位置左侧最近严格更小元素；`windowMin` / `windowMax` 用双端队列维护固定窗口的最值，比栈多一步从队首删除滑出窗口（`q.front() <= i - k`）的下标。比较符号决定「严格」还是「允许相等」——这里弹出条件用 `>=`（最小值）/ `<=`（最大值），留下的是严格意义的最近更小/更大，照抄前务必按题意核对。

```cpp
template <class T> vector<int> prevLess(const vector<T> &a)
{
    // a 是原序列；返回每个位置左侧最近严格更小元素的下标，不存在时为 -1。
    // 改求最近严格更大时，把弹栈条件 >= 改为 <=；若允许相等，则分别用 > 或 <。
    vector<int> stk, ans(a.size(), -1);
    for (int i = 0; i < (int)a.size(); i++)
    {
        while (!stk.empty() && a[stk.back()] >= a[i])
        {
            stk.pop_back();
        }
        if (!stk.empty())
        {
            ans[i] = stk.back();
        }
        stk.push_back(i);
    }
    return ans;
}
```

```cpp
template <class T> vector<T> windowMin(const vector<T> &a, int k)
{
    // a 是原序列，k 是固定窗口长度；返回每个连续窗口的最小值。
    // 改最大值时把维护队尾的 >= 改为 <=；过期下标的队首删除条件不变。
    assert(1 <= k && k <= (int)a.size()); // 调试检查，可删
    deque<int> q;
    vector<T> ans;
    for (int i = 0; i < (int)a.size(); i++)
    {
        while (!q.empty() && q.front() <= i - k)
        {
            q.pop_front();
        }
        while (!q.empty() && a[q.back()] >= a[i])
        {
            q.pop_back();
        }
        q.push_back(i);
        if (i + 1 >= k)
        {
            ans.push_back(a[q.front()]);
        }
    }
    return ans;
}
```

```cpp
template <class T> vector<T> windowMax(const vector<T> &a, int k)
{
    // a 是原序列，k 是固定窗口长度；返回每个连续窗口的最大值。
    // 改最小值时把维护队尾的 <= 改为 >=；过期下标的队首删除条件不变。
    assert(1 <= k && k <= (int)a.size()); // 调试检查，可删
    deque<int> q;
    vector<T> ans;
    for (int i = 0; i < (int)a.size(); i++)
    {
        while (!q.empty() && q.front() <= i - k)
        {
            q.pop_front();
        }
        while (!q.empty() && a[q.back()] <= a[i])
        {
            q.pop_back();
        }
        q.push_back(i);
        if (i + 1 >= k)
        {
            ans.push_back(a[q.front()]);
        }
    }
    return ans;
}
```

`prevLess(a)` 返回各位置左侧最近严格更小元素的下标（无则 `-1`），`windowMin(a, k)` / `windowMax(a, k)` 返回每个连续窗口的最值。模板弹出满足 $a_{stk.back()}\ge a_i$ 的元素，故留下的是严格更小；要「更小或相等」就改成只在严格大于时弹出。窗口接口要求 $1\le k\le n$。每个下标至多进出一次，时间 $O(n)$、空间 $O(n)$。

### 2.2.009 滑动窗口与区间最值

连续定长窗口的最值直接复用 [2.2.008 单调栈、单调队列](#22008) 的 `windowMin` / `windowMax`：队列保存值单调且下标仍在窗口内的候选，队首恒为当前答案，固定窗口下每个下标只进出一次，$O(n)$ 时间；除返回数组外额外空间为 $O(k)$，代码不再重复。真正的分界在于查询是否按右端点顺序滑动——一旦不是（窗口长度可变或任意区间查询），单调队列的不变量就失效，应换成 `multiset`（$O(n\log k)$）、对顶双堆、ST 表或线段树。切忌用 `priority_queue` 后再线性删除过期元素；若用堆，必须给元素带上下标并在堆顶循环清理过期项。

### 2.2.010 最长上升子序列及输出方案

求严格上升子序列并恢复一组原数组下标。核心不变量是 `val[len]` 保存长度为 $len+1$ 的上升子序列所能取得的最小结尾——结尾越小越有利于将来扩展，因此用 `lower_bound` 找到第一个不小于 `a[i]` 的位置替换即可，不损失最优性。`pos[len]` 记录该最小结尾来自哪个原下标，`pre[i]` 记录位置 $i$ 在方案中的前驱，最后从最长长度的结尾沿 `pre` 反向恢复一条合法方案。

```cpp
vector<int> lis(const vector<int> &a)
{
    // a 是原序列；返回一组严格上升子序列的原数组下标。
    vector<int> val, pos, pre(a.size(), -1);
    for (int i = 0; i < (int)a.size(); i++)
    {
        auto p = lower_bound(val.begin(), val.end(), a[i]) - val.begin();
        if (p == (int)val.size())
        {
            val.push_back(a[i]);
            pos.push_back(i);
        }
        else
        {
            val[p] = a[i];
            pos[p] = i;
        }
        if (p)
        {
            pre[i] = pos[p - 1];
        }
    }
    vector<int> ans;
    for (auto x = pos.empty() ? -1 : pos.back(); x >= 0; x = pre[x])
    {
        ans.push_back(x);
    }
    reverse(ans.begin(), ans.end());
    return ans;
}
```

`lis(a)` 返回一条最长严格上升子序列的原数组下标（不是值），需要打印子序列元素时用 `a[p]`。严格上升用 `lower_bound`，改求最长非降子序列则换成 `upper_bound`。时间 $O(n\log n)$，尾值、结尾下标和前驱数组共 $O(n)$ 空间。

### 2.2.011 二维 LIS / LCIS

本条是两个只有名字相近、不能互相替代的问题。二维 LIS 在点集里找两维都严格递增的最长链（信封嵌套、二维偏序、宽高同增等）：先按第一维升序、同第一维时按第二维降序排序，再对第二维做一维严格 LIS。同第一维降序是保证严格性的关键——它让同组元素在第二维上不构成上升关系，一维化后就不会误选两个第一维相等的点；若某维允许相等，排序并列规则与 `lower_bound` / `upper_bound` 须一并调整。LCIS 在两个序列中找既是公共子序列、值又严格递增的最长序列，无法用「先 LCS 再 LIS」拼出：令 $f_j$ 为已扫描 $a$ 的前缀中以 $b_j$ 结尾的 LCIS 长度，处理 $x=a_i$ 时从左到右维护所有满足 $b_j<x$ 的 $f_j$ 最大值 `best`，遇到 $b_j=x$ 就令 $f_j\leftarrow\max(f_j,best+1)$；因为 `best` 只从严格小于 $x$ 的状态更新，同一轮不会重复用到 $x$ 自身。

```cpp
int lis2D(vector<pair<int, int>> a)
{
    // a 保存二维点并按值复制；返回两维都严格增加的最长链长度。
    sort(a.begin(),
         a.end(),
         [](const auto &x, const auto &y)
         {
             if (x.first != y.first)
             {
                 return x.first < y.first;
             }
             return x.second > y.second;
         });
    vector<int> d;
    for (auto [x, y] : a)
    {
        auto it = lower_bound(d.begin(), d.end(), y);
        if (it == d.end())
        {
            d.push_back(y);
        }
        else
        {
            *it = y;
        }
    }
    return d.size();
}
```

```cpp
int lcis(const vector<int> &a, const vector<int> &b)
{
    // a、b 是两个原序列；返回最长公共严格上升子序列长度。
    vector<int> f(b.size());
    for (auto x : a)
    {
        int best = 0;
        for (int j = 0; j < (int)b.size(); j++)
        {
            if (b[j] < x)
            {
                chmax(best, f[j]);
            }
            else if (b[j] == x)
            {
                chmax(f[j], best + 1);
            }
        }
    }
    return f.empty() ? 0 : *max_element(f.begin(), f.end());
}
```

`lis2D(points)` 接收二元组副本、只返回链长而不恢复点链，重复点最多选一个；`lcis(a, b)` 只返回长度，要恢复方案得为每个 $f_j$ 额外记录前驱位置和来自 $a$ 的层次。二维 LIS 为 $O(n\log n)$ 时间、$O(n)$ 空间；两序列长 $n,m$ 时 LCIS 为 $O(nm)$ 时间、$O(m)$ 空间。

### 2.2.012 最大全 1 子矩形

把 01 矩阵逐行压成直方图：以当前行为底的全 1 矩形，其每列可用高度就是该列往上连续 1 的数量，于是问题化为「直方图中最大矩形」并对每行调用一次。直方图里每根柱子的最大贡献由它左右第一个更矮的柱子界定，单调栈在柱子被弹出时一次性确定其右边界，末尾补一个高度 0 的哨兵负责清空栈中残余柱子。

```cpp
int maxRect(const vector<int> &h)
{
    // h 是非负直方图柱高；返回由 Acc 可表示的最大矩形面积。
    vector<int> stk;
    int ans = 0;
    for (int i = 0; i <= (int)h.size(); i++)
    {
        auto x = i == (int)h.size() ? 0 : h[i];
        while (!stk.empty() && h[stk.back()] >= x)
        {
            auto p = stk.back();
            stk.pop_back();
            auto l = stk.empty() ? 0 : stk.back() + 1;
            chmax(ans, h[p] * (i - l));
        }
        stk.push_back(i);
    }
    return ans;
}

int maxRect(const vector<vector<int>> &a)
{
    // a 是规则矩阵，非零元素视为 1；返回由 Acc 可表示的最大全 1 子矩形面积。
    if (a.empty() || a[0].empty())
    {
        return 0;
    }
    vector<int> h(a[0].size());
    int ans = 0;
    for (auto &row : a)
    {
        assert(row.size() == h.size()); // 调试检查，可删
        for (int j = 0; j < (int)h.size(); j++)
        {
            h[j] = row[j] ? h[j] + 1 : 0;
        }
        chmax(ans, maxRect(h));
    }
    return ans;
}
```

`maxRect(grid)` 接收规则矩阵、非零元素视为 1，返回最大全 1 子矩形面积；重载 `maxRect(h)` 直接对非负柱高的直方图求最大矩形。调用者须保证柱高、宽度乘积和最终面积能由 `int` 表示。若还要矩形的坐标，须在弹栈时一并记录左右边界和当前行。$n\times m$ 矩阵总时间 $O(nm)$、额外空间 $O(m)$；直方图长度为 $m$ 时为 $O(m)$ 时间和 $O(m)$ 额外空间。

### 2.2.013 约瑟夫问题

$n$ 人编号 $0\ldots n-1$、每次数到第 $k$ 人出局，求最后幸存者。把规模 $i$ 的答案 $f(i)$ 由 $f(i-1)$ 反推：删掉第一个出局者后余下 $i-1$ 人重新编号，相当于整体偏移 $k$，于是 $f(i)=(f(i-1)+k)\bmod i$，$f(1)=0$。只有一个状态和一段短循环，直接内联进解题代码即可，无需封装。

```cpp
// n 是人数，k 是报数步长，ans 是从 0 开始的幸存者编号。
assert(n > 0 && k > 0); // 调试检查，可删
int ans = 0;
if (n >= 2)
{
    int i = 2;
    while (true)
    {
        int x = k % i;
        ans = ans >= i - x ? ans - (i - x) : ans + x;
        if (i == n)
        {
            break;
        }
        i++;
    }
}
```

循环结束后的 `ans` 是从 0 开始的幸存者编号，题目若从 1 编号则答案加 1。每轮先取 `k % i`，再用比较和减法实现模加，避免 `ans + k % i` 溢出；循环在处理 `i == n` 后先退出再递增，因此 `n`、`k` 取完整正 64 位范围时不会在取模前或末次自增时溢出。该递推只求最后一人，不输出完整删除顺序。$O(n)$ 时间、$O(1)$ 空间。

### 2.2.014 快速选择 / 线性期望第 k 元素

只要第 $k$ 小而不需完整排序时，划分后只递归含第 $k$ 位的那一侧、丢弃另一侧，期望线性。`nthValue` 直接包了标准库 `nth_element`，经过充分优化，是默认实现；`quickSelect` 手写随机枢轴 + 三路划分，把等于枢轴的元素聚在中间，对高重复数据更稳，供不能用 STL 或需定制状态时备用。

```cpp
template <class T> T nthValue(vector<T> a, int k)
{
    // a 是按值复制的数组，k 是从 0 开始的排名；返回第 k 小值。
    assert(0 <= k && k < (int)a.size()); // 调试检查，可删
    nth_element(a.begin(), a.begin() + k, a.end());
    return a[k];
}

template <class T, class Rng> T quickSelect(vector<T> a, int k, Rng &rng)
{
    // a 是按值复制的数组，k 是从 0 开始的排名，rng 是随机源；返回第 k 小值。
    assert(0 <= k && k < (int)a.size()); // 调试检查，可删
    int l = 0, r = a.size();
    while (r - l > 1)
    {
        auto p = a[uniform_int_distribution<int>(l, r - 1)(rng)];
        auto m1 = partition(a.begin() + l,
                            a.begin() + r,
                            [&](const T &x)
                            {
                                return x < p;
                            });
        auto m2 = partition(m1,
                            a.begin() + r,
                            [&](const T &x)
                            {
                                return !(p < x);
                            });
        auto x = m1 - a.begin();
        auto y = m2 - a.begin();
        if (k < x)
        {
            r = x;
        }
        else if (k >= y)
        {
            l = y;
        }
        else
        {
            return p;
        }
    }
    return a[l];
}
```

两者的 `k` 都从 0 开始：`nthValue(a, k)` 是主版本，`quickSelect(a, k, rng)` 是随机备用。本机基准（100 组、每组十万元素、7 轮中位数）`nth_element=50ms`、手写三路 `61ms`，故默认 `nth_element`。标准库对 `nth_element` 保证线性期望比较次数，手写版期望 $O(n)$、最坏 $O(n^2)$，两者都按值复制输入需 $O(n)$ 空间。

## 2.3 莫队与离线查询

### 2.3.001 普通莫队

当单个端点的加入/删除都能 $O(1)$ 维护、且询问允许离线重排时，把大量区间查询降到约 $O(n\sqrt q)$ 次状态更新。按左端点分块排序，使同块内右端点大体单调移动，奇偶块内右端点反向排序进一步减少折返。调度函数本身只负责移动当前 $[l,r)$，真正的答案状态交由四个端点回调（`addL` / `addR` / `delL` / `delR`）维护，因此保持为单函数而非封装成类。普通、带修改、回滚、二次离线莫队与专用离线算法之间的取舍见 [`知识点关系.md`](知识点关系.md)。

```cpp
// MoQuery[0..2] 依次表示左端点、右端点、答案编号。
using MoQuery = array<int, 3>;

template <class Ans, class AddL, class AddR, class DelL, class DelR, class Get>
vector<Ans> mo(int n, vector<MoQuery> qs, AddL addL, AddR addR, DelL delL, DelR delR, Get get)
{
    // n 是数组长度，qs 是询问；四个端点回调维护状态，get 返回当前答案。
    auto z = max<int>(1, (int)(n / sqrtl(max<int>(1, qs.size()))));
    sort(qs.begin(),
         qs.end(),
         [&](const auto &a, const auto &b)
         {
             auto x = a[0] / z, y = b[0] / z;
             if (x != y)
             {
                 return x < y;
             }
             return x & 1 ? a[1] > b[1] : a[1] < b[1];
         });
    vector<Ans> ans(qs.size());
    int l = 0, r = 0;
    for (auto q : qs)
    {
        while (l > q[0])
        {
            addL(--l);
        }
        while (r < q[1])
        {
            addR(r++);
        }
        while (l < q[0])
        {
            delL(l++);
        }
        while (r > q[1])
        {
            delR(--r);
        }
        ans[q[2]] = get();
    }
    return ans;
}
```
用 `auto ans = mo<int>(n, qs, addL, addR, delL, delR, get)` 调用，`MoQuery={l,r,id}`。询问使用 `[l, r)`，`id` 必须覆盖 $[0, q)$。左右端操作不对称时分别实现四个回调，对称时可以对 `add`/`del` 传同一个函数。排序为 $O(q\log q)$；块长为 $B$ 时端点移动上界为 $O\left(\frac{n^2}{B}+qB\right)$，代码取 $B\approx\frac{n}{\sqrt q}$，得到 $O(n\sqrt q+q\log q)$ 时间；除维护状态外，调度额外空间为 $O(q)$。

当区间端点位于较大坐标范围、又不想为块长调参时，可以按二维端点的 Hilbert 曲线排序。递归把每个 $2^k\times2^k$ 正方形分成四块，并在相邻块之间旋转方向，使相邻询问的端点通常同时较近；这只改变访问顺序，不改变莫队状态。`moHilbert` 仍使用半开区间和单个 `add`/`del` 回调，空区间也允许；实现要求数组长度不超过 $2^{31}$，以便把二维键压进无符号 $64$ 位。

```cpp
unsigned long long hilbertOrder(int x, int y, int power, int rotate = 0)
{
    // x、y 是 [0,2^power) 内的坐标，power 不超过 31；返回 Hilbert 序键。
    if (!power)
    {
        return 0;
    }
    int h = 1LL << (power - 1);
    int seg = x < h ? (y < h ? 0 : 3) : (y < h ? 1 : 2);
    seg = (seg + rotate) & 3;
    static constexpr int delta[4] = {3, 0, 0, 1};
    int nextRot = (rotate + delta[seg]) & 3;
    unsigned long long z = 1ULL << (2 * power - 2);
    unsigned long long sub = hilbertOrder(x & (h - 1), y & (h - 1), power - 1, nextRot);
    return (unsigned long long)seg * z + (seg == 1 || seg == 2 ? sub : z - sub - 1);
}

template <class Ans, class Add, class Del, class Get>
vector<Ans> moHilbert(int n, vector<MoQuery> qs, Add add, Del del, Get get)
{
    // n 是数组长度，qs 是半开区间询问；add/del 接收下标，get 返回当前答案。
    int power = 0;
    while ((1LL << power) < max<int>(1, n))
    {
        power++;
    }
    assert(power <= 31);
    sort(qs.begin(), qs.end(), [&](const MoQuery &a, const MoQuery &b)
    {
        int ax = min<int>(a[0], max<int>(0, n - 1));
        int ay = min<int>(max<int>(0, a[1] - 1), max<int>(0, n - 1));
        int bx = min<int>(b[0], max<int>(0, n - 1));
        int by = min<int>(max<int>(0, b[1] - 1), max<int>(0, n - 1));
        return hilbertOrder(ax, ay, power) < hilbertOrder(bx, by, power);
    });
    vector<Ans> ans(qs.size());
    int l = 0, r = 0;
    for (auto q : qs)
    {
        while (l > q[0])
        {
            add(--l);
        }
        while (r < q[1])
        {
            add(r++);
        }
        while (l < q[0])
        {
            del(l++);
        }
        while (r > q[1])
        {
            del(--r);
        }
        ans[q[2]] = get();
    }
    return ans;
}
```

`moHilbert(n,qs,add,del,get)` 与普通 `mo` 的答案接口相同，`MoQuery={l,r,id}` 且 `id` 从 $0$ 开始。排序为 $O(q\log q)$，端点移动次数取决于 Hilbert 曲线的局部性，通常不需要显式块长；它不适合带修改时间轴，带修改仍使用 [2.3.002 带修改莫队](#23002)。

下面是普通莫队、Hilbert 莫队的最小可运行调用：

```cpp
vector<int> a{1, 2, 1, 3};
vector<MoQuery> qs{{0, 3, 0}, {1, 4, 1}};
int cur = 0;
auto add = [&](int p) { cur += a[p]; };
auto del = [&](int p) { cur -= a[p]; };
auto get = [&]() { return cur; };
assert((mo<int>(4, qs, add, add, del, del, get) == vector<int>{4, 6}));
cur = 0;
assert((moHilbert<int>(4, qs, add, del, get) == vector<int>{4, 6}));
```

### 2.3.002 带修改莫队

当询问之间夹有单点修改时，给莫队再加一维时间轴 `t`，让修改既能向前应用又能向后撤销。每个询问记录它之前已发生的修改数，块长取 $n^{2/3}$，排序时同时控制左端、右端和时间指针三者的移动。应用或撤销一次修改时，如果修改位置正落在当前区间内，必须先移除旧贡献、再改值、再加入新贡献，漏掉任一步都会让状态与时间轴不一致。

```cpp
// ModifyQuery[0..3] 依次表示左端点、右端点、答案编号、修改时间。
using ModifyQuery = array<int, 4>;

template <class Ans, class Add, class Del, class Change, class Get>
vector<Ans> moModify(int n, vector<ModifyQuery> qs, Add add, Del del, Change change, Get get)
{
    // n 是数组长度，qs 含修改时间；add/del 维护端点，change(p,forward,l,r) 切换第 p 次修改，get 返回答案。
    auto z = max<int>(1, (int)powl(max<int>(1, n), 2.0L / 3));
    sort(qs.begin(),
         qs.end(),
         [&](const auto &a, const auto &b)
         {
             auto al = a[0] / z, bl = b[0] / z;
             if (al != bl)
             {
                 return al < bl;
             }
             auto ar = a[1] / z, br = b[1] / z;
             if (ar != br)
             {
                 return al & 1 ? ar > br : ar < br;
             }
             return ar & 1 ? a[3] > b[3] : a[3] < b[3];
         });
    vector<Ans> ans(qs.size());
    int l = 0, r = 0, t = 0;
    for (auto q : qs)
    {
        while (t < q[3])
        {
            change(t++, true, l, r);
        }
        while (t > q[3])
        {
            change(--t, false, l, r);
        }
        while (l > q[0])
        {
            add(--l);
        }
        while (r < q[1])
        {
            add(r++);
        }
        while (l < q[0])
        {
            del(l++);
        }
        while (r > q[1])
        {
            del(--r);
        }
        ans[q[2]] = get();
    }
    return ans;
}
```

调用 `moModify<int>(n, qs, add, del, change, get)`，`ModifyQuery={l,r,id,t}` 中 `id` 须覆盖 $[0,q)$，`t` 是该询问前的修改次数且满足 $0\le t\le c$。`change(p, forward, l, r)` 中 `p` 是从 0 开始的修改编号；修改位置当前位于 $[l, r)$ 时，回调必须同步删除旧贡献、写入新值、加入新贡献，反向时恢复旧值。块长取 $n^{2/3}$，在 $n$、$q$ 和修改数同阶时状态移动为 $O\left(n^{5/3}\right)$，排序为 $O(q\log q)$，空间为 $O(n+q+c)$（$c$ 是修改数）。

调用示例（区间和、一次修改）：

```cpp
vector<int> b{1, 2, 3};
vector<ModifyQuery> mq{{0, 3, 0, 1}};
int sum = 0;
auto addM = [&](int p) { sum += b[p]; };
auto delM = [&](int p) { sum -= b[p]; };
auto change = [&](int p, bool forward, int l, int r)
{
    int pos = 1, old = 2, now = 5;
    if (p != 0) return;
    if (l <= pos && pos < r) sum += forward ? now - old : old - now;
    b[pos] = forward ? now : old;
};
auto getM = [&]() { return sum; };
assert(moModify<int>(3, mq, addM, delM, change, getM)[0] == 9);
```

### 2.3.003 回滚莫队

当状态只能廉价加入、却难以删除时（如维护区间最大值、可撤销并查集），改用回滚莫队：右端在同一左端块内按升序单调扩展并跨询问保留，左端只对当前询问临时补入、回答后立刻撤销到快照；询问区间完全落在一个块内时直接临时加入再撤销。算法本身仍只是一次离线调度，历史栈等可回滚状态由调用者维护。

```cpp
template <class Ans, class Add, class Snap, class Undo, class Get>
vector<Ans> rollbackMo(int n, vector<MoQuery> qs, Add add, Snap snap, Undo undo, Get get)
{
    // n 是数组长度，qs 是询问；add 加入位置，snap/undo 管理快照，get 返回当前答案。
    auto z = max<int>(1, (int)sqrtl(max<int>(1, n)));
    sort(qs.begin(),
         qs.end(),
         [&](const auto &a, const auto &b)
         {
             auto x = a[0] / z, y = b[0] / z;
             return x != y ? x < y : a[1] < b[1];
         });
    vector<Ans> ans(qs.size());
    auto empty = snap();
    for (int i = 0; i < (int)qs.size();)
    {
        auto k = qs[i][0] / z;
        auto j = i;
        while (j < (int)qs.size() && qs[j][0] / z == k)
        {
            j++;
        }
        auto mid = min<int>(n, (k + 1) * z);
        auto r = mid;
        for (auto p = i; p < j; p++)
        {
            auto q = qs[p];
            if (q[1] <= mid)
            {
                auto s = snap();
                for (auto x = q[0]; x < q[1]; x++)
                {
                    add(x);
                }
                ans[q[2]] = get();
                undo(s);
                continue;
            }
            while (r < q[1])
            {
                add(r++);
            }
            auto s = snap();
            for (auto x = mid - 1; x >= q[0]; x--)
            {
                add(x);
            }
            ans[q[2]] = get();
            undo(s);
        }
        undo(empty);
        i = j;
    }
    return ans;
}
```
调用 `rollbackMo<int>(n, qs, add, snap, undo, get)`，`MoQuery={l,r,id}`；`snap()` 返回历史栈大小等快照，`undo(s)` 必须精确恢复到该状态，块内短询问在临时加入后回滚。块长为 $B$ 时右端扩展为 $O\left(\frac{n^2}{B}\right)$，短询问与左端临时扩展为 $O(qB)$，取 $B\approx\sqrt n$ 得 $O((n+q)\sqrt n)$，排序为 $O(q\log q)$；除调用者保存的回滚历史外，调度额外空间为 $O(q)$。

回调可以用一个历史栈实现可撤销的区间和：

```cpp
vector<int> c{1, 2, 3};
vector<MoQuery> rq{{0, 2, 0}};
int val = 0;
vector<int> hist;
auto addR = [&](int p) { hist.push_back(val); val += c[p]; };
auto snap = [&]() { return (int)hist.size(); };
auto undo = [&](int s)
{
    while ((int)hist.size() > s)
    {
        val = hist.back();
        hist.pop_back();
    }
};
auto getR = [&]() { return val; };
assert(rollbackMo<int>(3, rq, addR, snap, undo, getR)[0] == 3);
```

### 2.3.004 二次离线莫队

当区间答案是点对贡献之和、普通莫队每移动一个端点仍要扫描整段才能算出新增贡献时，用二次离线把这份代价均摊掉。前提是答案能写成

$$
F(l,r)=\sum_{l\le i<j<r}w(a_i,a_j),
$$

并且能预处理或离线回答前缀贡献 $G(p,x)=\sum_{0\le i<x}w(a_i,a_p)$——此时加入右端点 $p$ 的增量是 $G(p,p)-G(p,l)$，加入左端点同理。于是第一次莫队并不立即计算昂贵的端点贡献，而是把它拆成若干带正负号的「端点对某段前缀」的 $G$ 事件；第二次沿前缀位置从左到右扫描，用值域计数一次性回答整批事件。下面给出的异或点对是一个完整问题实例（统计区间内 $\operatorname{popcount}(a_i\oplus a_j)=k$ 的无序点对数），其中的值域计数只对这一贡献函数成立，不能当成对任意 $w$ 都通用的类。

```cpp
vector<int> xorPairs(const vector<int> &a, const vector<pair<int, int>> &qs, int k, int bits)
{
    // a 是 bits 位非负整数，qs 是半开区间，k 是目标异或位数；返回各区间点对数。
    assert(0 <= bits && bits <= 20); // 调试检查，可删
    auto n = (int)a.size();
    auto lim = 1LL << bits;
    for (auto x : a)
    {
        assert(0 <= x && x < lim); // 调试检查，可删
        (void)x;
    }
    vector<int> ans(qs.size());
    if (k < 0 || k > bits)
    {
        return ans;
    }

    // Query[0..2] 依次表示从 1 开始的左端点、右端点、原询问编号。
    using Query = array<int, 3>;
    vector<Query> ord;
    for (int id = 0; id < (int)qs.size(); id++)
    {
        auto [l, r] = qs[id];
        assert(0 <= l && l <= r && r <= n); // 调试检查，可删
        if (l < r)
        {
            ord.push_back({l + 1, r, id});
        }
    }
    if (ord.empty())
    {
        return ans;
    }

    auto z = max<int>(1, (int)(n / sqrtl((long double)ord.size())));
    sort(ord.begin(),
         ord.end(),
         [&](const auto &x, const auto &y)
         {
             auto bx = (x[0] - 1) / z, by = (y[0] - 1) / z;
             if (bx != by)
             {
                 return bx < by;
             }
             return bx & 1 ? x[1] > y[1] : x[1] < y[1];
         });

    vector<int> masks;
    for (int s = 0; s < lim; s++)
    {
        if (popcount((unsigned long long)s) == k)
        {
            masks.push_back(s);
        }
    }
    vector<int> v(n + 1), cnt(lim), pre(n + 1);
    copy(a.begin(), a.end(), v.begin() + 1);
    for (int i = 1; i <= n; i++)
    {
        pre[i] = pre[i - 1];
        for (auto s : masks)
        {
            pre[i] += cnt[v[i] ^ s];
        }
        cnt[v[i]]++;
    }

    // Event[0..3] 依次表示左端点、右端点、贡献符号、排序后询问编号。
    using Event = array<int, 4>;
    vector<vector<Event>> ev(n + 1);
    vector<int> cur(ord.size());
    int l = 1, r = 0;
    for (int id = 0; id < (int)ord.size(); id++)
    {
        auto q = ord[id];
        cur[id] = pre[q[1]] - pre[r] + pre[q[0] - 1] - pre[l - 1];
        if (!k)
        {
            cur[id] += q[0] - l;
        }
        if (r < q[1])
        {
            ev[l - 1].push_back({r + 1, q[1], -1, id});
            r = q[1];
        }
        if (l > q[0])
        {
            ev[r].push_back({q[0], l - 1, 1, id});
            l = q[0];
        }
        if (r > q[1])
        {
            ev[l - 1].push_back({q[1] + 1, r, 1, id});
            r = q[1];
        }
        if (l < q[0])
        {
            ev[r].push_back({l, q[0] - 1, -1, id});
            l = q[0];
        }
    }

    fill(cnt.begin(), cnt.end(), 0);
    for (int i = 1; i <= n; i++)
    {
        for (auto s : masks)
        {
            cnt[v[i] ^ s]++;
        }
        for (auto e : ev[i])
        {
            int val = 0;
            for (int j = e[0]; j <= e[1]; j++)
            {
                val += cnt[v[j]];
            }
            cur[e[3]] += e[2] * val;
        }
    }
    for (int i = 1; i < (int)cur.size(); i++)
    {
        cur[i] += cur[i - 1];
    }
    for (int i = 0; i < (int)ord.size(); i++)
    {
        ans[ord[i][2]] = cur[i];
    }
    return ans;
}
```
用 `auto ans = xorPairs(a, qs, k, bits)` 调用，`qs` 是若干 $[l, r)$，返回每个区间内满足 $\operatorname{popcount}(a_i\oplus a_j)=k$ 的无序点对数，要求 $0\le a_i<2^{bits}$ 且 $bits\le20$。令 $C=\binom{bits}{k}$、块长为 $B$，本实例时间为 $O\left(2^{bits}+nC+\frac{n^2}{B}+qB+q\log q\right)$，取 $B\approx\frac{n}{\sqrt q}$ 时莫队部分为 $O(n\sqrt q)$，空间为 $O(2^{bits}+n+q+C)$。二次离线只在前缀贡献 $G$ 能显著快于逐段扫描时才划算；区间不同数、区间和这类端点本就 $O(1)$ 的问题应继续用普通莫队，而换一个贡献函数 $w$ 都必须重新推导并对拍。下面用四个两位数同时检查整段、子段与空区间：

```cpp
signed main()
{
    vector<int> a{0, 1, 2, 3};
    vector<pair<int, int>> q{{0, 4}, {1, 4}, {2, 2}};
    assert((xorPairs(a, q, 1, 2) == vector<int>{4, 2, 0}));
}
```

### 2.3.005 区间不同数统计

静态数组上的区间不同数，比起普通莫队有更快且确定性更强的做法：把询问按右端点离线，扫描右端点 `r` 时用树状数组只保留每个值的最后一次出现——遇到新的 `a[r-1]` 就把它旧的最后出现位置减 $1$、当前位置加 $1$，于是 Fenwick 中每个不同值恰好留下一个标记，区间 $[l, r)$ 的标记和即不同值数量。这依赖查询静态，一旦夹杂修改，「最后出现位置」会整体漂移而失效。这里先离散化值域，最后位置、Fenwick 和查询桶都只存下标与频次，打印版按普通 `int` 处理；`Fenwick` 的查询接口不直接复用是因为它的节点类型必须保留一般的 64 位和，而此处计数上界为数组长度。此处只给新增的 `distinct`：

```cpp
vector<int> distinct(const vector<int> &a, const vector<pair<int, int>> &qs)
{
    // a 是静态数组，qs 是半开区间；返回每个区间中的不同值数量。
    // 只有下标、排名和频次的热点数据使用普通 int，避免无意义地扩大工作集。
    vector<int> val = a;
    sort(val.begin(), val.end());
    val.erase(unique(val.begin(), val.end()), val.end());
    vector<int> rank(a.size());
    for (int i = 0; i < (int)a.size(); i++)
    {
        rank[i] = (int)(lower_bound(val.begin(), val.end(), a[i]) - val.begin());
    }
    // Ask[0..1] 依次表示左端点与答案编号，按右端点分桶。
    using Ask = array<int, 2>;
    vector<vector<Ask>> ask(a.size() + 1);
    for (int i = 0; i < (int)qs.size(); i++)
    {
        auto [l, r] = qs[i];
        assert(0 <= l && l <= r && r <= (int)a.size()); // 调试检查，可删
        assert(r <= numeric_limits<int>::max());    // 调试检查，可删
        ask[r].push_back({(int)l, (int)i});
    }
    vector<int> bit(a.size() + 1), last(val.size(), -1);
    auto add = [&](int p, int delta)
    {
        // p 是从 0 开始的位置，delta 是出现位置标记的变化。
        for (p++; p < (int)bit.size(); p += p & -p)
        {
            bit[p] += (int)delta;
        }
    };
    auto sum = [&](int p)
    {
        // p 是半开前缀右端点；返回 [0,p) 的最后出现位置标记数。
        int ans = 0;
        for (; p; p -= p & -p)
        {
            ans += bit[p];
        }
        return ans;
    };
    vector<int> ans(qs.size());
    for (int r = 0; r <= (int)a.size(); r++)
    {
        if (r)
        {
            auto x = rank[r - 1];
            if (last[x] >= 0)
            {
                add(last[x], -1);
            }
            add(r - 1, 1);
            last[x] = r - 1;
        }
        for (auto [l, id] : ask[r])
        {
            ans[id] = sum(r) - sum(l);
        }
    }
    return ans;
}
```
用 `auto ans = distinct(a, qs)` 调用，`qs` 里每个区间为 $[l, r)$，允许空区间。数组值经防卡哈希记录最后位置，需要稳定最坏复杂度时可先离散化再把 `last` 换成 `vector<int>`。每个位置至多执行两次 Fenwick 修改、每个询问执行一次区间和，时间为 $O((n+q)\log n)$，空间为 $O(n+q)$。

### 2.3.006 区间第 K 小整体二分

在静态数组上批量回答 $[l, r)$ 第 $k$ 小，用整体二分套树状数组即可，无需建可持久化线段树：把元素按离散值域中点分到左右两组，Fenwick 只暂存左半值在各位置的出现次数，每个询问用区间计数 `c` 判断第 $k$ 小落在哪组——落右组时把 $k$ 扣掉 `c`，每层递归前务必撤销本层的 Fenwick 修改。这套代码与 [2.2.004 整体二分](#22004) 给出的 `rangeKth` 完全一致（那里连同离散化 `Discrete`、`Fenwick` 一并给出并附固定样例），此处不再重复。`KthQuery={l,r,k}` 三维为半开区间左右端点与从 $1$ 开始的排名，须满足 $1\le k\le r-l$，函数只改询问副本中的 $k$、不动调用者数据；时间 $O((n+q)\log V\log n)$、空间 $O(n+q+V)$。若有在线强制查询，改用主席树或小波矩阵。

### 2.3.007 树上莫队

欧拉括号序把树上路径查询降到序列区间查询：DFS 时进入结点 $u$ 追加一次记录 $st_u$、离开时再追加一次记录 $ed_u$，得到长 $2n$ 的序列 $seq$，每个结点恰出现两次。对路径 $(u,v)$（先令 $st_u\le st_v$），设 $w=\operatorname{lca}(u,v)$：

- 若 $w=u$（$u$ 是 $v$ 的祖先），路径点集恰为 $seq[st_u..st_v]$ 中「出现奇数次」的那些结点；
- 否则取区间 $seq[ed_u..st_v]$，其奇数次结点为路径去掉 $w$ 后的部分，需额外单独加入 $w$。

因此把每个询问转成一段区间（外加一个可选的 $w$），用普通莫队（[2.3.001 普通莫队](#23001)）离线跑，`work(u)` 按 $u$ 当前出现次数的奇偶切换其贡献（偶→奇计入、奇→偶移除）。LCA 用倍增（[6.1.002 最近公共祖先：倍增](#61002)）。下例统计路径上不同权值个数，权值需先离散化到 $[0,n)$。

```cpp
struct TreeMo
{
    int n = 0;                     // n 是树的顶点数。
    int lg = 1;                    // lg 是倍增祖先表的层数。
    int blk = 1;                   // blk 是当前询问排序的块长。
    vector<vector<int>> g;         // g 是树的邻接表。
    vector<int> col;               // col[u] 是顶点 u 离散到 [0,n) 的权值。
    vector<int> st;                // st[u] 是顶点 u 进入欧拉序的位置。
    vector<int> ed;                // ed[u] 是顶点 u 离开欧拉序的位置。
    vector<int> seq;               // seq 是每个顶点进出各出现一次的欧拉序。
    vector<int> dep;               // dep[u] 是顶点 u 到当前根的边数。
    vector<vector<int>> up;        // up[k][u] 是顶点 u 的第 2^k 级祖先。
    vector<array<int, 4>> qs;      // 每项是 {欧拉左端、欧拉右端、额外 LCA、答案编号}。

    explicit TreeMo(int m) : n(m), g(m), col(m), st(m), ed(m), dep(m)
    {
        // m 是非空树的顶点数。
        assert(m > 0); // 调试检查，可删
    }

    void addTreeEdge(int u, int v)
    {
        // u、v 是无向树边的两个端点；调用后把边加入邻接表。
        assert(0 <= u && u < n && 0 <= v && v < n); // 调试检查，可删
        g[u].push_back(v);
        g[v].push_back(u);
    }

    void build(int root = 0)
    {
        // root 是本次选定的根；重建欧拉序和祖先表，并清空依赖旧序的询问。
        assert(0 <= root && root < n); // 调试检查，可删
        lg = 1;
        while ((1ULL << lg) < (unsigned long long)n)
        {
            lg++;
        }
        up.assign(lg, vector<int>(n, root));
        fill(dep.begin(), dep.end(), 0);
        seq.clear();
        seq.reserve((size_t)n * 2);
        qs.clear();

        st[root] = 0;
        seq.push_back(root);
        auto dfs = [&](auto &&self, int u, int p) -> void
        {
            for (auto v : g[u])
            {
                if (v == p)
                {
                    continue;
                }
                up[0][v] = u;
                dep[v] = dep[u] + 1;
                st[v] = seq.size();
                seq.push_back(v);
                self(self, v, u);
            }
            ed[u] = seq.size();
            seq.push_back(u);
        };
        dfs(dfs, root, -1);
        for (int k = 1; k < lg; k++)
        {
            for (int u = 0; u < n; u++)
            {
                up[k][u] = up[k - 1][up[k - 1][u]];
            }
        }
    }

    int lca(int u, int v) const
    {
        // u、v 是树上顶点；返回它们在当前根下的最近公共祖先。
        assert(!up.empty() && 0 <= u && u < n && 0 <= v && v < n); // 调试检查，可删
        if (dep[u] < dep[v])
        {
            swap(u, v);
        }
        auto d = dep[u] - dep[v];
        for (int k = 0; k < lg; k++)
        {
            if (d >> k & 1)
            {
                u = up[k][u];
            }
        }
        if (u == v)
        {
            return u;
        }
        for (int k = lg - 1; k >= 0; k--)
        {
            if (up[k][u] != up[k][v])
            {
                u = up[k][u];
                v = up[k][v];
            }
        }
        return up[0][u];
    }

    void addQuery(int u, int v)
    {
        // u、v 是路径两端；把该路径转成半开欧拉区间并按加入顺序编号。
        assert(!up.empty() && 0 <= u && u < n && 0 <= v && v < n); // 调试检查，可删
        if (st[u] > st[v])
        {
            swap(u, v);
        }
        auto w = lca(u, v);
        auto id = (int)qs.size();
        if (w == u)
        {
            qs.push_back({st[u], st[v] + 1, -1, id});
        }
        else
        {
            qs.push_back({ed[u], st[v] + 1, w, id});
        }
    }

    vector<int> solve()
    {
        // 返回每条已加入路径上的不同权值数，顺序与 addQuery 一致。
        if (qs.empty())
        {
            return {};
        }
        for (auto x : col)
        {
            assert(0 <= x && x < n); // 调试检查，可删
        }
        auto m = (int)qs.size();
        blk = max<int>(1, (int)((long double)seq.size() / sqrtl(m)));
        sort(qs.begin(),
             qs.end(),
             [&](const auto &a, const auto &b)
             {
                 auto x = a[0] / blk;
                 auto y = b[0] / blk;
                 if (x != y)
                 {
                     return x < y;
                 }
                 return x & 1 ? a[1] > b[1] : a[1] < b[1];
             });
        vector<int> cnt(n);
        vector<int> used(n);
        vector<int> ans(m);
        int cur = 0;
        auto work = [&](int u)
        {
            // u 是本次切换的顶点；奇数次出现计入路径，偶数次出现移出路径。
            used[u] ^= 1;
            if (used[u])
            {
                if (cnt[col[u]]++ == 0)
                {
                    cur++;
                }
            }
            else
            {
                if (--cnt[col[u]] == 0)
                {
                    cur--;
                }
            }
        };
        int l = 0;
        int r = 0;
        for (auto q : qs)
        {
            auto ql = q[0];
            auto qr = q[1];
            auto w = q[2];
            auto id = q[3];
            while (l > ql)
            {
                work(seq[--l]);
            }
            while (r < qr)
            {
                work(seq[r++]);
            }
            while (l < ql)
            {
                work(seq[l++]);
            }
            while (r > qr)
            {
                work(seq[--r]);
            }
            if (w >= 0)
            {
                work(w);
            }
            ans[id] = cur;
            if (w >= 0)
            {
                work(w);
            }
        }
        return ans;
    }
};
```

先用 `addTreeEdge` 连成一棵树，填好 `col` 后调用 `build(root)`，再用 `addQuery(u,v)` 挂路径询问；`solve()` 返回按加入顺序排列的不同权值数。再次 `build` 会重置深度、欧拉序、祖先表，并清空基于旧根编码的询问。带修改版再增加时间轴，思路同 [2.3.002 带修改莫队](#23002)。欧拉序长 $2n$，代码取块长约 $2n/\sqrt q$，排序和状态切换共 $O(n\sqrt q+q\log q)$ 时间，祖先表与其余状态共 $O(n\log n+q)$ 空间。

下面的四点树覆盖跨分支路径、祖孙路径、单点路径与根路径，并检查换根重建会清空旧询问：

```cpp
signed main()
{
    TreeMo tr(4);
    tr.addTreeEdge(0, 1);
    tr.addTreeEdge(0, 2);
    tr.addTreeEdge(1, 3);
    tr.col = {1, 2, 1, 3};
    tr.build(0);
    for (auto [u, v] : vector<pair<int, int>>{{3, 2}, {3, 1}, {2, 2}, {3, 0}})
    {
        tr.addQuery(u, v);
    }
    assert((tr.solve() == vector<int>{3, 2, 1, 3}));
    tr.build(3);
    assert(tr.qs.empty());
}
```

## 2.4 差分与前缀技巧

### 2.4.001 一维/二维前缀和

静态数组区间和与静态矩阵子矩形和的基础工具。一维前缀定义 $s_i=\sum_{0\le j<i}a_j$，于是 $[l, r)$ 的区间和为 $s_r-s_l$；二维前缀沿两个轴累计，查询时用四个角做容斥。全程半开区间，让空区间、边界与长度计算保持一致。一维只需 `partial_sum`：

```cpp
// a 是原数组，s 是前缀和，l、r 是半开区间端点，sum 是区间和。
vector<int> s(a.size() + 1);
partial_sum(a.begin(), a.end(), s.begin() + 1);
auto sum = s[r] - s[l];
```

二维把它封装成 `Prefix2`，构造时预处理带零行零列的前缀矩阵，`sum` 用四角容斥回答子矩形：

```cpp
template <class T> struct Prefix2
{
    int n = 0, m = 0;    // n、m 是原矩阵行数与列数。
    vector<vector<T>> s; // s 是带额外零行零列的二维前缀和。

    explicit Prefix2(const vector<vector<T>> &a)
    {
        // a 是规则原矩阵。
        n = a.size();
        m = n ? a[0].size() : 0;
        s.assign(n + 1, vector<T>(m + 1));
        for (int i = 0; i < n; i++)
        {
            assert((int)a[i].size() == m); // 调试检查，可删
            for (int j = 0; j < m; j++)
            {
                s[i + 1][j + 1] = a[i][j] + s[i][j + 1] + s[i + 1][j] - s[i][j];
            }
        }
    }

    T sum(int x1, int y1, int x2, int y2) const
    {
        // x1、y1、x2、y2 是半开子矩形的上、左、下、右边界；返回子矩形和。
        return s[x2][y2] - s[x1][y2] - s[x2][y1] + s[x1][y1];
    }
};
```
调用形如 `Prefix2<int> ps(mat); auto rect = ps.sum(x1, y1, x2, y2)`，所有接口都用半开区间，二维矩阵必须规则矩形，空矩阵只能构造不能查询。模板参数 `T` 必须能表示每个前缀、四角容斥和查询结果；能由范围证明 64 位安全时使用 `int`，否则把累计类型实例化为更宽类型，不要只看单个元素范围。一维构造 $O(n)$、查询 $O(1)$、空间 $O(n)$；二维构造 $O(nm)$、查询 $O(1)$、空间 $O(nm)$。

### 2.4.002 一维/二维差分

前缀和的逆运算：离线执行大量区间加、矩形加，最后一次性恢复全部值。差分只在区间边界记录「从这里开始增加、到那里停止」，最终做一次前缀和即恢复所有位置；二维矩形修改在四个角写入容斥符号，再沿两个轴分别做前缀和。若修改后还要在线查询，则应改用 Fenwick 或线段树。一维封装为 `Diff`：

```cpp
template <class T> struct Diff
{
    int n = 0;   // n 是目标数组长度。
    vector<T> d; // d 保存长度为 n+1 的边界差分。

    Diff(int m = 0) : n(m), d(m + 1)
    {
        // m 是目标数组长度。
    }

    void add(int l, int r, T x)
    {
        // l、r 是半开区间端点，x 是区间增量。
        assert(0 <= l && l <= r && r <= n); // 调试检查，可删
        d[l] += x;
        d[r] -= x;
    }

    vector<T> build() const
    {
        // 返回执行全部区间修改后的长度 n 数组。
        vector<T> a(n);
        T cur{};
        for (int i = 0; i < n; i++)
        {
            cur += d[i];
            a[i] = cur;
        }
        return a;
    }
};
```

二维版 `Diff2` 在矩形四角写差分、`build()` 时沿两轴前缀和还原：

```cpp
template <class T> struct Diff2
{
    int n = 0, m = 0;    // n、m 是目标矩阵行数与列数。
    vector<vector<T>> d; // d 保存带额外边界的二维差分。

    Diff2(int x = 0, int y = 0) : n(x), m(y), d(x + 1, vector<T>(y + 1))
    {
        // x、y 是目标矩阵行数与列数。
    }

    void add(int x1, int y1, int x2, int y2, T v)
    {
        // 四个坐标描述半开子矩形，v 是矩形增量。
        assert(0 <= x1 && x1 <= x2 && x2 <= n); // 调试检查，可删
        assert(0 <= y1 && y1 <= y2 && y2 <= m); // 调试检查，可删
        d[x1][y1] += v;
        d[x1][y2] -= v;
        d[x2][y1] -= v;
        d[x2][y2] += v;
    }

    vector<vector<T>> build() const
    {
        // 返回执行全部矩形修改后的 n 行 m 列矩阵。
        auto a = d;
        for (int i = 0; i < n; i++)
        {
            for (int j = 0; j < m; j++)
            {
                if (i)
                {
                    a[i][j] += a[i - 1][j];
                }
                if (j)
                {
                    a[i][j] += a[i][j - 1];
                }
                if (i && j)
                {
                    a[i][j] -= a[i - 1][j - 1];
                }
            }
        }
        a.resize(n);
        for (auto &row : a)
        {
            row.resize(m);
        }
        return a;
    }
};
```
调用形如 `Diff<int> d(n); d.add(l, r, x); auto a = d.build();` 与 `Diff2<int> d2(n, m); d2.add(x1, y1, x2, y2, v); auto mat = d2.build();`，修改同样是半开区间，`build()` 不清空差分故可重复恢复同一结果。模板参数 `T` 必须能表示边界差分、前缀恢复中的所有中间量和最终数组；若单次修改或多次叠加可能越过 64 位，应显式选择更宽累计类型。每次修改 $O(1)$；一维恢复 $O(n)$、空间 $O(n)$；二维恢复 $O(nm)$、空间 $O(nm)$。

### 2.4.003 K 阶差分

定义一阶差分 $\Delta a_i=a_{i+1}-a_i$，它把多项式次数降低 $1$，其逆过程即前缀和。于是普通差分重复 $k$ 次后，次数不超过 $k$ 的多项式序列会变成常量——这可用来识别多项式序列、从有限差分恢复值，以及设计以组合数为基的多项式区间更新。后者的依据是组合数基满足

$$
\binom{x}{k}-\binom{x-1}{k}=\binom{x-1}{k-1},
$$

对它做一次差分会自然降阶，区间加一个多项式可转成少量高阶差分端点修改。但各题的端点补偿取决于所选基底、下标起点和模数，不宜塞进一个没有明确语义的通用类，因此本节的短函数只负责对一个静态序列求 $k$ 阶差分；前缀和、差分、K 阶差分与组合数基推导之间的关系见 [`知识点关系.md`](知识点关系.md)。

```cpp
template <class T> vector<T> kthDiff(vector<T> a, int k)
{
    // a 是按值复制的原序列，k 是差分阶数；返回 k 阶差分序列。
    assert(k >= 0); // 调试检查，可删
    auto t = min<int>(k, a.size());
    for (int z = 0; z < t; z++)
    {
        for (int i = 1; i < (int)a.size(); i++)
        {
            a[i - 1] = a[i] - a[i - 1];
        }
        a.pop_back();
    }
    return a;
}
```
调用 `kthDiff(a, k)` 返回长度为 $\max(0, n-k)$ 的新序列、不修改传入数组，例如 `kthDiff(vector<int>{0,1,4,9,16}, 2)` 得 `{2,2,2}`（平方序列的二阶差分为常量）。序列在第 $n$ 阶后已经为空，`k>n` 时不再执行无意义循环。若题目要多次区间加后统一输出，应先把所加多项式写成 $\binom{i}{j}$ 的线性组合，再据上式推导左右端点补偿；需在线查询则把各阶差分放入 Fenwick 或线段树。令 $h=\min(k,n)$，当前实现执行 $\sum_{j=0}^{h-1}(n-j-1)$ 次减法，时间 $O(hn)$、额外空间 $O(n)$；所有差分值须能由 `T` 表示。组合数区间更新的题目特化通常单次修改 $O(k)$、最终恢复 $O(kn)$。

### 2.4.004 子段和、子矩阵和

Kadane 求非空最大子段和：在每个位置只比较「接到前一段后面」与「从当前位置重新开始」，全负数时也能返回最大单元素而不误判为空：

```cpp
template <class T> T maxSub(const vector<T> &a)
{
    // a 是非空序列；返回非空最大子段和。
    // 若要最小子段和，保留首元素初始化，把 max 改成 min、chmax 改成 chmin；不能只改最终答案比较。
    assert(!a.empty()); // 调试检查，可删
    T ans = a[0];
    T cur = a[0];
    for (int i = 1; i < (int)a.size(); i++)
    {
        T x = a[i];
        cur = max(x, cur + x);
        chmax(ans, cur);
    }
    return ans;
}
```

最大子矩阵和枚举上下边界，把夹在两行间的每列和压成一维数组再复用同一个 Kadane；调用前让较小维度承担平方枚举，可明显降低常数：

```cpp
template <class T> T maxSubMat(const vector<vector<T>> &a)
{
    // a 是非空规则矩阵；返回非空最大子矩阵和。
    // 若要最小子矩阵和，同步使用最小子段版本并把 chmax 改成 chmin；边界仍以 a[0][0] 初始化。
    assert(!a.empty() && !a[0].empty()); // 调试检查，可删
    auto n = (int)a.size();
    auto m = (int)a[0].size();
    for (auto &row : a)
    {
        assert((int)row.size() == m); // 调试检查，可删
    }
    T ans = a[0][0];
    for (int u = 0; u < n; u++)
    {
        vector<T> s(m);
        for (int d = u; d < n; d++)
        {
            for (int j = 0; j < m; j++)
            {
                s[j] += a[d][j];
            }
            chmax(ans, maxSub(s));
        }
    }
    return ans;
}
```
直接 `maxSub(a)`、`maxSubMat(mat)` 调用，两者都要求非空输入并已正确处理全负数，返回类型与元素类型 `T` 相同。调用者须保证全部累计量能由 `T` 表示；确实需要 `__int128` 时先把输入元素转成 `__int128`，不为这两个短函数再加一层累计类型参数。当前实现平方枚举行数，故当行数大于列数时应先转置。最大子段 $O(n)$ 时间、$O(1)$ 空间；$n\times m$ 矩阵当前实现 $O(n^2m)$ 时间、$O(m)$ 空间，令较小维度作为行数后为 $O(\min(n,m)^2\max(n,m))$。

### 2.4.005 所有区间 GCD

令 $V=\max_i|a_i|$。固定右端点 $r$、让左端点从大到小移动时，$\gcd(a_l,\dots,a_r)$ 除了从 $0$ 变为首个非零值外，只会变成前一个正值的真因数，因此不同取值至多 $O(\log(V+2))$ 个。据此对每个右端点维护一张压缩列表：从 `r-1` 的列表转移到 `r` 时，把每个旧 gcd 与 `a[r]` 再取 gcd 并合并相邻相同结果，同时记录每个 gcd 生效的最小左端点，查询固定右端点后按左端点二分即可。因为要保存所有右端点的列表并支持多次查询，这里封装成结构体是必要的：

```cpp
template <class T> struct GcdRanges
{
    using U = make_unsigned_t<T>;

    vector<vector<pair<int, U>>> g; // g[r] 保存以 r 结尾的不同 GCD 及最小左端点。

    static U mag(T x)
    {
        // x 是原数组元素；返回不对最小负数取正值的无符号幅值。
        auto u = (U)x;
        if constexpr (is_signed_v<T>)
        {
            if (x < 0)
            {
                return (U)0 - u;
            }
        }
        return u;
    }

    explicit GcdRanges(const vector<T> &a) : g(a.size())
    {
        // a 是用于预处理所有右端点 GCD 分段的原数组。
        static_assert(is_integral_v<T>);
        vector<pair<int, U>> pre;
        for (int r = 0; r < (int)a.size(); r++)
        {
            auto v = mag(a[r]);
            vector<pair<int, U>> cur{{r, v}};
            for (auto [l, x] : pre)
            {
                x = gcd(x, v);
                if (cur.back().second == x)
                {
                    cur.back().first = l;
                }
                else
                {
                    cur.push_back({l, x});
                }
            }
            reverse(cur.begin(), cur.end());
            g[r] = cur;
            pre = cur;
            reverse(pre.begin(), pre.end());
        }
    }

    U query(int l, int r) const
    {
        // l、r 是闭区间端点；返回 a[l..r] 的绝对值 GCD。
        assert(0 <= l && l <= r && r < (int)g.size()); // 调试检查，可删
        auto it = upper_bound(g[r].begin(),
                              g[r].end(),
                              l,
                              [](int x, const auto &p)
                              {
                                  return x < p.first;
                              });
        return prev(it)->second;
    }
};
```
调用形如 `GcdRanges<int> gr(a); auto g = gr.query(l, r);`，其中 `query` 是本章唯一使用闭区间 $[l, r]$ 的接口——因为结构按「以 $r$ 结尾」存储，这里特意保留差异以防与半开区间混用。GCD 以 `make_unsigned_t<T>` 保存，负数先按位转换后在无符号环中取幅值，因此最小有符号整数也得到可表示的 $2^{63}$，返回值同样是无符号类型。每个右端点至多保留 $O(\log(V+2))$ 个不同 GCD；按 64 位 gcd 为常数操作的竞赛 RAM 模型，构造为 $O(n\log(V+2))$，若计入 Euclid 迭代则保守上界为 $O(n\log^2(V+2))$；空间 $O(n\log(V+2))$，单次查询 $O(\log(1+\log(V+2)))$。

### 2.4.006 连续区间按位异或

连续四个整数的低两位模式，使前缀异或 $0\oplus1\oplus\dots\oplus n$ 只由 $n\bmod 4$ 决定（依次为 $n$、$1$、$n+1$、$0$），于是闭区间 $[l, r]$ 的异或可用两个前缀异或相消得到，常数时间完成。这是纯公式，没有状态，也不需要结构体：

```cpp
// l、r 是闭区间端点，ans 是区间内所有整数的异或和。
auto ans = r;
if ((r & 3) == 1) ans = 1;
else if ((r & 3) == 2) ans = r + 1;
else if ((r & 3) == 3) ans = 0;

if (l)
{
    auto x = l - 1;
    auto pre = x;
    if ((x & 3) == 1) pre = 1;
    else if ((x & 3) == 2) pre = x + 1;
    else if ((x & 3) == 3) pre = 0;
    ans ^= pre;
}
```
代码结束后的 `ans` 即闭区间 $[l, r]$ 的异或和，要求 $0\le l\le r$，且 `l`、`r` 使用无符号 $64$ 位整数；若要对数组下标区间异或仍应改用普通前缀异或数组。$O(1)$ 时间、$O(1)$ 空间。
