# 合订本构建

`book/` 把第 0–15 章 Markdown 合成带目录、页码和可点击交叉引用的合订 PDF，并额外构建三册打印版。原版合订 PDF 保留在 `book/` 根目录，分册 PDF 统一放在 `book/分册版/`；中间 Markdown、TeX 和 LaTeX 缓存不纳入 Git。

## 命令

Linux / MSYS2：

```bash
bash book/build.sh
bash book/build.sh tex
```

Windows：

```bat
book\build.bat
book\build.bat tex
```

`tex` 参数只生成合订本中间 TeX，用于排查渲染问题；默认无参数构建才会同时生成合订 PDF 和三册打印 PDF。

## 依赖

- Python 3.10+ 与 `pypdf`（`python -m pip install pypdf`）。
- Pandoc 3.x。
- XeLaTeX 与 `ctex`、`tcolorbox`、`fvextra` 宏包。
- `head.tex` 中配置的中文与代码字体；本机没有该字体时需改为已安装字体。

## 文件

- `build.sh` / `build.bat`：调用 `build.py` 的跨平台入口，失败返回非零退出码。
- `render_pdf.py`：在系统临时目录生成 TeX，运行三遍 XeLaTeX；失败保留正式 PDF，日志保留在输出的临时路径。
- `build.py`：构建合订本、三册 PDF 后运行 Markdown 链接及 PDF 结构检查。
- `build_volumes.py`：读取本次合订本的章书签与实际页数，自动选择连续章节边界，优先减小最大册页数，再减小册间页数差；三册各带本册目录与对应分册封皮。
- `分册版/`：三份分册 PDF，文件名为 `hushuqi算法竞赛模板(上).pdf`、`hushuqi算法竞赛模板(中).pdf`、`hushuqi算法竞赛模板(下).pdf`。
- `strip_preamble.py`：合订时删除重复的章前导。
- `anchors.lua`：把知识点编号转成稳定锚点。
- `numberlines.lua`：为代码块加行号。
- `head.tex` / `cover.tex`：XeLaTeX 页面与封面配置。
- `jblight.theme` / `jbdark.theme`：Pandoc 代码高亮主题。

默认构建会拒绝缺字、未定义引用、空 PDF 或超出 600 页的分册，并输出溢出框数量。字体必须能被 XeLaTeX 按文件名找到；`head.tex` 不再绑定本机 TeX Live 安装盘符。PDF 内容流与页数检查不能替代抽样查看公式、代码换行与目录位置。

分册边界只落在章之间，不限制章节总数为 16。合订本正文页数用于排序候选，实际分册还包含封面、目录和分页差异；若某册超过 600 页，构建器自动尝试其他边界并复用已构建的相同分册。三册均通过页数检查后才更新正式分册；没有可行边界或编译失败时保留原分册。单独运行 `python book/build_volumes.py` 也会先重建合订本，避免沿用旧页数。

运行 `python tests/test_book_volumes.py` 检查连续划分、超页重试和失败保留文件。
