# 合订本构建

`book/` 把第 0–15 章 Markdown 合成带目录、页码和可点击交叉引用的合订 PDF，并额外构建三册打印版。原版合订 PDF 保留在 `book/` 根目录，分册 PDF 统一放在 `book/分册版/`；中间 Markdown、TeX 和 LaTeX 缓存不纳入 Git。

## 命令

Linux / MSYS2：

```bash
bash book/build.sh
bash book/build.sh tex
```

Windows：

```bat
book\build.bat
book\build.bat tex
```

`tex` 参数只生成合订本中间 TeX，用于排查渲染问题；默认无参数构建才会同时生成合订 PDF 和三册打印 PDF。

## 依赖

- Pandoc 3.x。
- XeLaTeX 与 `ctex`、`tcolorbox`、`fvextra` 宏包。
- `head.tex` 中配置的中文与代码字体；本机没有该字体时需改为已安装字体。

## 文件

- `build.sh` / `build.bat`：合订与构建入口。
- `build_volumes.py`：按章节构建上、中、下三册；三册各带本册目录与对应分册封皮。
- `分册版/`：三份分册 PDF，文件名为 `hushuqi算法竞赛模板(上).pdf`、`hushuqi算法竞赛模板(中).pdf`、`hushuqi算法竞赛模板(下).pdf`。
- `strip_preamble.py`：合订时删除重复的章前导。
- `anchors.lua`：把知识点编号转成稳定锚点。
- `numberlines.lua`：为代码块加行号。
- `head.tex` / `cover.tex`：XeLaTeX 页面与封面配置。
- `jblight.theme` / `jbdark.theme`：Pandoc 代码高亮主题。
